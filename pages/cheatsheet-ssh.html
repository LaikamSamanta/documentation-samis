SSH Cheatsheet

Ātrās uzziņas lapa - katrai kartiņai īss skaidrojums un komandas fragments. Pilnus piemērus un paskaidrojumus skaties pilnajā SSH dokumentācijā.

Pieslēgšanās SSH atslēgas WP-CLI Statusa pārbaude Datubāze Faili & tiesības Servera resursi Tīkla diagnostika Drošība Logi Pārsūtīšana

Pieslēgšanās

ssh

Pamata pieslēgšanās komanda.

ssh lietotajs@serveris.lv

Nestandarta ports

Ja serveris klausās citā portā, ne 22.

ssh -p 2222 lietotajs@serveris.lv

Atrast WordPress

Meklē wp-config.php visā serverī.

find / -name wp-config.php 2>/dev/null

SSH atslēgas

Ģenerē atslēgu

Modernais, ieteicamais tips.

ssh-keygen -t ed25519 -C "e@pasts.lv"

Nokopē uz serveri

Automātiski pievieno authorized_keys failam.

ssh-copy-id lietotajs@serveris.lv

~/.ssh/config saīsinājums

Ļauj pieslēgties ar "ssh vārds" bez pilnas adreses.

Host vards
  HostName serveris.lv
  User lietotajs

WP-CLI

Spraudņi

Saraksts, uzstādīšana, masveida atjaunināšana.

wp plugin list
wp plugin update --all

Tēmas

Aktivizēšana un atjaunināšana.

wp theme activate mana-tema

Lietotāji

Jauna admin lietotāja izveide (paroles atgūšanai).

wp user create adminis e@pasts.lv --role=administrator

Tikai administratori

Drošības audits - pārbaudi, vai nav svešu admin kontu.

wp user list --role=administrator

Konkrēta lietotāja info

Visi dati par vienu lietotāju.

wp user get lietotajvards --fields=all

Opcijas

Nolasa/maina jebkuru WordPress iestatījumu.

wp option update blogname "Jauns nosaukums"

Cache

Notīra WordPress objektu kešu.

wp cache flush

Statusa pārbaude

Aktīvā tēma

Uzreiz nosaukums, bez liekā.

wp theme list --status=active --field=name

Aktīvie spraudņi

Tikai ieslēgtie, ne visi uzstādītie.

wp plugin list --status=active --field=name

WordPress versija

Instalētā kodola versija.

wp core version

PHP versija

Servera, ne WordPress, versija.

php -v

MySQL versija

Datubāzes servera versija.

wp db query "SELECT VERSION();"

Vietnes URL

Tas, kas saglabāts datubāzē (ne DNS).

wp option get siteurl

Datubāze

Eksports

Pilns datubāzes dublējums vienā failā.

wp db export dublejums.sql

Imports

Atjaunošana no dublējuma faila.

wp db import dublejums.sql

Domēna maiņa

Vienmēr vispirms ar --dry-run, tad bez tā.

wp search-replace 'vecs.lv' 'jauns.lv' --dry-run

mysqldump (bez WP-CLI)

Tiešs MySQL dublējums.

mysqldump -u lietotajs -p db > dublejums.sql

Faili & tiesības

Rediģēt failu

nano - vienkāršākais termināļa redaktors.

nano wp-config.php

Mapju tiesības

Standarta drošas tiesības - 755.

find . -type d -exec chmod 755 {} \;

Failu tiesības

Standarta drošas tiesības - 644.

find . -type f -exec chmod 644 {} \;

wp-config.php

Stingrāk - tikai īpašniekam.

chmod 600 wp-config.php

Faila datumi

Modify laiks - svarīgākais, meklējot mainītus failus.

stat fails.php

Servera resursi

RAM

Atmiņas izmantojums cilvēkam lasāmā formātā.

free -h

TOP procesi pēc RAM

Kas patērē visvairāk atmiņas šobrīd.

ps aux --sort=-%mem | head -10

Diska vieta

Izmantojums pa nodalījumiem.

df -h

Lielākās mapes

Kas piepildījis disku.

du -sh */ | sort -rh | head -10

Tīkla diagnostika

Servera IP

Piešķirtā/iekšējā adrese.

hostname -I

Publiskā IP

Tā, kā serveri redz internets.

curl ifconfig.me

MX ieraksti

Kur nonāk domēna e-pasts.

dig domena.lv MX

Porta pārbaude

Vai konkrēts ports sasniedzams (piem., SMTP).

telnet domena.lv 25

Drošība

Core integritāte

Salīdzina failus ar oficiālo WordPress.

wp core verify-checksums

Nesen mainīti faili

Bieža pirmā pazīme, ka vietne uzlauzta.

find . -name "*.php" -mtime -7

Aizdomīgs kods

Bieži izmantots ļaunprātīga koda paraugs.

grep -rl "eval(base64_decode" wp-content/

Logi

WordPress debug log

Reāllaika kļūdu pārraudzība.

tail -f wp-content/debug.log

Ieslēdz debug logu

wp-config.php konstantes.

define('WP_DEBUG', true);
define('WP_DEBUG_LOG', true);

Pārsūtīšana

scp uz serveri

Vienkārša kopēšana caur SSH.

scp fails.zip lietotajs@serveris.lv:/celjs/

rsync

Kopē tikai mainītos failus - ātrāk regulāram deploy.

rsync -avz ./mape/ lietotajs@serveris.lv:/celjs/
