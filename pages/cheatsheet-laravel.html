Sākums Laravel Cheatsheet

Laravel Cheatsheet

Ātrās uzziņas lapa - katrai kartiņai īss skaidrojums un komandas/koda fragments. Pilnus piemērus un paskaidrojumus skaties pilnajā Laravel dokumentācijā.

Artisan Routing Eloquent Migrations Blade Testēšana

Artisan

make:model -mf

Modelis + migrācija + factory vienā komandā.

php artisan make:model Post -mf

make:controller --resource

Controller ar visām 7 CRUD metodēm.

php artisan make:controller PostController --resource

make:request

Form Request validācijas klase.

php artisan make:request StorePostRequest

tinker

Interaktīva PHP konsole ar ielādētu Laravel kontekstu.

php artisan tinker

route:list

Visi reģistrētie maršruti.

php artisan route:list

serve

Iebūvēts dev serveris - der lokālai izstrādei.

php artisan serve

Routing

Route::get

Pamata GET maršruts ar closure.

Route::get('/x', fn () => 'Sveiki');

Route model binding

{post} automātiski atrod Post ierakstu.

Route::get('/posts/{post}', [PostController::class, 'show']);

Route::resource

Visi 7 CRUD maršruti vienā rindā.

Route::resource('posts', PostController::class);

Middleware grupa

Piemēro middleware vairākiem maršrutiem uzreiz.

Route::middleware('auth')->group(function () {
    Route::get('/dashboard', DashboardController::class);
});

Eloquent

Pamata CRUD

Create/read/update/delete bez SQL.

Post::create([...]);
Post::findOrFail(1);
$post->update([...]);
$post->delete();

belongsTo / hasMany

Attiecību abas puses.

public function user(): BelongsTo {
    return $this->belongsTo(User::class);
}

Novērš N+1

Ielādē attiecību VIENĀ papildu vaicājumā.

Post::with('user')->get();

where + paginate

Filtrēts, lapots saraksts.

Post::where('published', true)->paginate(10);

Migrations

migrate

Palaiž visas jaunās migrācijas.

php artisan migrate

migrate:fresh

Izdzēš VISU un veido no jauna - tikai izstrādei.

php artisan migrate:fresh

foreignId + constrained

Ārējā atslēga ar automātisku tabulas noteikšanu.

$table->foreignId('user_id')->constrained()->cascadeOnDelete();

Blade

@extends / @section

Layout mantošana.

@extends('layouts.app')
@section('content') ... @endsection

@forelse

Cikls ar iebūvētu "tukšs saraksts" gadījumu.

@forelse ($posts as $post)
    {{ $post->title }}
@empty
    Nav rakstu.
@endforelse

Komponents ar slot

x-alert automātiski atrod components/alert.blade.php.

<x-alert type="success">Teksts</x-alert>

Testēšana

RefreshDatabase

Tīra datubāze katram testam.

use RefreshDatabase;

Feature tests pieprasījums

Reāls HTTP pieprasījums pret lietotni testā.

$this->getJson('/api/posts')->assertOk();

actingAs

Simulē pieteikušos lietotāju testā.

$this->actingAs($user)->postJson('/api/posts', [...]);

artisan test

Palaiž visu testu komplektu.

php artisan test
