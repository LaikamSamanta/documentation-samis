Sākums WordPress WooCommerce

WooCommerce pamati

WooCommerce ir spraudnis, kas pārvērš WordPress par e-komercijas platformu - tas NAV WordPress kodola daļa, tāpēc viss zemāk strādā tikai tad, ja spraudnis ir instalēts un aktivizēts. Šī lapa sedz praktiskos pamatus (produkti, hooks, grozs, pasūtījumi, pielāgošana) - pilnu API skaties oficiālajā WooCommerce izstrādātāju dokumentācijā.

Pārskats

WooCommerce reģistrē savu pielāgoto ieraksta tipu (Custom Post Type) product - tāpēc produkti pamatā ir WordPress ieraksti ar papildu datiem (cena, krājums, attēli) un savu WC_Product objektu klasi virs tiem. Tas nozīmē - viss, ko jau zini par Custom Post Types un WP_Query, attiecas arī uz produktiem, plus WooCommerce pievieno savu papildu hooks sistēmu virs WordPress standarta add_action/add_filter.

product

CPT, ar ko glabā katru produktu - pamatā tas pats, kas parasts ieraksts, plus WooCommerce papildu meta lauki (cena, SKU, krājums).

WC_Product

PHP klase, kas apvieno visus produkta datus vienā objektā ar ērtām metodēm (get_price(), get_name()) - nevis jāvelk katrs meta lauks atsevišķi.

WC()

Globāla funkcija, kas atgriež galveno WooCommerce objektu - caur to piekļūst grozam (WC()->cart), sesijai un citām aktīvās apmeklējuma daļām.

Vietējai izstrādei WooCommerce hooks/funkcijas var izsaukt tikai, kad spraudnis ir aktīvs - der pārbaudīt ar if (class_exists('WooCommerce')), ja kods jāizmanto arī vietnēs bez WooCommerce.

Produktu iegūšana

Vienam produktam - wc_get_product(), vairākiem (sarakstam/arhīvam) - parasts WP_Query ar post_type => 'product'.

php// Viens konkrēts produkts pēc ID
$produkts = wc_get_product( 123 );

if ( $produkts ) {
    echo $produkts->get_name();
    echo $produkts->get_price_html(); // formatēta cena ar valūtu
}

// Saraksts - 12 jaunākie publicētie produkti
$vaicajums = new WP_Query([
    'post_type'      => 'product',
    'posts_per_page' => 12,
]);

while ( $vaicajums->have_posts() ) : $vaicajums->the_post();
    $p = wc_get_product( get_the_ID() );
    echo $p->get_name();
endwhile;
wp_reset_postdata();

get_price() vs get_price_html()

get_price() atgriež jēlu skaitli (der aprēķiniem), get_price_html() atgriež gatavu, formatētu HTML ar valūtas simbolu un, ja piemērojams, arī atsvītrotu vecu cenu (izpārdošanai).

get_stock_quantity() / is_in_stock()

Krājuma daudzums un vienkāršs true/false, vai produkts pašlaik pērkams.

Galvenie hooks

WooCommerce veidnes ir pilnas ar saviem do_action() izsaukumiem - tie ļauj pievienot/noņemt saturu produktu un norēķinu lapās, negrozot pašus veidņu failus.

php// Parāda pielāgotu tekstu virs produkta pievienot-grozam pogas
add_action( 'woocommerce_before_add_to_cart_button', function () {
    echo '<p>Bezmaksas piegāde pasūtījumiem virs 50€</p>';
});

// Izpilda kodu, kad pasūtījuma statuss mainās (piem., apmaksāts)
add_action( 'woocommerce_order_status_changed', function ( $order_id, $vecais, $jaunais ) {
    if ( 'completed' === $jaunais ) {
        // piem., piešķir piekļuvi digitālam produktam
    }
}, 10, 3 );

// Izpilda kodu "paldies" lapā uzreiz pēc veiksmīga pasūtījuma
add_action( 'woocommerce_thankyou', function ( $order_id ) {
    // piem., nosūta papildu paziņojumu
});

woocommerce_before/after_single_product_summary

Ietver visu produkta lapas labo pusi (nosaukums, cena, poga) - der, lai pievienotu saturu tieši pirms/pēc tā.

woocommerce_before_shop_loop_item

Izsaukts pirms katra produkta kartītes veikala/kategorijas sarakstā - der iezīmēm ("Jauns", "Izpārdošana") virs attēla.

woocommerce_order_status_changed

Trīs argumenti: pasūtījuma ID, vecais statuss, jaunais statuss. Biežākie statusi: pending, processing, completed, cancelled, refunded.

Grozs (Cart)

Aktīvā apmeklētāja grozs ir pieejams caur WC()->cart jebkurā vietā, kur WooCommerce ir ielādēts.

php// Cik produktu grozā kopā
$skaits = WC()->cart->get_cart_contents_count();

// Groza kopsumma (ar formatējumu)
echo WC()->cart->get_cart_total();

// Iziet cauri katrai groza rindai
foreach ( WC()->cart->get_cart() as $rinda ) {
    $produkts = $rinda['data']; // WC_Product objekts
    $daudzums = $rinda['quantity'];
}

Pasūtījumi (Orders)

Pasūtījums arī ir pielāgots ieraksta tips (shop_order) ar savu WC_Order objektu - iegūst ar wc_get_order().

php$pasutijums = wc_get_order( $order_id );

echo $pasutijums->get_total();          // kopsumma
echo $pasutijums->get_status();         // piem., "processing"
echo $pasutijums->get_billing_email();

// Katra pasūtītā produkta rinda
foreach ( $pasutijums->get_items() as $vieniba ) {
    echo $vieniba->get_name();
    echo $vieniba->get_quantity();
}

Pielāgoti produktu lauki

Lai admin panelī produkta rediģēšanas lapā (cilnē "General") pievienotu savu lauku un saglabātu to - divi hooks kopā: viens izvada HTML lauku, otrs to saglabā.

php// 1. Izvada jaunu lauku "Ražotāja kods" produkta datu cilnē
add_action( 'woocommerce_product_options_general_product_data', function () {
    woocommerce_wp_text_input([
        'id'          => 'razotaja_kods',
        'label'       => 'Ražotāja kods',
        'desc_tip'    => true,
        'description' => 'Iekšējais ražotāja identifikators.',
    ]);
});

// 2. Saglabā ievadīto vērtību, kad produktu saglabā
add_action( 'woocommerce_process_product_meta', function ( $product_id ) {
    if ( isset( $_POST['razotaja_kods'] ) ) {
        update_post_meta(
            $product_id,
            'razotaja_kods',
            sanitize_text_field( $_POST['razotaja_kods'] )
        );
    }
});

Nolasīšana pēc tam - parasts get_post_meta(), tāpat kā jebkuram citam pielāgotam laukam (skat. Pielāgoti lauki):

php$kods = get_post_meta( $product_id, 'razotaja_kods', true );

Biežas pielāgošanas

php// Maina "Pievienot grozam" pogas tekstu produkta lapā
add_filter( 'woocommerce_product_single_add_to_cart_text', function () {
    return 'Pasūtīt tagad';
});

// Noņem cilni "Papildu informācija" no visiem produktiem
add_filter( 'woocommerce_product_tabs', function ( $cilnes ) {
    unset( $cilnes['additional_information'] );
    return $cilnes;
});

// Pievieno pielāgotu tekstu aiz katras cenas
add_filter( 'woocommerce_get_price_html', function ( $cena_html ) {
    return $cena_html . ' <small>ar PVN</small>';
});

woocommerce_get_price_html filtrs izpildās katrai produkta kartītei sarakstos (ne tikai produkta lapā) - ja pievieno kaut ko smagu (piem., datubāzes vaicājumu), tas atkārtosies katram produktam sarakstā un var palēnināt lapu.

Veidņu pārrakstīšana

WooCommerce izvada HTML no saviem veidņu failiem (wp-content/plugins/woocommerce/templates/). Lai pielāgotu izkārtojumu bez spraudņa failu rediģēšanas (kas pazustu pie nākamā atjauninājuma) - nokopē konkrēto failu uz tēmas woocommerce/ mapi, saglabājot to pašu ceļu struktūru. WooCommerce vispirms meklē failu tēmā un tikai tad krīt atpakaļ uz spraudņa oriģinālu.

bash# Piemērs - pārraksta vienas preces lapas veidni
# No:
wp-content/plugins/woocommerce/templates/single-product.php
# Uz:
wp-content/themes/tava-tema/woocommerce/single-product.php

Pēc katra WooCommerce atjauninājuma admin panelī (Statuss → Sistēmas statuss) parādās brīdinājums, ja pārrakstītā veidne ir "novecojusi" salīdzinājumā ar jauno spraudņa versiju - der pārbaudīt, vai jaunajā oriģinālā nav svarīgu izmaiņu, ko manuāli pārnest uz savu kopiju.
