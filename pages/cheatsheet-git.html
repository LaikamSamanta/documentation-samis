Sākums Git Cheatsheet

Git Cheatsheet

Ātrās uzziņas lapa - katrai kartiņai īss skaidrojums un komandas fragments. Pilnus piemērus un paskaidrojumus skaties pilnajā Git dokumentācijā.

Pamati Vēsture Zari Merge & konflikti Remotes SSH .gitignore Atsaukšana stash

Pamati

git init

Sāk jaunu, tukšu repozitoriju pašreizējā mapē.

git init

git clone

Lejupielādē esošu repozitoriju ar visu vēsturi.

git clone url

git status

Rāda, kuri faili mainīti, jauni vai gatavi commit'am.

git status

git add

Sagatavo failus nākamajam commit - konkrētu vai visus.

git add fails.txt
git add .

git commit

Saglabā sagatavotās izmaiņas kā jaunu momentuzņēmumu.

git commit -m "Ziņojums"

git config

Iestata autora vārdu/e-pastu, kas parādās pie commit'iem.

git config --global user.name "Vārds"

Vēsture

git log

Visu commit'u saraksts, jaunākais augšā.

git log --oneline

git diff

Kas mainījies kopš pēdējā commit, bet vēl nav sagatavots.

git diff

git show

Kas tieši mainījās konkrētā commit.

git show a1b2c3d

Zari

git branch

Parāda visus zarus / izveido jaunu.

git branch
git branch jauns-zars

git switch -c

Izveido zaru UN uzreiz pārslēdzas uz to.

git switch -c jauns-zars

git branch -d

Izdzēš zaru (droši, tikai ja jau apvienots).

git branch -d vecs-zars

Merge & konflikti

git merge

Apvieno otra zara izmaiņas pašreizējā zarā.

git checkout main
git merge jauns-zars

Konflikta atzīmes

<<<<<<< tava versija, ======= dalītājs, >>>>>>> otra versija.

git merge --abort

Atceļ visu merge mēģinājumu, atgriežot stāvokli pirms tā.

git merge --abort

git rebase

Pārliek commit'us uz jaunākās main versijas - lineāra vēsture. Nekad jau push'otiem zariem.

git rebase main

Remotes

git push

Nosūta lokālos commit'us uz remote.

git push origin main

git pull

fetch + merge vienā komandā - lejupielādē un apvieno.

git pull

git fetch

Tikai lejupielādē info, neko neapvieno.

git fetch

git remote add

Pievieno remote saiti esošam lokālam repo.

git remote add origin url

SSH GitHub autentifikācijai

Ģenerē atslēgu

Modernais, ieteicamais tips.

ssh-keygen -t ed25519 -C "e@pasts.lv"

Pārbauda savienojumu

Apstiprina, ka GitHub atpazīst tavu atslēgu.

ssh -T git@github.com

Klonē ar SSH

git@ adrese, ne https:// - autentifikācija automātiska.

git clone git@github.com:u/repo.git

.gitignore

Tipisks saturs

Ģenerēti faili un atkarības, kam nav vietas versiju kontrolē.

node_modules/
.env
*.log

git rm --cached

Izņem jau izsekotu failu no izsekošanas (bet ne no vēstures).

git rm --cached fails

Atsaukšana

git restore

Atceļ nesaglabātas izmaiņas failā.

git restore fails.txt

git reset --soft

Atceļ pēdējo commit, izmaiņas paliek sagatavotas.

git reset --soft HEAD~1

git reset --hard

Neatgriezeniski dzēš pēdējo commit un tā izmaiņas.

git reset --hard HEAD~1

git revert

Izveido jaunu commit, kas atceļ norādīto - droši jau push'otam kodam.

git revert a1b2c3d

git stash

git stash

Īslaicīgi noliek nesaglabātās izmaiņas plauktā.

git stash

git stash pop

Atgriež pēdējās noliktās izmaiņas atpakaļ.

git stash pop
