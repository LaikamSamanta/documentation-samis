Sākums JavaScript Cheatsheet

JavaScript Cheatsheet

Blīva ātrās uzziņas lapa — sintakse bez garajiem skaidrojumiem. Pilnus piemērus un paskaidrojumus skaties pilnajā JavaScript dokumentācijā.

Mainīgie & tipi Operatori Vadības struktūras Funkcijas Masīvi Objekti Teksti Klases Async DOM Kļūdas Citas noderīgas

Mainīgie & tipi

let / const

Mainīgs / nemainīgs

let a = 1; const b = 2;

typeof

Vērtības tips

typeof "x" // "string"

Template literal

Teksts ar mainīgajiem

`Sveiks, ${vards}!`

Tipi

Pamata datu tipi

string, number, boolean,
null, undefined, object, array

Array.isArray()

Vai masīvs

Array.isArray([1,2]) // true

Number() / String()

Tipa konvertācija

Number("5") // 5
String(5) // "5"

Operatori

===

Stingra salīdzināšana (vienmēr šo)

"5" === 5 // false

??

Tikai null/undefined

0 ?? "def" // 0

?.

Optional chaining

obj?.adrese?.pilseta

...spread

Izklāj masīvu/objektu

[...arr, 4]
{...obj, x: 1}

...rest

Savāc argumentus

function f(...args) {}

Ternārais

Īss if/else

vecums >= 18 ? "jā" : "nē"

&&= / ||= / ??=

Piešķiršana ar nosacījumu

x ??= "noklusējums";

Vadības struktūras

if / else if / else

if (a) {} else if (b) {} else {}

switch

switch (x) {
  case 1: break;
  default: break;
}

for

for (let i = 0; i < 5; i++) {}

for...of

Masīva vērtības

for (const x of arr) {}

for...in

Objekta atslēgas

for (const k in obj) {}

while / do...while

while (x < 5) { x++; }

Funkcijas

function

function f(a, b) { return a + b; }

Arrow function

Nesaista savu this

const f = (a, b) => a + b;

Noklusējuma parametrs

function f(x = 10) {}

Destrukturēšana parametros

function f({ vards, vecums }) {}

Masīvi

.map()

Pārveido katru

arr.map(n => n * 2)

.filter()

Atlasa atbilstošos

arr.filter(n => n > 0)

.reduce()

Sasummē vienā vērtībā

arr.reduce((a,b) => a+b, 0)

.find()

Pirmais atbilstošais

arr.find(n => n > 5)

.some() / .every()

Vismaz viens / visi

arr.some(n => n > 5)

.includes()

Vai satur vērtību

arr.includes(3) // true

.sort()

Kārto (mutē oriģinālu!)

arr.sort((a,b) => a - b)

.slice() / .splice()

Izgriež daļu / maina oriģinālu

arr.slice(1, 3)

push/pop/shift/unshift

Pievieno/noņem galos

arr.push(4); arr.pop();

.join() / .flat()

Par tekstu / izlīdzina

arr.join(", ")

Objekti

Destrukturēšana

const { vards, epasts = "nav" } = obj;

Object.keys/values/entries

Object.keys(obj)
Object.entries(obj)

Object.assign()

Sapludina objektus

Object.assign({}, a, b)

Property shorthand

const obj = { vards, vecums };

Teksti

.split() / .trim()

"a,b".split(",")
" x ".trim()

.replace()

"abc".replace("a", "x")

.includes/startsWith/endsWith

"abc".startsWith("a")

.slice() / .padStart()

"abc".slice(0, 2)
"5".padStart(2, "0")

.toUpperCase/LowerCase()

"abc".toUpperCase()

Klases

class

class Lietotajs {
  constructor(v) { this.vards = v; }
}

extends / super

Mantojums

class Admins extends Lietotajs {
  constructor(v) { super(v); }
}

static

Metode uz klases, ne objekta

static create() { return new this(); }

get / set

Getteri/setteri

get pilnsVards() { return this.v; }

Async

async / await

async function f() {
  const r = await fetch(url);
}

Promise

new Promise((resolve, reject) => {});

Promise.all()

Vairāki paralēli

await Promise.all([p1, p2]);

try/catch ar await

try { await f(); } catch (e) {}

DOM

querySelector()

document.querySelector(".klase")

addEventListener()

el.addEventListener("click", fn);

classList

el.classList.toggle("aktivs");

textContent / innerHTML

el.textContent = "teksts";

createElement / appendChild

const d = document.createElement("div");
parent.appendChild(d);

Kļūdu apstrāde

try/catch/finally

try {} catch (e) {} finally {}

throw

throw new Error("kļūda");

Citas noderīgas

JSON.stringify/parse

JSON.stringify(obj)
JSON.parse(teksts)

localStorage

localStorage.setItem("k", "v");
localStorage.getItem("k");

setTimeout / setInterval

setTimeout(fn, 1000);
clearInterval(id);

import / export

export function f() {}
import { f } from "./f.js";
