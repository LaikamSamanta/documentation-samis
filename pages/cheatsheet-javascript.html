JavaScript Cheatsheet

Ātrās uzziņas lapa — katrai kartiņai īss skaidrojums, ko tā dara un kam domāta, plus sintakses fragments. Pilnus piemērus un paskaidrojumus skaties pilnajā JavaScript dokumentācijā.

Mainīgie & tipi

let / const

let deklarē mainīgu, kuru vēlāk var pārrakstīt; const deklarē nemainīgu — vērtību nevar piešķirt no jauna (bet objekta/masīva saturu joprojām var mainīt).

let a = 1; const b = 2;

typeof

Atgriež mainīgā tipu kā tekstu (piem. "string", "number") — noder pārbaudīt, ar ko strādā, pirms to izmanto.

typeof "x" // "string"

Template literal

Ar atpakaļvērstajām pēdiņām veidots teksts, kur ${} iekšpusē var tieši ievietot mainīgos, bez teksta savienošanas ar +.

`Sveiks, ${vards}!`

Tipi

JavaScript pamata (primitīvie) datu tipi — visi, izņemot object un array, ir nemainīgi paši par sevi.

string, number, boolean,
null, undefined, object, array

Array.isArray()

Pārbauda, vai vērtība ir masīvs — typeof masīvam maldīgi atgriež "object", tāpēc masīviem jālieto tieši šī funkcija.

Array.isArray([1,2]) // true

Number() / String()

Piespiedu kārtā pārvērš vērtību par skaitli vai tekstu — noder, piem., kad no HTML formas ienāk teksts, bet vajag ar to rēķināt.

Number("5") // 5
String(5) // "5"

Operatori

===

Salīdzina gan vērtību, gan tipu, bez automātiskas konvertācijas — vienmēr lieto šo, nevis ==, kas var dot negaidītus rezultātus.

"5" === 5 // false

??

Atgriež labo pusi tikai tad, ja kreisā ir tieši null vai undefined — atšķirībā no ||, neaizvieto arī 0, "" vai false.

0 ?? "def" // 0

?.

Droši piekļūst iegultai īpašībai — ja jebkura daļa ceļā ir null/undefined, izteiksme atgriež undefined, nevis met kļūdu.

obj?.adrese?.pilseta

...spread

Izklāj (izpleš) masīva vai objekta saturu atsevišķos elementos — noder kopēšanai vai apvienošanai, neietekmējot oriģinālu.

[...arr, 4]
{...obj, x: 1}

...rest

Savāc visus atlikušos, nenosauktos argumentus vienā masīvā funkcijas iekšpusē.

function f(...args) {}

Ternārais

Īsāks veids if/else izteiksmei, kas atgriež vērtību — noder, kad ātri jāizvēlas starp divām vērtībām.

vecums >= 18 ? "jā" : "nē"

&&= / ||= / ??=

Piešķir jaunu vērtību mainīgajam tikai tad, ja izpildās attiecīgais nosacījums — īsāka forma nekā x = x ?? "y".

x ??= "noklusējums";

Vadības struktūras

if / else if / else

Pamata sazarošanās — izpilda atšķirīgu koda bloku atkarībā no nosacījuma patiesumvērtības.

if (a) {} else if (b) {} else {}

switch

Alternatīva vairākiem if/else if, kad viena vērtība jāsalīdzina ar daudzām iespējamām — break apstādina "izkrišanu" uz nākamo case.

switch (x) {
  case 1: break;
  default: break;
}

for

Klasiskais cikls ar zināmu iterāciju skaitu — noder, kad jāzina precīzs indekss katrā solī.

for (let i = 0; i < 5; i++) {}

for...of

Iziet cauri masīva (vai citas iterējamas kolekcijas) vērtībām tieši, bez indeksa.

for (const x of arr) {}

for...in

Iziet cauri objekta atslēgu (īpašību) nosaukumiem — masīviem parasti labāk lietot for...of vai .forEach().

for (const k in obj) {}

while / do...while

Cikls, kas turpinās, kamēr nosacījums ir patiess — do...while vienmēr izpilda ķermeni vismaz vienreiz, pat ja nosacījums uzreiz nepatiess.

while (x < 5) { x++; }

Funkcijas

function

Klasiska funkcijas deklarācija — pieejama pat pirms tās definīcijas vietas kodā ("hoisting").

function f(a, b) { return a + b; }

Arrow function

Īsāka sintakse funkcijai, kas nesaista savu this — this iekšpusē nozīmē to pašu, ko ārpusē, kas noder callback funkcijās.

const f = (a, b) => a + b;

Noklusējuma parametrs

Piešķir vērtību parametram, ja izsaucot funkciju tas netiek nodots (vai nodots kā undefined).

function f(x = 10) {}

Destrukturēšana parametros

Tieši funkcijas parametros izvelk konkrētas objekta īpašības — noder, kad funkcijai nodod vienu opciju objektu.

function f({ vards, vecums }) {}

Masīvi

.map()

Izveido JAUNU masīvu, katru elementu pārveidojot ar norādīto funkciju — oriģinālais masīvs netiek mainīts.

arr.map(n => n * 2)

.filter()

Izveido jaunu masīvu tikai ar elementiem, kas iztur nosacījumu — noder atlasei pēc kritērija.

arr.filter(n => n > 0)

.reduce()

Sareducē visu masīvu vienā vērtībā (summa, vidējais u.c.), izpildot funkciju secīgi katram elementam.

arr.reduce((a,b) => a+b, 0)

.find()

Atgriež pirmo elementu, kas atbilst nosacījumam, vai undefined, ja neviens neatbilst.

arr.find(n => n > 5)

.some() / .every()

some() pārbauda, vai vismaz viens elements atbilst nosacījumam; every() — vai visi elementi atbilst.

arr.some(n => n > 5)

.includes()

Vienkārša pārbaude, vai masīvs satur konkrētu vērtību — atgriež true/false.

arr.includes(3) // true

.sort()

Sakārto masīvu — uzmanību: maina oriģinālo masīvu, nevis atgriež jaunu. Bez salīdzināšanas funkcijas kārto kā tekstu, kas skaitļiem var dot negaidītus rezultātus.

arr.sort((a,b) => a - b)

.slice() / .splice()

slice() atgriež jaunu masīva daļu, neko nemainot; splice() izgriež/ievieto elementus tieši oriģinālajā masīvā.

arr.slice(1, 3)

push/pop/shift/unshift

Pievieno/noņem elementus masīva galos — push/pop strādā ar beigām, shift/unshift ar sākumu. Visi maina oriģinālo masīvu.

arr.push(4); arr.pop();

.join() / .flat()

join() pārvērš masīvu par tekstu ar norādīto atdalītāju; flat() izlīdzina ligzdotus masīvus vienā līmenī.

arr.join(", ")

Objekti

Destrukturēšana

Izvelk konkrētas īpašības no objekta atsevišķos mainīgajos vienā rindā — var uzreiz norādīt arī noklusējuma vērtību.

const { vards, epasts = "nav" } = obj;

Object.keys/values/entries

Atgriež objekta atslēgas, vērtības vai [atslēga, vērtība] pārus kā masīvu — noder objekta apstrādei ciklā.

Object.keys(obj)
Object.entries(obj)

Object.assign()

Sapludina vairāku objektu īpašības vienā jaunā objektā — vēlāk pievienotie objekti pārraksta agrāko vērtības.

Object.assign({}, a, b)

Property shorthand

Ja mainīgā nosaukums sakrīt ar vēlamo objekta atslēgu, var izlaist atkārtošanu — { vards } nozīmē { vards: vards }.

const obj = { vards, vecums };

Teksti

.split() / .trim()

split() sadala tekstu masīvā pēc norādītā atdalītāja; trim() noņem liekās atstarpes teksta sākumā/beigās.

"a,b".split(",")
" x ".trim()

.replace()

Aizvieto pirmo sakritību ar jaunu tekstu — visu sakritību aizvietošanai izmanto regulāru izteiksmi ar "g" karodziņu.

"abc".replace("a", "x")

.includes/startsWith/endsWith

Pārbauda, vai teksts satur/sākas/beidzas ar norādīto apakštekstu — atgriež true/false.

"abc".startsWith("a")

.slice() / .padStart()

slice() izgriež teksta daļu pēc indeksiem; padStart() papildina tekstu no kreisās puses līdz vēlamajam garumam (piem., "05" formātam).

"abc".slice(0, 2)
"5".padStart(2, "0")

.toUpperCase/LowerCase()

Pārvērš tekstu par lielajiem/mazajiem burtiem — noder salīdzināšanai bez reģistrjutības.

"abc".toUpperCase()

Klases

class

Veidne objektu izveidei ar kopīgu struktūru — constructor izpildās automātiski, kad izveido jaunu instanci ar new.

class Lietotajs {
  constructor(v) { this.vards = v; }
}

extends / super

extends izveido mantojumu no citas klases; super(v) izsauc vecākklases konstruktoru — obligāti pirms this lietošanas bērnu klasē.

class Admins extends Lietotajs {
  constructor(v) { super(v); }
}

static

Metode, kas pieder pašai klasei, nevis atsevišķai instancei — izsauc caur klases nosaukumu, nevis izveidotu objektu.

static create() { return new this(); }

get / set

get definē "virtuālu" īpašību, kas aprēķinās katru reizi, kad to nolasa; set — funkciju, kas izpildās, kad īpašībai piešķir vērtību.

get pilnsVards() { return this.v; }

Async

async / await

async pirms funkcijas ļauj tās iekšpusē lietot await, kas "pagaida" Promise atrisināšanos, nebloķējot pārējo lapu.

async function f() {
  const r = await fetch(url);
}

Promise

Objekts, kas apzīmē vēl nezināmu, nākotnē pienākošu rezultātu — resolve/reject nosaka, vai tas beidzas veiksmīgi vai ar kļūdu.

new Promise((resolve, reject) => {});

Promise.all()

Gaida, kamēr visi nodotie Promise atrisinās paralēli — ātrāk nekā gaidīt katru pēc kārtas ar atsevišķiem await.

await Promise.all([p1, p2]);

try/catch ar await

Ja await gaidītais Promise noraidās, tas izmet kļūdu, ko var noķert ar try/catch — tāpat kā sinhronā kodā.

try { await f(); } catch (e) {}

DOM

querySelector()

Atrod pirmo HTML elementu, kas atbilst CSS selektoram — atgriež null, ja nekas nav atrasts.

document.querySelector(".klase")

addEventListener()

Pieskaita funkciju, kas izpildīsies, kad uz elementa notiek norādītais notikums (klikšķis, ievade u.c.).

el.addEventListener("click", fn);

classList

Ļauj pievienot/noņemt/pārslēgt CSS klases elementam bez manuālas teksta manipulācijas ar className.

el.classList.toggle("aktivs");

textContent / innerHTML

textContent iestata/nolasa tikai tekstu (droši); innerHTML iestata/nolasa HTML kodu — uzmanīgi ar lietotāja ievadi (XSS risks).

el.textContent = "teksts";

createElement / appendChild

createElement izveido jaunu, vēl neredzamu HTML elementu; appendChild pievieno to kā bērnu esošam elementam lapā.

const d = document.createElement("div");
parent.appendChild(d);

Kļūdu apstrāde

try/catch/finally

try satur kodu, kas var izmest kļūdu; catch to noķer un apstrādā; finally izpildās vienmēr, neatkarīgi no tā, vai kļūda bija.

try {} catch (e) {} finally {}

throw

Apzināti izmet (rada) kļūdu — apstādina tālāko koda izpildi, ja vien to neaptver try/catch.

throw new Error("kļūda");

Citas noderīgas

JSON.stringify/parse

stringify() pārvērš JS objektu par tekstu (saglabāšanai/nosūtīšanai); parse() dara pretējo — tekstu pārvērš atpakaļ par objektu.

JSON.stringify(obj)
JSON.parse(teksts)

localStorage

Saglabā datus pārlūkā starp lapas atsvaidzināšanas reizēm un pat pēc pārlūka aizvēršanas — dati paliek, kamēr tos manuāli neizdzēš.

localStorage.setItem("k", "v");
localStorage.getItem("k");

setTimeout / setInterval

setTimeout izpilda funkciju vienreiz pēc norādītā laika; setInterval atkārto to ik pēc intervāla, kamēr to neaptur ar clearInterval.

setTimeout(fn, 1000);
clearInterval(id);

import / export

ES modulu sintakse koda sadalīšanai vairākos failos — export padara funkciju/mainīgo pieejamu citiem failiem, import to ielādē.

export function f() {}
import { f } from "./f.js";
