JavaScript

Ievads JavaScript

JavaScript ir programmēšanas valoda, kas ļauj tīmekļa lapām būt interaktīvām - bez tās vietne var tikai parādīt statisku tekstu un attēlus, bet ar JS tā var reaģēt uz klikšķiem, ielādēt datus bez lapas pārlādēšanas, validēt formas un daudz ko citu. JavaScript darbojas divās vietās: pārlūkā (katrā mūsdienu pārlūkā tā jau ir iebūvēta) un serverī caur Node.js vidi.

Valoda ir dinamiski tipizēta - mainīgajam nav jānorāda tips iepriekš, tas tiek noteikts automātiski pēc piešķirtās vērtības.

Kā palaist savu pirmo JS kodu (izvēlies vienu no diviem):

text1. Ātrākais veids - pārlūka konsole:
   Atver jebkuru vietni → nospied F12 (vai Ctrl+Shift+J Chrome) →
   cilnē "Console" ieraksti kodu un spied Enter.

2. HTML failā - saglabā šo kā mans-fails.html un atver pārlūkā:
html<!doctype html>
<html>
<body>
  <h1 id="virsraksts">Sveiki!</h1>

  <script>
    console.log("JavaScript strādā!");
    document.getElementById("virsraksts").textContent = "JS to uzrakstīja!";
  </script>
</body>
</html>

Visi šīs lapas piemēri ir uzrakstīti tā, lai tos varētu iekopēt tieši pārlūka konsolē un tie uzreiz strādātu - nav jāpievieno nekādi papildu mainīgie no citām sadaļām.

Mainīgie & tipi

Mainīgo veido ar let (vērtību var mainīt vēlāk) vai const (vērtību pēc piešķiršanas vairs nemainīs). Veco var mūsdienās neizmanto - tam ir savādāka un mulsinoša darbības joma (scope), kas var izraisīt grūti atrodamas kļūdas.

JavaScript ir vairāki pamata datu tipi: string (teksts), number (skaitlis), boolean (true/false), null un undefined (tukšas vērtības), kā arī salikti tipi object un array.

jsconst vards = "Anna";      // string - nemainīgs
let vecums = 25;               // number - mainīgs
let aktivs = true;             // boolean
let adrese = null;             // apzināti tukšs

const lietotajs = {              // object - atslēga: vērtība
  vards: vards,
  vecums: vecums,
};

const skaitli = [1, 2, 3];       // array - sarakstots

console.log(typeof vards);     // "string"
console.log(lietotajs);          // { vards: "Anna", vecums: 25 }

const nenozīmē "pilnīgi nemaināms" objektam/masīvam - tas nozīmē, ka mainīgais vienmēr norādīs uz to pašu objektu, bet paša objekta īpašības tomēr var mainīt (lietotajs.vecums = 26 strādās).

Nosacījumi (if/else)

Nosacījumi ļauj kodam pieņemt lēmumus - izpildīt vienu bloku, ja nosacījums ir true, citu, ja false. Salīdzinot vērtības, vienmēr izmanto === (stingra salīdzināšana, pārbauda arī tipu), nevis ==, kas mēģina tipus automātiski konvertēt un var dot negaidītus rezultātus ("5" == 5 ir true, bet "5" === 5 ir false).

jsconst vecums = 16;

if (vecums >= 18) {
  console.log("Pieaugušais");
} else if (vecums >= 13) {
  console.log("Pusaudzis");
} else {
  console.log("Bērns");
}
// izvads: "Pusaudzis"

// Īsākais variants sarežģītam if/else - ternārais operators
const statuss = vecums >= 18 ? "pieaugušais" : "nepilngadīgais";
console.log(statuss); // "nepilngadīgais"

Cikli (for/while)

Cikli izpilda kodu atkārtoti. for der, kad zini, cik reižu jāatkārto; for...of der, lai izietu cauri masīva elementiem; while der, kad atkārto, kamēr nosacījums ir patiess (nezinot iepriekš, cik reižu).

js// Klasiskais for - no 0 līdz 4
for (let i = 0; i < 5; i++) {
  console.log(i);
}

// for...of - iziet cauri masīva vērtībām
const lietotaji = ["Anna", "Kārlis", "Līga"];
for (const lietotajs of lietotaji) {
  console.log(lietotajs);
}

// while - atkārto, kamēr nosacījums patiess
let mesginajumi = 0;
while (mesginajumi < 3) {
  console.log("Mēģinājums Nr." + (mesginajumi + 1));
  mesginajumi++;
}

while ciklā vienmēr pārliecinies, ka mainīgais nosacījumā (piem., mesginajumi++) tiešām mainās - pretējā gadījumā cikls turpināsies mūžīgi un iesaldēs pārlūka cilni.

Funkcijas

Funkcija ir koda bloks, ko var izsaukt atkārtoti ar dažādiem ievaddatiem (parametriem). JavaScript ir vairāki veidi, kā tās uzrakstīt - biežāk lieto klasisko function deklarāciju un īsāko arrow funkciju (=>). Galvenā atšķirība: arrow funkcijas nesaista savu this vērtību - tās manto to no ietverošā konteksta, kas ir īpaši noderīgi callback funkcijās (piem., forEach iekšienē).

js// Klasiska funkcijas deklarācija
function saskaitit(a, b) {
  return a + b;
}

// Arrow funkcija - īsāks pieraksts
const reizinat = (a, b) => a * b;

console.log(saskaitit(2, 3));  // 5
console.log(reizinat(2, 3));    // 6

// Funkcijas ar noklusējuma vērtību parametram
function sveiciens(vards = "Viesi") {
  return `Sveiki, ${vards}!`;
}
console.log(sveiciens());        // "Sveiki, Viesi!"
console.log(sveiciens("Anna")); // "Sveiki, Anna!"

Masīvu metodes

Masīviem ir iebūvētas metodes, kas ļauj tos apstrādāt bez manuāla cikla rakstīšanas. Trīs visbiežāk lietotās - visas atgriež jaunu masīvu, nemainot oriģinālu:

  • map() - pārveido katru elementu un atgriež jaunu masīvu ar tādu pašu garumu.
  • filter() - atstāj tikai elementus, kas iztur pārbaudi.
  • reduce() - "sasummē" visu masīvu vienā vērtībā.
jsconst skaitli = [1, 2, 3, 4, 5];

const dubulti = skaitli.map(n => n * 2);
console.log(dubulti); // [2, 4, 6, 8, 10]

const parie = skaitli.filter(n => n % 2 === 0);
console.log(parie); // [2, 4]

const summa = skaitli.reduce((kopa, n) => kopa + n, 0);
console.log(summa); // 15

// Var arī sasaistīt vairākas metodes ķēdē
const pariodubulti = skaitli.filter(n => n % 2 === 0).map(n => n * 2);
console.log(pariodubulti); // [4, 8]

Klases

Klase ir "recepte" objektu veidošanai ar kopīgu struktūru un uzvedību. Tā ir sintaktiskais cukurs virs JavaScript prototipiskā mantojuma, bet izskatās pazīstamāk tiem, kas nāk no citām valodām (PHP, Java). constructor izpildās, kad ar new izveido jaunu instanci.

jsclass Lietotajs {
  constructor(vards, vecums) {
    this.vards = vards;
    this.vecums = vecums;
  }

  sveicies() {
    return `Sveiks, es esmu ${this.vards} un man ir ${this.vecums} gadi.`;
  }
}

const anna = new Lietotajs("Anna", 25);
console.log(anna.sveicies());
// "Sveiks, es esmu Anna un man ir 25 gadi."

// Klase var mantot no citas klases ar "extends"
class Administrators extends Lietotajs {
  sveicies() {
    return super.sveicies() + " Esmu administrators.";
  }
}
const peteris = new Administrators("Pēteris", 30);
console.log(peteris.sveicies());

Async/Await

Daudzas darbības (datu ielāde no interneta, faila lasīšana) aizņem laiku un nenotiek uzreiz - tās sauc par asinhronām. JavaScript tās apstrādā ar Promise objektiem, bet async/await ir sintaktiskais cukurs, kas ļauj asinhronu kodu rakstīt tā, it kā tas būtu parasts, secīgs kods - daudz vieglāk lasāms.

Zemāk piemērs, kas strādā uzreiz jebkurā konsolē bez interneta - simuletApiZvanu() ar setTimeout imitē lēnu tīkla pieprasījumu:

js// Simulē lēnu API pieprasījumu (imitē tīklu, strādā bez interneta)
function simuletApiZvanu() {
  return new Promise((resolve) => {
    setTimeout(() => resolve({ vards: "Anna", vecums: 25 }), 1000);
  });
}

async function iegutDatus() {
  console.log("Ielādē...");
  try {
    const dati = await simuletApiZvanu();
    console.log("Saņemts:", dati);
  } catch (kluda) {
    console.error("Kļūda:", kluda);
  }
}

iegutDatus();
// izvadā: "Ielādē..." uzreiz, tad pēc 1 sek: "Saņemts: {vards: 'Anna', vecums: 25}"

Reālā projektā biežākais lietojums ir dati no servera, izmantojot iebūvēto fetch():

jsasync function iegutLietotajus() {
  const atbilde = await fetch("https://jsonplaceholder.typicode.com/users");
  const dati = await atbilde.json();
  console.log(dati);
}
iegutLietotajus();

Otro piemēru vari iekopēt tieši pārlūka konsolē - jsonplaceholder.typicode.com ir publisks bezmaksas testa API, kas tieši šim nolūkam vienmēr atbild ar testa datiem.

Destrukturēšana

Destrukturēšana ļauj vienā rindā "izvilkt" vērtības no objekta vai masīva atsevišķos mainīgajos, nevis piekļūt katrai ar objekts.lauks atsevišķi.

jsconst lietotajs = { vards: "Anna", vecums: 25, pilseta: "Rīga" };

// Objekta destrukturēšana - nosaukumiem jāsakrīt ar lauku nosaukumiem
const { vards, epasts = "nav norādīts" } = lietotajs;
console.log(vards);  // "Anna"
console.log(epasts); // "nav norādīts" - jo objektā tāda lauka nav, izmanto noklusējumu

// Masīva destrukturēšana - pēc secības
const [pirmais, ...pareja] = [1, 2, 3, 4];
console.log(pirmais); // 1
console.log(pareja);   // [2, 3, 4]

// Bieži izmanto tieši funkcijas parametros
function parada({ vards, vecums }) {
  console.log(`${vards} ir ${vecums} gadus vecs`);
}
parada(lietotajs); // "Anna ir 25 gadus vecs"

?. un ??

Divi mazi, bet ārkārtīgi bieži lietoti operatori, kas pasargā no vienas no visbiežākajām JS kļūdām - Cannot read properties of undefined. Optional chaining (?.) pārtrauc piekļuvi un atgriež undefined, tiklīdz sastop null/undefined, nevis izmet kļūdu. Nullish coalescing (??) atgriež labo pusi tikai tad, ja kreisā ir tieši null vai undefined (atšķirībā no ||, kas nostrādā arī uz 0, "" vai false).

jsconst lietotajs = {
  vards: "Anna",
  adrese: {
    pilseta: "Rīga",
    // nav "valsts" lauka
  },
};

// Bez ?. - šī rinda izmestu kļūdu, ja "adrese" nebūtu definēta:
console.log(lietotajs.adrese?.valsts);        // undefined (bez kļūdas)
console.log(lietotajs.kontakti?.epasts);     // undefined - "kontakti" pat neeksistē

// Var kombinēt ar funkciju izsaukumu
const objekts = { saskaitit(a, b) { return a + b; } };
console.log(objekts.saskaitit?.(2, 3));       // 5
console.log(objekts.atnemt?.(5, 2));          // undefined - metode neeksistē, bez kļūdas

// ?? - noklusējuma vērtība TIKAI null/undefined gadījumā
const atlaide = 0;
console.log(atlaide || "nav atlaides");   // "nav atlaides" - || uzskata 0 par "tukšu"! (kļūda)
console.log(atlaide ?? "nav atlaides");   // 0 - ?? pareizi atpazīst, ka 0 ir derīga vērtība

Pēdējais piemērs parāda ļoti biežu kļūdu: ja vēlies noklusējuma vērtību tikai tad, kad dati patiešām nav norādīti (nevis kad tie ir 0, tukšs teksts vai false), vienmēr izmanto ??, nevis ||.

Spread & Rest (...)

Viena un tā pati sintakse (...) izmantojama diviem pretējiem mērķiem, atkarībā no konteksta: spread "izklāj" elementus (kopē masīvu/objektu vai apvieno vairākus), rest tos "savāc kopā" (piem., nezināmu skaitu funkcijas argumentu).

js// Spread - apvieno vai kopē masīvus
const pirmie = [1, 2, 3];
const visi = [...pirmie, 4, 5];
console.log(visi); // [1, 2, 3, 4, 5]

// Spread - kopē objektu un pārraksta vienu lauku
const lietotajs = { vards: "Anna", vecums: 25 };
const vecaksLietotajs = { ...lietotajs, vecums: 26 };
console.log(vecaksLietotajs); // { vards: "Anna", vecums: 26 }

// Rest - savāc atlikušos argumentus vienā masīvā
function summa(...skaitli) {
  return skaitli.reduce((a, b) => a + b, 0);
}
console.log(summa(1, 2, 3, 4)); // 10

Moduļi

Moduļi ļauj kodu sadalīt vairākos failos un koplietot funkcijas starp tiem ar export/import. Tas noder, lai kods nebūtu viens milzīgs fails un lai varētu atkārtoti izmantot vienu un to pašu funkciju vairākās vietās.

js// utils.js
export function formatCena(vertiba) {
  return `€${vertiba.toFixed(2)}`;
}

// main.js
import { formatCena } from "./utils.js";
console.log(formatCena(9.5)); // "€9.50"

Šo piemēru nevar vienkārši ielīmēt konsolē vai atvērt HTML failu dubultklikšķi - pārlūki moduļus bloķē drošības dēļ, ja lapa atvērta tieši no faila (file://). Lai to izmēģinātu: (1) HTML failā pievieno <script type="module" src="main.js"></script>, un (2) atver lapu caur lokālu serveri, piem., VS Code paplašinājumu "Live Server", vai palaižot terminālī npx serve mapē ar failiem.

JSON

JSON (JavaScript Object Notation) ir teksta formāts datu apmaiņai - ar to strādā gandrīz katrs tīmekļa API un arī localStorage. JSON.stringify() pārvērš JS objektu tekstā (lai to varētu nosūtīt/saglabāt), JSON.parse() dara pretējo.

jsconst lietotajs = { vards: "Anna", vecums: 25 };

const teksts = JSON.stringify(lietotajs);
console.log(teksts);
// '{"vards":"Anna","vecums":25}'  ← tas ir teksts (string), ne objekts

const atpakalObjekts = JSON.parse(teksts);
console.log(atpakalObjekts.vards); // "Anna" - atkal parasts objekts

Kļūdu apstrāde

try/catch noder ne tikai async kodam - jebkurš kods, kas var neizdoties (piem., nederīgs JSON, nepareizs lietotāja ievads), jāietver blokā, lai kļūda nesagāztu visu skriptu. finally bloks izpildās vienmēr - gan ja bija kļūda, gan ja nebija.

jsfunction nolasitDatus(teksts) {
  try {
    const dati = JSON.parse(teksts);
    console.log("Izdevās:", dati);
  } catch (kluda) {
    console.error("Neizdevās nolasīt datus:", kluda.message);
  } finally {
    console.log("Mēģinājums pabeigts.");
  }
}

nolasitDatus('{"vards": "Anna"}'); // "Izdevās: {vards: 'Anna'}"
nolasitDatus("nederīgs teksts");  // "Neizdevās nolasīt datus: ..."

localStorage

Saglabā datus tieši pārlūkā, starp lapas ielādēm un pat pēc datora pārstartēšanas - dati paliek, kamēr lietotājs manuāli neiztīra pārlūka datus. Noder iestatījumiem, tēmas izvēlei, iepirkumu grozam u.tml. Glabā tikai tekstu, tāpēc objekti pirms saglabāšanas jāpārvērš ar JSON.stringify().

js// Saglabā vienkāršu vērtību
localStorage.setItem("tema", "tumsa");
console.log(localStorage.getItem("tema")); // "tumsa"

// Saglabā objektu (jāpārvērš par tekstu)
const iestatijumi = { valoda: "lv", tema: "tumsa" };
localStorage.setItem("iestatijumi", JSON.stringify(iestatijumi));

const saglabatie = JSON.parse(localStorage.getItem("iestatijumi"));
console.log(saglabatie.valoda); // "lv"

localStorage.removeItem("tema"); // izdzēš vienu ierakstu

Iekopē šo tieši jebkuras vietnes pārlūka konsolē (F12) - localStorage ir pieejams jebkurā lapā, nav vajadzīga papildu iestatīšana.

setTimeout / setInterval

JavaScript izpilda kodu vienā pavedienā (single-threaded) - nevar divas lietas darīt burtiski vienlaicīgi, taču setTimeout un setInterval ļauj ieplānot koda izpildi nākotnē, neapturot pārējo skriptu. setTimeout izpildās vienreiz pēc norādītā laika, setInterval - atkārtoti ik pēc norādītā intervāla.

jsconsole.log("1. Sākums");

setTimeout(() => {
  console.log("3. Izpildās pēc 2 sekundēm");
}, 2000);

console.log("2. Turpinās uzreiz, negaidot taimeri");

// Atkārtojas ik pēc sekundes, kamēr netiek apturēts
let skaits = 0;
const intervalaId = setInterval(() => {
  skaits++;
  console.log("Tikšķis Nr." + skaits);
  if (skaits === 3) {
    clearInterval(intervalaId); // aptur atkārtošanos
  }
}, 1000);

DOM manipulācija

DOM (Document Object Model) ir tas, kā pārlūks HTML lapu "redz" kā koku ar elementiem, ko JavaScript var atrast, mainīt vai izveidot no jauna. Tas ir pamats jebkurai interaktīvai vietnei - bez DOM manipulācijas JS varētu tikai skaitļot fonā, bet neko nemainītu ekrānā.

Zemāk ir pilns, patstāvīgs HTML fails - saglabā to kā dom-piemers.html un atver ar dubultklikšķi jebkurā pārlūkā, lai redzētu to strādājam:

html<!doctype html>
<html>
<body>
  <button id="mana-poga">Spied mani</button>
  <p id="rezultats">Vēl nav nospiests.</p>

  <script>
    const poga = document.querySelector("#mana-poga");
    const rezultats = document.querySelector("#rezultats");
    let klikski = 0;

    poga.addEventListener("click", () => {
      klikski++;
      rezultats.textContent = `Nospiests ${klikski} reizes.`;
      poga.classList.toggle("aktivs");
    });
  </script>
</body>
</html>

Biežāk lietotās DOM metodes: querySelector() (atrod vienu elementu pēc CSS selektora), querySelectorAll() (atrod visus atbilstošos), addEventListener() (reaģē uz notikumiem - klikšķi, ievadi u.c.), textContent/innerHTML (maina saturu).

Build rīki

Reālos projektos JS kodu parasti neraksta vienā failā - izmanto rīkus, kas apvieno, optimizē un pārbauda kodu pirms tas nonāk pārlūkā. Zemāk komandas, ar ko no nulles izveidot un palaist projektu ar Vite (mūsdienās populārākais, ātrākais variants):

bash# Izveido jaunu projektu (jautās projekta nosaukumu un veidu)
npm create vite@latest mans-projekts

# Ieej projekta mapē
cd mans-projekts

# Instalē atkarības
npm install

# Palaiž dev serveri ar automātisku pārlādēšanu
npm run dev

⚡ Vite

Ātrs dev serveris ar automātisku pārlūka atsvaidzināšanu (HMR) un moderna build sistēma gatavajai versijai.

📦 npm / pnpm

Pakotņu pārvaldnieki - instalē un pārvalda projekta atkarības (bibliotēkas), kas uzskaitītas package.json failā.

🧹 ESLint / Prettier

ESLint atrod iespējamas kļūdas un stila problēmas kodā; Prettier automātiski formatē kodu vienotā stilā.

Kur atrast bibliotēkas? - npmjs.com ir centrālais JavaScript pakotņu katalogs (tas pats, kas PHP pasaulē ir Packagist). Meklē pēc vajadzības, tad instalē tieši ar to nosaukumu, ko atradi tur:

bash# Instalē konkrētu bibliotēku (piem., datumu formatēšanai)
npm install dayjs
jsimport dayjs from 'dayjs';
console.log(dayjs().format('YYYY-MM-DD'));

npmjs.com pakotnes lapā pārbaudi to pašu, ko Packagist lapā - lejupielāžu skaitu (populārāka = uzticamāka), pēdējā atjauninājuma datumu un vai bibliotēka tiek aktīvi uzturēta. Instalētās bibliotēkas nonāk node_modules/ mapē - tāpat kā PHP vendor/, arī šo mapi nekad nepievieno Git repozitorijā.

DevTools & atkļūdošana

Pārlūka izstrādātāju rīki (F12) piedāvā daudz vairāk par console.log() - šīs tehnikas ietaupa stundas, salīdzinot ar mēģinājumu atrast kļūdu, tikai skatoties uz kodu.

Console metodes papildus console.log()

jsconsole.table([{ vards: 'Anna', vecums: 25 }, { vards: 'Kārlis', vecums: 30 }]);
// izvada skaistu TABULU konsolē, nevis nesalasāmu masīva izdruku

console.group('Lietotāja validācija');

console.log('E-pasts pareizs');
console.groupEnd(); // sagrupē rindas, var sakļaut/izvērst konsolē

console.time('vaicajums');
// ... kāda darbība
console.timeEnd('vaicajums'); // izvada: "vaicajums: 123.45ms"

console.assert(lietotajs.vecums >= 18, 'Lietotājs nav pilngadīgs!');
// izvada kļūdu TIKAI tad, ja nosacījums ir false - klusē, ja true

debugger; un breakpoints

jsfunction apstradatMaksajumu(summa) {

    return summa * 1.21;
}

debugger; aptur izpildi un ļauj cilnē "Sources" apskatīt visu mainīgo vērtības tajā brīdī, iet cauri kodam rindu pa rindai (step over/into) un pat mainīt mainīgo vērtības uz vietas - daudz jaudīgāk nekā mēģināt uzminēt problēmu, izkaisot console.log() pa visu funkciju. Pēc atkļūdošanas neaizmirsti izdzēst debugger; rindu.

Network cilne

Rāda katru tīkla pieprasījumu, ko lapa nosūta - API izsaukumus, attēlus, skriptus.

Statusa kods

200 (OK), 404 (nav atrasts), 500 (servera kļūda) - pirmais, kas jāpārbauda, ja pieprasījums "neko nedara".

Response/Preview

Skati tieši to, ko serveris atsūtīja - der pārbaudīt, vai API tiešām atgriež gaidītos datus.

Filtrs: Fetch/XHR

Paslēpj attēlus/fontus/CSS, atstājot redzamus tikai API izsaukumus - daudz vieglāk atrast vajadzīgo starp desmitiem pieprasījumu.

Preserve log

Saglabā pieprasījumu sarakstu arī pēc lapas pārlādes - noder, atkļūdojot pāradresācijas vai pieteikšanās plūsmas.
