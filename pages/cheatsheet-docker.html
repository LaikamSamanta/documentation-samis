Docker Cheatsheet

Ātrās uzziņas lapa - katrai kartiņai īss skaidrojums un komandas fragments. Pamatjēdzienus un pilnu WordPress + MySQL piemēru skaties pilnajā Docker dokumentācijā.

Attēli (images) Konteineri Compose Volumes & tīkli Žurnāli & atkļūdošana Tīrīšana

Attēli (images)

docker build

Uzbūvē image no Dockerfile pašreizējā mapē.

docker build -t mans-app .

docker images

Rāda visus lokāli lejupielādētos/uzbūvētos images.

docker images

docker pull

Lejupielādē gatavu image no Docker Hub.

docker pull nginx:latest

docker rmi

Izdzēš vienu image (jābūt bez aktīviem konteineriem, kas to lieto).

docker rmi mans-app

docker tag

Piešķir image papildu nosaukumu/versiju, piem. pirms push uz reģistru.

docker tag mans-app mans-app:v2

Konteineri

docker run

Palaiž jaunu konteineru no image, fonā, ar porta piesaisti.

docker run -d -p 8080:80 nginx

docker ps

Palaistie konteineri / arī apturētie ar -a.

docker ps
docker ps -a

docker stop / start

Aptur vai atsāk konteineru, nedzēšot to.

docker stop konteiners
docker start konteiners

docker restart

Pārstartē konteineru - noder pēc konfigurācijas maiņas.

docker restart konteiners

docker rm

Izdzēš apturētu konteineru (pievieno -f, lai piespiestu, ja vēl darbojas).

docker rm konteiners

docker exec

Atver termināli KONTEINERA iekšienē - failu vai datubāzes pārbaudei.

docker exec -it konteiners bash

Docker Compose

docker compose up

Palaiž visus servisus no docker-compose.yml fonā.

docker compose up -d

docker compose down

Aptur un izdzēš visus servisus (volumes paliek droši).

docker compose down

docker compose build

Pārbūvē images pēc Dockerfile vai atkarību izmaiņām.

docker compose build

docker compose restart

Pārstartē VIENU konkrētu servisu, neietekmējot pārējos.

docker compose restart wordpress

docker compose exec

Termināls konkrētā compose servisā.

docker compose exec wordpress bash

docker compose ps

Rāda visu compose projekta servisu statusu.

docker compose ps

Volumes & tīkli

docker volume ls

Rāda visus Docker pārvaldītos volumes (pastāvīgos datus).

docker volume ls

docker volume rm

Izdzēš volume - neatgriezeniski dzēš tajā glabātos datus.

docker volume rm db_dati

docker network ls

Rāda visus Docker tīklus, kas savieno konteinerus savā starpā.

docker network ls

docker network inspect

Rāda, kuri konteineri pievienoti konkrētam tīklam.

docker network inspect tikls

Žurnāli & atkļūdošana

docker logs

Konteinera izvades žurnāls, -f seko tiešraidē.

docker logs -f konteiners

docker compose logs

Tas pats, bet konkrētam compose servisam.

docker compose logs -f wordpress

docker inspect

Pilna konteinera/image konfigurācija JSON formātā (porti, volumes, env).

docker inspect konteiners

docker stats

CPU/RAM/tīkla lietojums visiem palaistajiem konteineriem, tiešraidē.

docker stats

docker top

Rāda procesus, kas darbojas konteinera iekšienē.

docker top konteiners

Tīrīšana

docker system prune

Noņem NEIZMANTOTUS images/konteinerus/build kešu - volumes paliek droši.

docker system prune

docker container prune

Izdzēš tikai apturētos konteinerus.

docker container prune

docker image prune

Izdzēš tikai neizmantotos (dangling) images.

docker image prune

docker system prune -a --volumes

Bīstami - izdzēš arī VISUS neizmantotos volumes (dati zūd neatgriezeniski). Lieto tikai, ja tiešām jāatbrīvo maksimāli daudz vietas.

docker system prune -a --volumes
