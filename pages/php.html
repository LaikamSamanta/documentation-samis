PHP

Pilns iesācēja ceļvedis: katrai tēmai — skaidrojums, kāpēc tas vajadzīgs, un pilnībā patstāvīgs koda piemērs, ko var iekopēt un uzreiz palaist.

Ievads PHP

PHP ir servera puses skriptvaloda — kods izpildās serverī, pirms rezultāts (parasti HTML) tiek nosūtīts apmeklētāja pārlūkam. Apmeklētājs pats PHP kodu nekad neredz, tikai gala rezultātu. Tā ir viena no visizplatītākajām valodām web izstrādē un darbina arī WordPress.

Kā palaist PHP kodu savā datorā (izvēlies vienu no diviem):

text1. Vienkāršākais veids — iebūvētais PHP serveris:
   Instalē PHP (php.net) → izveido failu index.php ar kodu →
   terminālī tajā pašā mapē palaid: php -S localhost:8000
   → atver pārlūkā http://localhost:8000

2. Vai izmanto gatavu vidi: XAMPP / Local / Laragon —
   tie uzreiz iekļauj PHP + MySQL + serveri vienā instalācijā.

Visi šīs lapas piemēri sākas ar <?php — tieši tā jāsāk jebkurš .php fails, lai serveris zinātu, kur sākas PHP kods (pretstatā parastam HTML).

Sintakse & tipi

PHP mainīgie vienmēr sākas ar $ un tiem nav jānorāda tips iepriekš. Katra rinda beidzas ar semikolu ;. Pamata tipi: string (teksts), int/float (skaitļi), bool (true/false), array (masīvs).

php<?php
$vards = "Anna";
$vecums = 25;
$aktivs = true;

function sveiciens(string $vards): string {
    return "Sveiks, {$vards}!";
}

echo sveiciens($vards); // izvada: Sveiks, Anna!
echo gettype($vecums);   // izvada: integer

"Sveiks, {$vards}!" — teksts pēdiņās (dubultajās) automātiski ievieto mainīgo vērtību. Vienpēdiņu tekstā ('...') tas nenotiek — $vards tur paliktu kā burtisks teksts.

Konstantes

Konstante ir vērtība, kas pēc definēšanas nekad nemainās visa skripta izpildes laikā — atšķirībā no mainīgā, to nevar vēlāk pārrakstīt. Noder iestatījumiem, konfigurācijas vērtībām un "burtiskiem" skaitļiem, kuriem vēlies aprakstošu nosaukumu.

php<?php
define('SITE_NAME', 'Mana Vietne');
const MAX_MEGINAJUMI = 3;

echo SITE_NAME;       // izvada: Mana Vietne
echo MAX_MEGINAJUMI;  // izvada: 3

// Mēģinājums mainīt konstanti izraisītu kļūdu:
// SITE_NAME = 'Cits nosaukums'; // Fatal error

Nosacījumi & cikli

Tāpat kā citās valodās, if/elseif/else ļauj pieņemt lēmumus, bet cikli (for, foreach, while) atkārto kodu. foreach ir īpaši ērts masīviem — PHP to izmanto biežāk nekā klasisko for.

php<?php
$vecums = 16;

if ($vecums >= 18) {
    echo "Pieaugušais";
} elseif ($vecums >= 13) {
    echo "Pusaudzis"; // šis izpildīsies
} else {
    echo "Bērns";
}

echo "\n---\n";

for ($i = 0; $i < 5; $i++) {
    echo $i . " "; // 0 1 2 3 4
}

echo "\n---\n";

$i = 0;
while ($i < 3) {
    echo "Mēģinājums " . $i . "\n";
    $i++;
}

Salīdzinot vērtības, === pārbauda arī tipu, ne tikai vērtību — "5" == 5 ir true, bet "5" === 5 ir false. Droši ieteicams vienmēr izmantot ===.

Masīvi

PHP masīvi var būt indeksēti (numurēti automātiski, sākot no 0) vai asociatīvi (paši nosauc atslēgas, kā "vārdnīca"). foreach iet cauri jebkuram no tiem.

php<?php
// Indeksēts masīvs
$augli = ["ābols", "banāns", "apelsīns"];

foreach ($augli as $auglis) {
    echo $auglis . "\n";
}

// Asociatīvs masīvs
$lietotajs = [
    "vards" => "Kārlis",
    "vecums" => 30,
];

foreach ($lietotajs as $atslega => $vertiba) {
    echo "{$atslega}: {$vertiba}\n";
}
// vards: Kārlis
// vecums: 30

echo count($augli); // 3 — elementu skaits

String funkcijas

PHP piedāvā simtiem iebūvētu funkciju teksta apstrādei — biežāk lietotās:

php<?php
echo strlen("Sveiki") . "\n";                      // 6 — garums
echo str_replace("a", "o", "banāns") . "\n";      // "bonāns"
echo strtoupper("sveiki") . "\n";                // "SVEIKI"

$dalas = explode(",", "a,b,c");
print_r($dalas);                                    // ["a", "b", "c"]

echo implode(", ", ["a", "b", "c"]) . "\n";      // "a, b, c"
echo trim("  teksts  ") . "\n";                   // "teksts" (bez atstarpēm)

Superglobālie mainīgie

Iebūvēti masīvi, kas pieejami jebkurā faila vietā (bez īpašas importēšanas) un satur ievaddatus no lietotāja vai pārlūka:

php<?php
// URL: piemers.lv/lapa.php?id=5
$id = $_GET['id'] ?? null; // "5"

// Nosūtīta veidlapa ar method="post"
$epasts = $_POST['epasts'] ?? null;

// Dati, kas saglabāti starp lapām (skat. nākamo sadaļu)
$lietotaja_id = $_SESSION['user_id'] ?? null;

echo "ID no URL: " . ($id ?? 'nav norādīts');

?? ir "null coalescing" operators — atgriež kreiso pusi, ja tā nav null, citādi labo. Tas pasargā no kļūdas, ja parametrs vispār nav nosūtīts.

Šie dati nāk tieši no lietotāja — nekad neuzticies tiem tieši. Vienmēr pārbaudi/attīri ar htmlspecialchars() pirms izvadīšanas HTML, lai novērstu XSS uzbrukumus.

Sesijas & sīkdatnes

Sesija saglabā datus serverī starp lapas ielādēm (piem., vai lietotājs ir pieteicies) — jāsāk ar session_start() pašā faila sākumā, pirms jebkāda izvada. Sīkdatne (cookie) tā vietā saglabā nelielu datu daudzumu pašā lietotāja pārlūkā.

php<?php
session_start(); // vienmēr pirmā rinda, pirms echo/HTML

$_SESSION['user_id'] = 5;
echo "Saglabāts sesijā: " . $_SESSION['user_id'];

// Sīkdatne, derīga 1 stundu (3600 sekundes)
setcookie('valoda', 'lv', time() + 3600);

Ja session_start() izsauc pēc tam, kad kaut kas jau izvadīts (pat viena atstarpe pirms <?php), PHP izmet kļūdu "headers already sent" — tas ir viens no biežākajiem iesācēju stiķiem.

include / require

Ielādē citu PHP failu tieši pašreizējā vietā — noder koda sadalīšanai vairākos failos (galvene, kājene, konfigurācija), lai neatkārtotu vienu un to pašu kodu katrā lapā. require apstādina visu skriptu, ja fails nav atrasts; include tikai izmet brīdinājumu un turpina tālāk.

php// config.php
<?php
$site_name = "Mana Vietne";

// index.php
<?php
require_once 'config.php'; // "once" — ielādē tikai vienreiz, pat ja izsauc vairākkārt

echo "Laipni lūdzam vietnē " . $site_name;

Kļūdu apstrāde

try/catch ļauj "noķert" kļūdu, nevis ļaut tai apstādināt visu skriptu ar fatālu paziņojumu. Kļūdu var pašam izraisīt ar throw, kad kods nonāk situācijā, kuru negribi turpināt apstrādāt.

php<?php
function dalit(float $a, float $b): float {
    if ($b === 0.0) {
        throw new Exception("Nevar dalīt ar nulli");
    }
    return $a / $b;
}

try {
    echo dalit(10, 0);
} catch (Exception $e) {
    echo "Kļūda: " . $e->getMessage();
} finally {
    echo "\nAprēķins pabeigts.";
}
// izvada: "Kļūda: Nevar dalīt ar nulli" tad "Aprēķins pabeigts."

Klases & objekti

Klase apraksta objekta struktūru (kādas īpašības un funkcijas tam būs), objekts ir konkrēta šīs klases "kopija" (instance). __construct izpildās automātiski, veidojot jaunu objektu ar new.

php<?php
class Lietotajs {
    public function __construct(
        private string $vards,
        private int $vecums
    ) {}

    public function sveicies(): string {
        return "Sveiks, es esmu {$this->vards} un man ir {$this->vecums} gadi";
    }
}

$lietotajs = new Lietotajs("Anna", 25);
echo $lietotajs->sveicies();
// "Sveiks, es esmu Anna un man ir 25 gadi"

Konstruktora argumenti ar private/public priekšā (PHP 8+) automātiski izveido un aizpilda attiecīgās klases īpašības — bez šī saīsinājuma vajadzētu rakstīt $this->vards = $vards; katram parametram atsevišķi.

Mantojums

Klase var pārmantot citas klases funkcionalitāti ar extends — noder, kad vairākām klasēm ir kopīga bāze. abstract klase pati nevar tikt izveidota (new), tā ir tikai "veidne" citām klasēm.

php<?php
abstract class Dzivnieks {
    public function __construct(protected string $vards) {}

    abstract public function skana(): string;

    public function apraksts(): string {
        return "{$this->vards} saka: " . $this->skana();
    }
}

class Suns extends Dzivnieks {
    public function skana(): string {
        return "Vau!";
    }
}

$suns = new Suns("Reksis");
echo $suns->apraksts(); // "Reksis saka: Vau!"

Dod priekšroku composition over inheritance ("sastāvs pār mantojumu") — ja hierarhija kļūst dziļa un sarežģīta, interfeisi un mazākas, koplietojamas klases bieži ir elastīgāks risinājums.

Interfeisi

Interfeiss apraksta, kādas funkcijas klasei jāievieš, bet ne to, kā tās strādā iekšēji. Tas ļauj dažādām, nesaistītām klasēm strādāt savstarpēji aizvietojami — jebkur, kur sagaida Maksajums, var padot jebkuru klasi, kas šo interfeisu ievieš.

php<?php
interface Maksajums {
    public function apstradat(float $summa): bool;
}

class KartesMaksajums implements Maksajums {
    public function apstradat(float $summa): bool {
        echo "Apstrādā {$summa}€ ar karti\n";
        return true;
    }
}

function veiktPirkumu(Maksajums $metode, float $summa): void {
    $metode->apstradat($summa);
}

veiktPirkumu(new KartesMaksajums(), 49.99);
// "Apstrādā 49.99€ ar karti"

Traits

PHP klase var extends tikai vienu vecākklasi — atšķirībā no dažām citām valodām, PHP neatbalsta vairākkārtēju mantojumu. Bet bieži gadās, ka divām nesaistītām klasēm (piem., Lietotajs un Produkts) vajag tieši to pašu, gatavo funkcionalitāti — piem., laika zīmogu izsekošanu. Trait atrisina šo: tas ir gatavu metožu "gabals", ko var iekopēt jebkurā klasē ar use, neatkarīgi no klases mantojuma hierarhijas.

php<?php
trait Laikazimogojams {
    private ?string $izveidots = null;

    public function atzimetIzveidosanu(): void {
        $this->izveidots = date('Y-m-d H:i:s');
    }

    public function iegutIzveidosanasLaiku(): ?string {
        return $this->izveidots;
    }
}

// Divas pilnīgi nesaistītas klases izmanto to pašu funkcionalitāti
class Lietotajs {
    use Laikazimogojams;

    public function __construct(public string $vards) {
        $this->atzimetIzveidosanu();
    }
}

class Produkts {
    use Laikazimogojams;

    public function __construct(public string $nosaukums) {
        $this->atzimetIzveidosanu();
    }
}

$lietotajs = new Lietotajs("Anna");
echo $lietotajs->iegutIzveidosanasLaiku(); // piem. "2026-07-24 14:32:10"

Vienkāršs veids atcerēties atšķirību: interfeiss saka "šeit ir tikai saraksts, ko tev jāievieš pašam", trait saka "šeit ir gatavs kods, ko vari uzreiz izmantot". Klase var izmantot vairākus traits vienlaikus (use TraitViens, TraitDivi;), kas apiet "tikai viena vecākklase" ierobežojumu.

Datubāzes (PDO)

PDO ir vienota saskarne darbam ar dažādām datubāzēm (MySQL, PostgreSQL, SQLite) — kods paliek līdzīgs, nomainot tikai savienojuma rindu. Zemāk pilns piemērs SQLite datubāzei, ko var izmēģināt uzreiz bez servera iestatīšanas (SQLite ir viens fails, iebūvēts PHP):

php<?php
// Izveido datubāzi atmiņā un tabulu (viss vienā failā, bez servera)
$pdo = new PDO('sqlite::memory:');
$pdo->exec('CREATE TABLE lietotaji (id INTEGER PRIMARY KEY, vards TEXT)');
$pdo->exec("INSERT INTO lietotaji (vards) VALUES ('Anna')");

// Drošs vaicājums ar prepared statement
$stmt = $pdo->prepare('SELECT * FROM lietotaji WHERE id = ?');
$stmt->execute([1]);
$lietotajs = $stmt->fetch();

echo $lietotajs['vards']; // "Anna"

Reālam projektam ar MySQL savienojuma rinda izskatās šādi:

php$pdo = new PDO("mysql:host=localhost;dbname=veikals", "root", "secret");

Vienmēr izmanto prepared statements (kā piemērā, ar ? vietturiem) — nekad nesalīmē lietotāja ievadi tieši SQL vaicājuma tekstā, jo tas atver ceļu SQL injection uzbrukumiem.

Composer

Composer ir PHP pakotņu pārvaldnieks — ļauj instalēt un pārvaldīt gatavas bibliotēkas, nevis rakstīt visu no nulles. Instalētās bibliotēkas nonāk vendor/ mapē un tiek automātiski ielādētas.

bash# Izveido jaunu projektu ar composer.json failu
composer init

# Instalē konkrētu bibliotēku (piem., loga rakstīšanai)
composer require monolog/monolog

# Instalē visas atkarības, kas jau uzskaitītas composer.json
composer install

Pēc instalēšanas bibliotēku izmanto, pievienojot vienu rindu koda sākumā:

php<?php
require 'vendor/autoload.php'; // ielādē visas Composer bibliotēkas
