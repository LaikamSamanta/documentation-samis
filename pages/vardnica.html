Laravel pamati

Kas notiek serverī (PHP pusē).

VārdsKo tas nozīmēPiemērs
Route (maršruts)Noteikums: "kad kāds atver šo adresi, palaid šo kodu". Bez maršruta adrese vienkārši nestrādā.Route::get('/shop', ...) → routes/web.php
Controller (kontrolieris)PHP klase, kurā ir tava loģika: paņem datus no datubāzes, pārbauda ievadi un atdod atbildi.CategoryController → app/Http/Controllers/
ModelPHP klase, kas ir "tilts" uz vienu datubāzes tabulu. Ar to lasi un raksti ierakstus, nerakstot SQL.Category ↔ tabula categories
EloquentLaravel veids, kā strādāt ar datubāzi caur modeļiem (nevis ar SQL vaicājumiem).Product::where('status', 1)->get()
Migration (migrācija)Fails, kas apraksta datubāzes izmaiņu (jauna tabula, jauna kolonna). Tās izpildās pēc kārtas, tāpēc vecās nekad nelabo - taisi jaunu.php artisan make:migration ... → php artisan migrate
SeederFails, kas ieliek datubāzē sākuma datus (piem. izmēru sarakstu S, M, L).php artisan db:seed
FactoryVeidne, kā uztaisīt viltus (testa) ierakstu. Seeder to izmanto, lai uzģenerētu daudz ierakstu.User::factory()->count(10)
Middleware"Sargs" starp pārlūku un kontrolieri. Katrs pieprasījums iet cauri tam: viņš var to apturēt, pārbaudīt vai papildināt.Vai lietotājs ir admin? → EnsureAdmin
Request (pieprasījums)Viss, ko pārlūks atsūta serverim: adrese, metode, ievadītie dati, sīkdatnes.$request->name
Response (atbilde)Ko serveris atsūta atpakaļ: lapa, JSON vai redirect.response()->json([...])
Validation (validācija)Pārbaude, vai ievadītie dati ir derīgi (nav tukši, ir e-pasts, ir unikāli), pirms tos saglabā.'email' => 'required|email'
Form RequestValidācijas noteikumi, iznesti atsevišķā failā. Kontrolierī pieraksti tikai tā nosaukumu, un validācija notiek pati.php artisan make:request ProfileUpdateRequest
Route model bindingJa maršrutā raksti {category}, Laravel pats atrod ierakstu pēc id un iedod to kontrolierim. Ja nav - 404.fn (Category $category) => ...
ArtisanLaravel komandrindas rīks. Ar to veido failus, palaiž migrācijas, skatās maršrutus.php artisan route:list
BladeLaravel HTML šablonu valoda (.blade.php). Inertia lietotnē tā vajadzīga tikai vienam failam - saknes šablonam.resources/views/app.blade.php
Auth (autentifikācija)Pārbaude, KAS tu esi (ielogošanās). Atšķirība no autorizācijas - vai TEV drīkst darīt šo.Auth::attempt([...])
Session (sesija)Serveris atceras lietotāju starp pieprasījumiem. Pārlūks glabā tikai sesijas id sīkdatnē.SESSION_DRIVER=database failā .env
CSRFAizsardzība pret viltus formām no citām lapām. Katram POST vajag īpašu tokenu; ja nav - kļūda 419.Inertia to pievieno pati
FortifyGatava Laravel pakotne ielogošanai, reģistrācijai, paroles atjaunošanai un 2FA.config/fortify.php
SanctumLaravel pakotne API tokeniem (kad frontend ir atsevišķā domēnā). Inertia to nevajag.Sk. "Sanctum vs sesijas" augstāk lapā
ComposerPHP pakotņu pārvaldnieks (kā npm, bet PHP).composer install
.envFails ar paslēptiem iestatījumiem (datubāzes parole, APP_KEY). Nekad nelieto Git.DB_DATABASE=project_ecommerce

Inertia

Sasaiste starp Laravel un React.

VārdsKo tas nozīmēPiemērs
InertiaBibliotēka, kas ļauj Laravel un React strādāt kā vienai lietotnei: Laravel dod datus, React zīmē lapu, un nevajag rakstīt atsevišķu API.inertiajs/inertia-laravel + @inertiajs/react
Page (lapa)React komponente, ko kontrolieris izvēlas pēc nosaukuma. Atrodas mapē resources/js/pages/.inertia('Product') → pages/Product.jsx
PropsDati, ko serveris iedod lapai. Tu tos saņem kā funkcijas parametrus.({ product }) => ...
Shared propsProps, kas automātiski ir katrā lapā (piem. ielogotais lietotājs, kategoriju saraksts izvēlnei). Definē share() metodē.usePage().props.categories
HandleInertiaRequestsVienīgais Inertia middleware. Šeit iestata saknes šablonu, versiju un shared props.app/Http/Middleware/
Root template (saknes šablons)Vienīgais Blade fails, kas ielādē JS/CSS un ieliek vietu, kur React uzzīmēs lapu.resources/views/app.blade.php
Page objectMazs JSON, ko Inertia sūta katru reizi: kuru lapu rādīt, kādi props, kāds URL.{ component, props, url, version }
inertia() / Inertia::renderKontroliera rinda, kas saka: "parādi šo lapu ar šiem datiem".inertia('Product', ['product' => $p])
Route::inertiaSaīsinājums maršrutam, kas tikai parāda lapu bez datiem.Route::inertia('/shop', 'Shop')
<Link>Inertia saite: pāriet uz citu lapu bez pilnas pārlādes. Parastais <a> pārlādē visu lapu.<Link href="/shop">Shop</Link>
routerInertia veids, kā pāriet vai sūtīt datus no koda (nevis no saites).router.visit('/admin/products')
useFormInertia forma: pati sūta datus, glabā kļūdas un rāda, vai notiek sūtīšana.const { data, post, errors } = useForm({...})
usePageHook, ar kuru jebkurā komponentē nolasa props (arī shared).const { auth } = usePage().props
<Head>Uzstāda lapas virsrakstu (cilnes nosaukumu).<Head title="Shop" />
LayoutKopīgs ietvars visām lapām (header, footer). Persistent layout = ietvars nepārzīmējas, pārejot starp lapām.Shop.layout = page => <Layout>{page}</Layout>
Partial reloadPārlādē tikai dažus props, nevis visus. Ātrāk.router.reload({ only: ['users'] })
Deferred propsSmagie dati, kas ielādējas pēc tam, kad lapa jau parādījusies.Inertia::defer(fn () => ...)
Closure propProp kā funkcija - izpildās tikai, ja tiešām vajadzīgs. Ietaupa DB vaicājumus.'users' => fn () => User::all()
FlashĪsa ziņa, kas parādās vienu reizi un pazūd ("Saglabāts!").Inertia::flash('toast', [...])
Error bagNosaukta kļūdu grupa, ja vienā lapā ir vairākas formas ar vienādiem lauku nosaukumiem.{ errorBag: 'createCompany' }
SSRLapa tiek uzzīmēta jau serverī (labāk Google un ātrāks pirmais skats). Nav obligāta.config/inertia.php → ssr
WayfinderRīks, kas ģenerē JS funkcijas maršrutiem, lai URL nav jāraksta ar roku.resources/js/routes/
X-InertiaGalvene, ar kuru Inertia pasaka serverim: "atsūti tikai JSON, nevis visu HTML".DevTools → Network
Asset version (409)Ja pēc deploy mainās JS/CSS, Inertia vienreiz pārlādē visu lapu, lai dabūtu jaunos failus.Normāla uzvedība

React

Kas notiek pārlūkā (JS pusē).

VārdsKo tas nozīmēPiemērs
Component (komponente)Funkcija, kas atgriež kādu ekrāna daļu (JSX). Lapas, poga, header - viss ir komponentes.const Header = () => <nav>...</nav>
JSXHTML līdzīga sintakse JavaScript iekšā.<h1>{product.title}</h1>
State (useState)Komponentes atmiņa. Kad tā mainās, React pārzīmē ekrānu.const [count, setCount] = useState(0)
useEffectKods, kas jāizpilda pēc tam, kad komponente parādījusies vai kaut kas mainījies.useEffect(() => { fetchData() }, [])
HookFunkcija, kas sākas ar use un dod komponentei papildu spējas (state, effect, context).useState, useContext, usePage
Context / ProviderVeids, kā vienu datu kopu padarīt pieejamu visām komponentēm, nenododot to no vienas uz otru. Provider "ietin" lietotni.CartProvider + useContext(CartContext)
Re-render (pārzīmēšana)Kad state vai props mainās, React no jauna izpilda komponenti un atjauno ekrānu.Pēc setCartData(..)
react-hook-formBibliotēka formu laukiem un kļūdām (nav no Inertia).register('name', { required: true })
ToastĪss uznirstošs paziņojums ekrāna stūrī.toast.success('Saglabāts')

Datubāze

Kā dati tiek glabāti.

VārdsKo tas nozīmēPiemērs
Tabula / kolonna / ierakstsTabula = Excel lapa. Kolonna = lauks (nosaukums, cena). Ieraksts = viena rinda.products → title → "T-krekls"
Foreign key (ārējā atslēga)Kolonna, kas norāda uz citas tabulas ierakstu (produkta kategorija).category_id
Relation (relācija)Modelī aprakstīta saikne starp tabulām.hasMany, belongsToMany
Pivot tabulaStarptabula "daudzi pret daudziem" saitei (produkts ↔ izmēri).product_sizes
nullableKolonnā drīkst būt tukša vērtība (NULL). Vajadzīgs, ja pievieno kolonnu tabulai ar esošiem ierakstiem.->nullable()
defaultVērtība, ko iedod, ja nekas nav norādīts.->default(1)
uniqueVērtība nedrīkst atkārtoties (piem. SKU).$table->unique('sku')
load() / with()Papildus ielādē saistītos ierakstus vienlaikus, lai nav daudz atsevišķu vaicājumu.$product->load('sizes')

Web pamati

Kā pārlūks runā ar serveri.

VārdsKo tas nozīmēPiemērs
HTTP metodeKo pārlūks grib darīt: GET = lasīt, POST = izveidot, PUT/PATCH = mainīt, DELETE = dzēst.fetch(url, { method: 'DELETE' })
Statusa kodsSkaitlis, kas saka, kā gāja: 200 = OK, 302/303 = redirect, 401 = neesi ielogojies, 403 = nedrīkst, 404 = nav atrasts, 419 = beidzies CSRF/sesija, 422 = validācijas kļūda (API), 500 = servera kļūda.DevTools → Network
RedirectServeris pasaka pārlūkam: "ej uz citu adresi".return to_route('home')
JSONDatu formāts tekstā, ko saprot gan PHP, gan JavaScript.{ "id": 5, "title": "..." }
APIAdrese, kas atgriež datus (parasti JSON), nevis lapu./admin/categories/list
fetchJavaScript funkcija pieprasījuma nosūtīšanai serverim bez lapas pārlādes. Nemet kļūdu, ja serveris atbild 404/500 - pašam jāpārbauda.await fetch('/api/x')
XHR / AJAXPieprasījums serverim, ko JavaScript sūta fonā, lapu nepārlādējot. Inertia klikšķi ir XHR.Network → Fetch/XHR
Cookie (sīkdatne)Mazs teksts, ko pārlūks glabā un automātiski atsūta serverim (sesijai, iestatījumiem).XSRF-TOKEN
localStoragePārlūka atmiņa. Glabā tekstu arī pēc lapas pārlādes, bet tikai šim lietotājam un tikai šajā pārlūkā. Serveris to neredz.Grozs
TokenŠifrēta "caurlaide", ko sūta katrā pieprasījumā (API), nevis paļaujas uz sīkdatni.Authorization: Bearer ...
SPAVienas lapas lietotne: pārlūks ielādē vienu reizi, tālāk maina tikai saturu.Inertia dod SPA sajūtu

Rīki un izvietošana

Kā projekts tiek palaists un publicēts.

VārdsKo tas nozīmēPiemērs
npmJavaScript pakotņu pārvaldnieks. package.json ir saraksts, kas projektam vajadzīgs.npm install
node_modules / vendorMapes ar lejupielādētām pakotnēm (JS / PHP). Neliek Git un neaiztiec.Izveido npm install / composer install
ViteRīks, kas savāc JS/CSS un lokāli palaiž ātru dev serveri.npm run dev
BuildSagatavo gala JS/CSS failus produkcijai (public/build). Bez tā live lapa nedarbosies.npm run build
DeployProjekta izlikšana internetā (serverī vai hostingā).Render, Vercel
ProxyServeris pa vidu, kas pieņem pieprasījumus un pārsūta tālāk. Aiz proxy Laravel jāsaka, lai tam uzticas.trustProxies(at: '*')
Mixed contentLapa ir https, bet faili ielādējas ar http - pārlūks tos bloķē.Labo ar trustProxies
Dev / produkcijaDev = tavs dators (kļūdas redzamas, viss lēns). Produkcija = īstā lapa (viss jāsabūvē un jānoslēdz).APP_ENV=production
