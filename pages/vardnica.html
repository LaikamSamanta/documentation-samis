Vārdnīca

Jēdzienu īsā uzziņa - ja aizmirsies, kas ir API, ports vai commit, šeit atradīsi vienu teikumu, nevis veselu lekciju. Pilnus skaidrojumus ar piemēriem skaties attiecīgajā kategorijā - katram terminam apakšā ir saite uz to.

Web pamati

API

"Sarunvaloda" starp divām programmām - noteikums, kā viena sistēma var pieprasīt datus vai darbību no citas. Pilns skaidrojums API kategorijā.

CMS

Content Management System - programma satura (tekstu, attēlu, lapu) pārvaldīšanai bez koda rakstīšanas katru reizi. WordPress ir vispopulārākais. Skaties WordPress kategoriju.

Frontend

Viss, ko lietotājs redz un ar ko mijiedarbojas pārlūkā - HTML, CSS, JavaScript. Skaties JavaScript kategoriju.

Backend

Serverī strādājošā daļa, ko lietotājs neredz tieši - apstrādā datus, pieslēdzas datubāzei, atgriež atbildes. Skaties PHP kategoriju.

Fullstack

Izstrādātājs vai risinājums, kas aptver gan frontend, gan backend daļu.

Framework

Gatavs "skelets" ar noteikumiem un rīkiem, uz kura būvē lietotni, nevis raksti visu no nulles. Piemēri - React, Vue. Skaties React/Vue pārskatu.

SPA

Single Page Application - lietotne, kas ielādē vienu HTML lapu un pēc tam pati apmaina saturu bez pilnas pārlādes.

Responsīvs dizains

Izkārtojums, kas pielāgojas dažāda izmēra ekrāniem - telefonam, planšetei, monitoram - ar vienu un to pašu kodu.

Tīkls & serveri

IP adrese

Unikāls skaitlisks "adreses" identifikators, pēc kura ierīces tīklā atrod cita citu. Skaties Tīkls kategorijā.

Ports

Numurs, kas norāda, kuram konkrētam pakalpojumam uz servera adresēts pieprasījums (80 = HTTP, 443 = HTTPS, 22 = SSH). Skaties Tīkls kategorijā.

DNS

Sistēma, kas domēna vārdu (piem., example.com) pārvērš IP adresē, ko dators saprot. Skaties Tīkls kategorijā.

Domēns

Cilvēkam lasāms vietnes vārds (piem., example.com), kas reģistrēts un norāda uz serveri caur DNS.

Serveris

Dators, kas pastāvīgi strādā un atbild uz pieprasījumiem no interneta - tur "dzīvo" vietne vai lietotne.

Hosting

Pakalpojums, kas nodrošina serveri, uz kura izvietot vietni - tas var būt gan dalīts serveris, gan mākoņa risinājums.

CDN

Content Delivery Network - servera tīkls pasaulē, kas nogādā vietnes saturu no ģeogrāfiski tuvākā punkta lietotājam, tāpēc ātrāk. Skaties Tīkls kategorijā.

SSL / TLS

Šifrēšanas protokols, kas padara savienojumu starp pārlūku un serveri drošu (HTTPS). Skaties Tīkls kategorijā.

Izstrāde & darba plūsma

Git

Versiju kontroles sistēma - seko līdzi koda izmaiņām laika gaitā, ļauj atgriezties pie vecām versijām un strādāt vairākiem cilvēkiem vienlaikus. Skaties Git kategoriju.

Repozitorijs

Mape ar visu projekta kodu, ko Git izseko - vietējā kopija un/vai attālinātā (piem., GitHub). Skaties Git kategorijā.

Commit

"Saglabāts uzņēmums" no koda izmaiņām - ar ziņu, kas paskaidro, kas un kāpēc mainījās. Skaties Git kategorijā.

Branch (zars)

Paralēla koda versija, kurā droši var izstrādāt jaunu funkciju, neskarot galveno (main/master) kodu. Skaties Git kategorijā.

Pull Request

Pieprasījums apvienot viena zara izmaiņas galvenajā kodā - parasti ar koda pārskatīšanu pirms apstiprināšanas. Skaties Git kategorijā.

.gitignore

Fails, kas pasaka Git, kurus failus/mapes NEKAD nesekot (piem., node_modules, .env ar paroles). Skaties Git kategorijā.

SSH

Šifrēts protokols attālinātai pieslēgšanai serverim caur termināli - komandu izpildei bez fiziskas piekļuves. Skaties SSH kategoriju.

CI/CD

Automātiska koda testēšana (Continuous Integration) un izvietošana (Continuous Deployment) pēc katras izmaiņas, bez manuālas iejaukšanās.

Terminālis / CLI

Teksta interfeiss komandu ievadīšanai tieši datoram vai serverim, bez peles un logiem. Skaties SSH kategorijā.

Dati & backend

Datubāze

Strukturēta vieta, kur glabājas visi lietotnes dati - lietotāji, ieraksti, pasūtījumi. Skaties Datubāzu kategoriju.

SQL

Valoda datu pieprasīšanai un mainīšanai datubāzē (SELECT, INSERT, UPDATE, DELETE). Skaties Datubāzu kategorijā.

JOIN

SQL komanda, kas savieno datus no divām vai vairākām tabulām vienā rezultātā. Skaties Datubāzu kategorijā.

Primārā / ārējā atslēga

Unikāls ieraksta identifikators tabulā (primārā) un saite uz citas tabulas ierakstu (ārējā). Skaties Datubāzu kategorijā.

Indekss

Datubāzes iekšējā "satura rādītāja" struktūra, kas ļauj meklēt datus daudz ātrāk, bez pilnas tabulas caurskatīšanas. Skaties Datubāzu kategorijā.

Endpoint

Konkrēta API adrese, kurai var nosūtīt pieprasījumu (piem., /api/lietotaji). Skaties API kategorijā.

JSON

Vienkāršs teksta formāts datu apmaiņai starp programmām - atslēga/vērtība pāri, ko lasa gan cilvēks, gan programma. Skaties API kategorijā.

Cache (kešs)

Pagaidu saglabāta rezultāta kopija, lai nākamreiz to pašu neaprēķinātu/neielādētu no jauna - ātrāk, bet var rādīt novecojušus datus.

Vides mainīgie (.env)

Slepeni vai konfigurācijas dati (paroles, atslēgas), kas glabājas ārpus koda, atsevišķā .env failā, kas nekad netiek iekļauts Git. Skaties PHP kategorijā.

Konteineri (Docker)

Ietvars, kas iesaiņo lietotni ar visu tās vidi (PHP versiju, atkarībām), lai tā strādātu identiski jebkurā datorā. Skaties Docker kategoriju.

Drošība

Šifrēšana vs Hash

Šifrēšanu var atšifrēt atpakaļ ar atslēgu, hash - nevar, tas ir vienvirziena process (izmanto parolēm). Skaties Drošības kategorijā.

Autentifikācija vs Autorizācija

Autentifikācija pārbauda, KAS tu esi (pieslēgšanās), autorizācija - KO tev drīkst darīt (tiesības). Skaties Drošības kategorijā.

JWT / Token

Parakstīts "caurlaides" gabaliņš, ko lietotājs sūta ar katru pieprasījumu, lai pierādītu, ka ir pieslēdzies, bez servera puses sesijas. Skaties Drošības kategorijā.

XSS

Cross-Site Scripting - uzbrukums, kad ļaunprātīgs JavaScript tiek iemontēts lapā caur neattīrītu lietotāja ievadi. Skaties Drošības kategorijā.

SQL injekcija

Uzbrukums, kad ļaunprātīgs SQL tiek iemontēts pieprasījumā caur neattīrītu ievadi, lai piekļūtu vai bojātu datubāzi. Skaties Drošības kategorijā.

CSRF

Uzbrukums, kad lietotājs bez ziņas tiek piespiests veikt darbību citā vietnē, kurā jau ir pieslēdzies. Skaties Drošības kategorijā.

Rate limiting

Ierobežojums, cik pieprasījumus lietotājs/IP drīkst sūtīt noteiktā laikā - aizsardzība pret pārslodzi un brutālā spēka uzbrukumiem. Skaties Drošības kategorijā.

OWASP Top 10

Autoritatīvs, regulāri atjaunots saraksts ar 10 visbiežāk sastopamajām web lietotņu drošības problēmām. Skaties Drošības kategorijā.

WordPress & CMS

Spraudnis (Plugin)

Papildinājums, kas pievieno WordPress jaunas funkcijas, neskarot pamata kodu. Skaties WordPress kategorijā.

Motīvs (Theme)

Nosaka vietnes izskatu un izkārtojumu - var nomainīt bez satura zaudēšanas. Skaties WordPress kategorijā.

Hook

"Āķis" kodā, kurā var iekabināt savu funkciju - izpildās noteiktā brīdī (action) vai maina datus pirms izvades (filter). Skaties WordPress kategorijā.

Shortcode

Īsa iekava kvadrātiekavās (piem., [galerija]), ko redaktorā ievieto, un WordPress to aizvieto ar dinamisku saturu. Skaties WordPress kategorijā.

Widžets

Neliels, pārvietojams satura bloks (piem., sānjoslā vai kājenē) - kalendārs, jaunākie raksti, meklēšana. Skaties WordPress kategorijā.

WP-CLI

Komandrindas rīks WordPress pārvaldībai bez admin paneļa - instalēšana, atjaunināšana, datubāzes darbības. Skaties SSH kategorijā.
