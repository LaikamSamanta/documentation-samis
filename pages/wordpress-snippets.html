Sākums WordPress Ātrie risinājumi

Ātrie risinājumi

Populāri, patstāvīgi functions.php trikizi — katru var iekopēt tieši tādu, kāds tas ir, tēmas functions.php failā (vai izceltā failā, ko no turienes ielādē ar require_once). Meklē pilnas dziļās sadaļas? Skaties pilnajā WordPress dokumentācijā.

SVG augšupielāžu atbalsts

WordPress pēc noklusējuma bloķē SVG augšupielādi — SVG faili ir teksta (XML) faili, kas var saturēt JavaScript kodu, tāpēc tie ir potenciāls XSS drošības risks. Šis kods atļauj SVG, bet tikai uzticamiem lietotājiem (administratoriem).

phpadd_filter('upload_mimes', function($mimes) {
    if (current_user_can('manage_options')) {
        $mimes['svg'] = 'image/svg+xml';
    }
    return $mimes;
});

Nekad neatļauj SVG augšupielādi visiem lietotājiem (piem., edit_posts vietā manage_options) — jebkurš, kas var augšupielādēt SVG, teorētiski var ievietot ļaunprātīgu JavaScript kodu. Ražošanas vietnēm, kur SVG jāaugšupielādē arī parastiem redaktoriem, apsver specializētu spraudni (piem., "Safe SVG"), kas SVG failu attīra pirms saglabāšanas.

Noņemt WordPress versijas numuru

WordPress pēc noklusējuma lapas HTML kodā atklāj savu versijas numuru — tas atvieglo uzbrucējiem atrast vietnes, kam vēl nav uzstādīts jaunākais drošības labojums.

phpremove_action('wp_head', 'wp_generator');

Izslēgt XML-RPC

XML-RPC ir vecāks WordPress interfeiss ārējiem savienojumiem (piem., senākām mobilajām lietotnēm) — tas ir arī izplatīts brute-force uzbrukumu mērķis. Ja to nelieto (lielākā daļa vietņu nelieto), droši izslēdz.

phpadd_filter('xmlrpc_enabled', '__return_false');

Izslēgt komentārus pilnībā

Aizver komentārus visos esošajos ierakstos, noņem komentāru atbalstu no ierakstu/lapu tipiem un paslēpj "Komentāri" izvēlni admin panelī — der vietnēm, kur komentāri nemaz nav vajadzīgi.

php// 1) Aizver komentārus/trackback visiem esošajiem ierakstiem un lapām
function wpds_disable_comments_status() {
    return false;
}
add_filter('comments_open', 'wpds_disable_comments_status', 20, 2);
add_filter('pings_open', 'wpds_disable_comments_status', 20, 2);

// 2) Noņem komentāru atbalstu no ierakstu/lapu tipiem
add_action('init', function() {
    remove_post_type_support('post', 'comments');
    remove_post_type_support('page', 'comments');
});

// 3) Paslēpj "Komentāri" admin izvēlnē
add_action('admin_menu', function() {
    remove_menu_page('edit-comments.php');
});

Paslēpt admin izvēlnes punktus

Vienkāršo admin paneli parastiem redaktoriem, paslēpjot izvēlnes punktus, kas viņiem nav vajadzīgi.

phpadd_action('admin_menu', function() {
    if (current_user_can('manage_options')) return; // administratori redz visu

    remove_menu_page('tools.php');       // Rīki
    remove_menu_page('edit-comments.php'); // Komentāri
    remove_menu_page('plugins.php');     // Spraudņi
}, 999); // liels skaitlis — izpildās PĒC visiem, kas izveido izvēlnes

Standarta izvēlnes punktu identifikatorus (kā tools.php, edit-comments.php) atrodi WordPress oficiālajā remove_menu_page() dokumentācijā. Pielāgota spraudņa izveidoto izvēlni (piem., no kāda uzstādīta spraudņa) paslēpj tāpat, izmantojot tā reģistrēto slug.

Pieteikšanās logo & saite

Nomaina noklusējuma WordPress logo /wp-login.php lapā pret savas vietnes logo.

phpadd_action('login_enqueue_scripts', function() {
    $logo = get_template_directory_uri() . '/assets/logo.png';
    ?>
    <style>
        #login h1 a {
            background-image: url(<?= esc_url($logo) ?>);
            background-size: contain;
            width: 100%;
            height: 80px;
        }
    </style>
    <?php
});

// Neobligāti — logo klikšķis ved uz tavu vietni, ne wordpress.org
add_filter('login_headerurl', 'home_url');

Piemērs augstāk izmanto fiksētu failu no tēmas mapes — labi der, ja logo maina reti, pats izstrādātājs. Ja logo un logo saite jāļauj mainīt klientam pašam (bez koda rediģēšanas), izmanto WordPress Customizer — WP_Customize_Image_Control uzreiz dod gatavu attēla augšupielādes lauku ar priekšskatījumu no Media Library, bez papildu JS rakstīšanas:

php// 1) Reģistrē attēla LAUKU un URL LAUKU — abi Izskats → Pielāgot → Vietnes identitāte
add_action('customize_register', function($wp_customize) {
    $wp_customize->add_setting('wpds_login_logo', [
        'type'    => 'option', // saglabā wp_options tabulā, nevis theme mod
        'default' => '',
    ]);
    $wp_customize->add_control(new WP_Customize_Image_Control($wp_customize, 'wpds_login_logo_control', [
        'label'    => 'Pieteikšanās lapas logo',
        'section'  => 'title_tagline', // jau esoša "Vietnes identitāte" sadaļa
        'settings' => 'wpds_login_logo',
    ]));

    // Otrs, pavisam atsevišķs lauks — kur ved klikšķis uz logo
    $wp_customize->add_setting('wpds_login_logo_url', [
        'type'              => 'option',
        'default'           => '',
        'sanitize_callback' => 'esc_url_raw', // obligāti — lauks ir brīvs teksts, ne attēla ID
    ]);
    $wp_customize->add_control('wpds_login_logo_url', [
        'label'       => 'Logo saite (atstāj tukšu, lai vestu uz sākumlapu)',
        'section'     => 'title_tagline',
        'type'        => 'url',
    ]);
});

// 2) Nolasa saglabāto attēlu un izmanto to — WP_Customize_Image_Control jau
// pats saglabā GATAVU attēla URL (nevis tikai ID), tāpēc get_option() pietiek
add_action('login_enqueue_scripts', function() {
    $logo = get_option('wpds_login_logo');
    if (!$logo) return; // nekas nav augšupielādēts — paliek WordPress noklusējuma logo
    ?>
    <style>
        #login h1 a {
            background-image: url(<?= esc_url($logo) ?>);
            background-size: contain;
            width: 100%;
            height: 80px;
        }
    </style>
    <?php
});

// 3) Nolasa saglabāto URL — ja lauks tukšs, atgriežas pie WordPress noklusējuma (home_url)
add_filter('login_headerurl', function($noklusejuma_url) {
    $custom_url = get_option('wpds_login_logo_url');
    return $custom_url ? esc_url($custom_url) : $noklusejuma_url;
});

Šis piemērs ir pilnībā pašpietiekams — pēc iekopēšanas klients uzreiz redz jaunus "Pieteikšanās lapas logo" un "Logo saite" laukus Izskats → Pielāgot → Vietnes identitāte, ar pogu "Izvēlēties attēlu", kas atver Media Library. Nekas papildus (admin lapa, JS) nav jāraksta — abi ievades tipi to visu jau dara paši.

Novirzīšana pēc pieteikšanās (pēc lomas)

Pēc pieteikšanās administratorus nosūta uz admin paneli, bet parastos lietotājus (piem., abonentus) — uz konta lapu, nevis noklusējuma admin dashboard.

phpadd_filter('login_redirect', function($parasta_adrese, $pieprasita_adrese, $user) {
    if ($user instanceof WP_User && in_array('administrator', $user->roles, true)) {
        return admin_url();
    }
    return home_url('/mans-konts/');
}, 10, 3);

Izraksta (excerpt) garums

Noklusējuma izraksta garums ir 55 vārdi — šis filtrs to pielāgo pēc vajadzības.

phpadd_filter('excerpt_length', function($garums) {
    return 20; // vārdu skaits
});

// Neobligāti — nomaina noklusējuma "[...]" beigās uz kaut ko citu
add_filter('excerpt_more', function() {
    return '…';
});

Pielāgots attēla izmērs

WordPress automātiski ģenerē vairākus attēla izmērus katrai augšupielādei (thumbnail, medium, large) — šis pievieno vēl vienu, savu, izmēru tam pašam mehānismam.

phpadd_action('after_setup_theme', function() {
    // nosaukums, platums, augstums, vai apgriezt (true = precīzi izmēri)
    add_image_size('kartes-attels', 400, 300, true);
});

Lietošana veidnē:

php<?php if (has_post_thumbnail()): ?>
    <?= get_the_post_thumbnail(get_the_ID(), 'kartes-attels') ?>
<?php endif; ?>

Jauns izmērs attiecas tikai uz jaunām augšupielādēm — jau esošajiem attēliem šī izmēra versijas nav. Lai ģenerētu trūkstošos izmērus arī vecajiem attēliem, izmanto spraudni "Regenerate Thumbnails" vai WP-CLI komandu wp media regenerate.

Izslēgt emoji skriptus (veiktspēja)

WordPress pēc noklusējuma katrā lapā ielādē papildu skriptu emoji attēlošanai vecākos pārlūkos — lielākajai daļai vietņu tas nav vajadzīgs un nedaudz palēnina lapu.

phpadd_action('init', function() {
    remove_action('wp_head', 'print_emoji_detection_script', 7);
    remove_action('wp_print_styles', 'print_emoji_styles');
    remove_action('admin_print_scripts', 'print_emoji_detection_script');
    remove_action('admin_print_styles', 'print_emoji_styles');
});
