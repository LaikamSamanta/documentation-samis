Sākums React Cheatsheet

React Cheatsheet

Ātrās uzziņas lapa - katrai kartiņai īss skaidrojums un koda fragments. Pilnus piemērus un paskaidrojumus skaties pilnajā React dokumentācijā.

Hooks JSX & Props Saraksti & formas Router Testēšana

Hooks

useState

State + funkcija to mainīt.

const [n, setN] = useState(0);

useEffect

Kods pēc renderēšanas, ar cleanup.

useEffect(() => {
  const id = setInterval(tick, 1000);
  return () => clearInterval(id);
}, []);

useRef

DOM piekļuve vai vērtība bez re-renderēšanas.

const ref = useRef(null);
ref.current.focus();

useMemo

Pārrēķina TIKAI, kad atkarības mainās.

const filtered = useMemo(() => filter(items, q), [q]);

useContext

Dati bez props cauri katrai starpkomponentei.

const { theme } = useContext(ThemeContext);

JSX & Props

Props destructuring

Izņem konkrētus laukus tieši parametros.

function User({ name, age }) { ... }

Fragment

Vairāki elementi bez papildu DOM mezgla.

<><h1>A</h1><p>B</p></>

className

class ir rezervēts vārds JS - JSX izmanto className.

<div className="card">

children

Automātisks prop starp atverošo/aizverošo tagu.

function Card({ children }) { return <div>{children}</div>; }

Saraksti & formas

.map() + key

Unikāls key katram elementam, ne indekss.

{items.map(i => <li key={i.id}>{i.name}</li>)}

Controlled input

value + onChange vienmēr kopā.

<input value={v} onChange={e => setV(e.target.value)} />

Ternārais

Divas alternatīvas vienā izteiksmē.

{loading ? <Spinner /> : <Content />}

preventDefault

Aptur pārlūka noklusējuma formas pārlādi.

function onSubmit(e) { e.preventDefault(); }

Router

Instalācija

Oficiālā maršrutēšanas bibliotēka.

npm install react-router-dom

Routes

Ceļa-uz-komponentu piesaiste.

<Route path="/posts/:id" element={<Post />} />

useParams

Nolasa URL parametrus.

const { id } = useParams();

Link

Navigācija BEZ pilnas lapas pārlādes.

<Link to="/posts/5">Raksts</Link>

Testēšana

render + screen

Renderē komponentu testa vidē.

render(<Counter />);
screen.getByText('Skaits: 0');

fireEvent

Simulē lietotāja darbību.

fireEvent.click(screen.getByText('+'));

jest-dom setup

Nepieciešams toBeInTheDocument() u.c.

// src/setupTests.js
import '@testing-library/jest-dom';

Palaišana

Izpilda visu testu komplektu.

npx vitest run
