Mazi, praktiski Python skripti ikdienas darbu automatizēšanai — ne web izstrāde, bet noderīgi rīki, ko palaist lokāli no komandrindas. Katram skriptam — kas jāuzinstalē pirms palaišanas, pilns kods, ko var iekopēt un uzreiz palaist, un komandas soli pa solim.

YouTube video masveida lejupielāde

Skripts, kas lejupielādē vairākus YouTube video paralēli (vairākus vienlaicīgi, nevis vienu pēc otra), izmantojot yt-dlp bibliotēku video/audio iegūšanai un ffmpeg to salīmēšanai vienā failā.

Kas jāuzinstalē pirms palaišanas

1. Python 3.8+

Jābūt instalētam un pieejamam no komandrindas (python --version).

2. yt-dlp bibliotēka

pip install yt-dlp — pats video/audio lejupielādes rīks.

3. FFmpeg

Nepieciešams, lai salīmētu atsevišķi lejupielādēto video un audio straumi vienā failā — bez tā video var iznākt bez skaņas.

text1. Instalē yt-dlp:
   pip install yt-dlp

2. Instalē FFmpeg (Windows, ar winget):
   winget install ffmpeg

3. Restartē termināli — PATH atjaunojas tikai jaunā sesijā

4. Pārbaudi, vai abi ir pieejami:
   yt-dlp --version
   ffmpeg -version

Pilns skripts

pythonimport concurrent.futures
import yt_dlp

def lade_video(url):
    """Lejupielādē vienu video maksimālajā kvalitātē un salīmē video ar audio, izmantojot ffmpeg."""
    ydl_opts = {
        # Automātiski paņem labāko video (4K/2K/1080p) un labāko audio
        'format': 'bestvideo[ext=mp4]+bestaudio[ext=m4a]/best[ext=mp4]/best',
        # Saglabāšanas formāts: Video Nosaukums.mp4
        'outtmpl': '%(title)s.%(ext)s',
    }

    try:
        print(f"➜ Sāk lejupielādēt: {url}")
        with yt_dlp.YoutubeDL(ydl_opts) as ydl:
            ydl.download([url])
        print(f"✓ Veiksmīgi lejupielādēts: {url}\n")
    except Exception as e:
        print(f"✗ Kļūda ar {url}: {e}\n")

def masveida_lejupielade(saites, max_paraleli=3):
    """Palaiž vairāku video lejupielādi vienlaicīgi."""
    print(f"=== SĀK {len(saites)} VIDEO LEJUPIELĀDI ===")

    # ThreadPoolExecutor palaiž vairākas lejupielādes paralēli, nevis vienu pēc otras
    with concurrent.futures.ThreadPoolExecutor(max_workers=max_paraleli) as executor:
        executor.map(lade_video, saites)

    print("=== VISI VIDEO IR LEJUPIELĀDĒTI! ===")

if __name__ == "__main__":
    # Ievieto šeit savus YouTube linkus
    video_saraksts = [
        "https://www.youtube.com/watch?v=piemers1",
        "https://www.youtube.com/watch?v=piemers2",
        "https://www.youtube.com/watch?v=piemers3",
    ]

    # max_paraleli=3 nozīmē 3 video lejupielādē vienlaicīgi
    masveida_lejupielade(video_saraksts, max_paraleli=3)

Palaišana

text1. Saglabā skriptu kā lejupielade.py

2. Atver termināli tajā pašā mapē, kur atrodas fails

3. Palaid:
   python lejupielade.py

4. Video saglabāsies tajā pašā mapē, kurā palaists skripts

concurrent.futures

Python iebūvēts modulis paralēlai izpildei — nav jāuzinstalē atsevišķi. ThreadPoolExecutor pārvalda pavedienu (thread) kopu automātiski.

executor.map()

Izsauc lade_video() katram sarakstā esošajam URL, izmantojot brīvu pavedienu no kopas — nākamā lejupielāde sākas, tiklīdz atbrīvojas kāds no max_paraleli pavedieniem.

Kāpēc try/except katrā video

Ja viens URL ir nederīgs vai video izdzēsts, kļūda tiek noķerta un izdrukāta, bet pārējo saraksta video lejupielāde turpinās netraucēti.

Divi praktiski ierobežojumi: (1) max_paraleli nevajadzētu likt daudz augstāku par 3-5 — pārāk daudz paralēlu pieprasījumu var YouTube pusē izraisīt pagaidu bloķēšanu. (2) Lejupielādē tikai saturu, kam tev ir tiesības to saglabāt (paša augšupielādēts video/straume, saturs ar skaidru atļauju) — YouTube lietošanas noteikumi masveida lejupielādi svešam saturam neatļauj.

Attēlu masveida izmēra maiņa

Samazina visu norādītās mapes attēlu platumu un failu izmēru — noderīgi pirms attēlu augšupielādes WordPress vietnē, kad kameras/telefona attēli ir nevajadzīgi lieli (piem., 4000px platumā, kur reāli vajag 1600px).

Uzinstalē: pip install Pillow

pythonfrom PIL import Image
import os

def samazinat_attelus(mape, max_platums=1600, kvalitate=85):
    """Samazina visu mapes attēlu izmēru un pārraksta tos vietā."""
    for fails in os.listdir(mape):
        if not fails.lower().endswith(('.jpg', '.jpeg', '.png')):
            continue

        cels = os.path.join(mape, fails)
        with Image.open(cels) as img:
            if img.width > max_platums:
                attieciba = max_platums / img.width
                jauns_augstums = int(img.height * attieciba)
                img = img.resize((max_platums, jauns_augstums), Image.LANCZOS)
            img.save(cels, quality=kvalitate, optimize=True)
        print(f"✓ {fails}")

if __name__ == "__main__":
    samazinat_attelus("attēli")

Skripts pārraksta oriģinālos failus vietā (img.save(cels, ...)) — ja oriģinālie, pilna izmēra attēli vēl ir vajadzīgi, vispirms izveido to kopiju citā mapē, pirms palaid šo skriptu.

PDF failu apvienošana

Apvieno vairākus PDF failus vienā, tādā secībā, kādā tie norādīti sarakstā — noderīgi, piem., apvienojot skenētus dokumentus vai atsevišķas rēķina daļas, bez online rīkiem, kur faili iet caur svešu serveri.

Uzinstalē: pip install pypdf

pythonfrom pypdf import PdfWriter

def apvienot_pdf(faili, izvades_fails="apvienots.pdf"):
    apvienotajs = PdfWriter()
    for fails in faili:
        apvienotajs.append(fails)
    apvienotajs.write(izvades_fails)
    apvienotajs.close()
    print(f"✓ Izveidots: {izvades_fails}")

if __name__ == "__main__":
    apvienot_pdf(["dala1.pdf", "dala2.pdf", "dala3.pdf"])

apvienotajs.append(fails) pieņem gan faila ceļu (kā šeit), gan jau atvērtu faila objektu — der arī, ja PDF vispirms jāapstrādā citādi (piem., jāizfiltrē konkrētas lapas ar append(fails, pages=(0, 3))).

Lejupielāžu mapes automātiska sakārtošana

Pārvieto failus no vienas mapes (piem., Lejupielādes) apakšmapēs pēc faila tipa — attēli, dokumenti, arhīvi, video katrs savā mapē. Nelieto nekādas ārējas bibliotēkas, tikai Python standarta moduļus.

pythonimport os
import shutil

MAPES_PA_TIPIEM = {
    "Attēli": [".jpg", ".jpeg", ".png", ".gif", ".webp"],
    "Dokumenti": [".pdf", ".docx", ".txt", ".xlsx"],
    "Arhivi": [".zip", ".rar", ".7z"],
    "Video": [".mp4", ".mkv", ".mov"],
}

def sakartot_mapi(mape):
    for fails in os.listdir(mape):
        cels = os.path.join(mape, fails)
        if os.path.isdir(cels):
            continue

        pletiens = os.path.splitext(fails)[1].lower()
        for mapes_nosaukums, pletieni in MAPES_PA_TIPIEM.items():
            if pletiens in pletieni:
                merkis = os.path.join(mape, mapes_nosaukums)
                os.makedirs(merkis, exist_ok=True)
                shutil.move(cels, os.path.join(merkis, fails))
                print(f"→ {fails} pārvietots uz {mapes_nosaukums}/")
                break

if __name__ == "__main__":
    sakartot_mapi(os.path.expanduser("~/Downloads"))

shutil.move() failus pārvieto (ne kopē) — pirmajā reizē izmēģini uz mapi ar dažiem testa failiem, ne uzreiz uz reālo Lejupielādes mapi, lai pārliecinātos, ka sadalījums pa tipiem atbilst tavām vēlmēm.

Vietnes darbības pārbaude (uptime)

Ik pēc noteikta laika pārbauda, vai norādītās vietnes atbild — noderīgi, ja apkalpo klientu vietnes un gribas uzzināt par dīkstāvi ātrāk, nekā to pamana klients.

Uzinstalē: pip install requests

pythonimport requests
import time

VIETNES = [
    "https://piemers.lv",
    "https://otra-vietne.lv",
]

def parbaudit_vietnes():
    for url in VIETNES:
        try:
            atbilde = requests.get(url, timeout=10)
            if atbilde.status_code == 200:
                print(f"✓ {url} — strādā ({atbilde.status_code})")
            else:
                print(f"⚠ {url} — neparasts statuss ({atbilde.status_code})")
        except requests.exceptions.RequestException as e:
            print(f"✗ {url} — NESTRĀDĀ: {e}")

if __name__ == "__main__":
    while True:
        parbaudit_vietnes()
        print("-" * 40)
        time.sleep(300)  # pārbauda ik pēc 5 minūtēm

Šis piemērs tikai izdrukā rezultātu terminālī, kur tas paliek redzams tikai tik ilgi, kamēr skripts palaists. Reālai lietošanai der to papildināt ar paziņojumu (piem., e-pasts ar smtplib vai ziņa uz Slack/Telegram webhook), kas nosūtās tikai tad, kad statuss mainās no "strādā" uz "nestrādā" — nevis pie katras pārbaudes.
