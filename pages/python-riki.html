Mazi, praktiski Python skripti ikdienas darbu automatizēšanai - ne web izstrāde, bet noderīgi rīki, ko palaist lokāli no komandrindas. Katram skriptam - kas jāuzinstalē pirms palaišanas, pilns kods, ko var iekopēt un uzreiz palaist, un komandas soli pa solim.

YouTube video masveida lejupielāde

Skripts, kas lejupielādē vairākus YouTube video paralēli (vairākus vienlaicīgi, nevis vienu pēc otra), izmantojot yt-dlp bibliotēku video/audio iegūšanai un ffmpeg to salīmēšanai vienā failā.

Kas jāuzinstalē pirms palaišanas

1. Python 3.8+

Jābūt instalētam un pieejamam no komandrindas (python --version).

2. yt-dlp bibliotēka

pip install yt-dlp - pats video/audio lejupielādes rīks.

3. FFmpeg

Nepieciešams, lai salīmētu atsevišķi lejupielādēto video un audio straumi vienā failā - bez tā video var iznākt bez skaņas.

text1. Instalē yt-dlp:
   pip install yt-dlp

2. Instalē FFmpeg (Windows, ar winget):
   winget install ffmpeg

3. Restartē termināli - PATH atjaunojas tikai jaunā sesijā

4. Pārbaudi, vai abi ir pieejami:
   yt-dlp --version
   ffmpeg -version

Pilns skripts

pythonimport sys
sys.stdout.reconfigure(encoding="utf-8")  # bez šī print() ar ā/ē/ī/š var avarēt Windows terminālī

import concurrent.futures
import yt_dlp

def lade_video(url):
    """Lejupielādē vienu video maksimālajā kvalitātē un salīmē video ar audio, izmantojot ffmpeg."""
    ydl_opts = {
        # Automātiski paņem labāko video (4K/2K/1080p) un labāko audio
        'format': 'bestvideo[ext=mp4]+bestaudio[ext=m4a]/best[ext=mp4]/best',
        # Saglabāšanas formāts: Video Nosaukums.mp4
        'outtmpl': '%(title)s.%(ext)s',
    }

    try:
        print(f"➜ Sāk lejupielādēt: {url}")
        with yt_dlp.YoutubeDL(ydl_opts) as ydl:
            ydl.download([url])
        print(f"✓ Veiksmīgi lejupielādēts: {url}\n")
    except Exception as e:
        print(f"✗ Kļūda ar {url}: {e}\n")

def masveida_lejupielade(saites, max_paraleli=3):
    """Palaiž vairāku video lejupielādi vienlaicīgi."""
    print(f"=== SĀK {len(saites)} VIDEO LEJUPIELĀDI ===")

    # ThreadPoolExecutor palaiž vairākas lejupielādes paralēli, nevis vienu pēc otras
    with concurrent.futures.ThreadPoolExecutor(max_workers=max_paraleli) as executor:
        executor.map(lade_video, saites)

    print("=== VISI VIDEO IR LEJUPIELĀDĒTI! ===")

if __name__ == "__main__":
    # Ievieto šeit savus YouTube linkus
    video_saraksts = [
        "https://www.youtube.com/watch?v=piemers1",
        "https://www.youtube.com/watch?v=piemers2",
        "https://www.youtube.com/watch?v=piemers3",
    ]

    # max_paraleli=3 nozīmē 3 video lejupielādē vienlaicīgi
    masveida_lejupielade(video_saraksts, max_paraleli=3)

concurrent.futures

Python iebūvēts modulis paralēlai izpildei - nav jāuzinstalē atsevišķi. ThreadPoolExecutor pārvalda pavedienu (thread) kopu automātiski.

executor.map()

Izsauc lade_video() katram sarakstā esošajam URL, izmantojot brīvu pavedienu no kopas - nākamā lejupielāde sākas, tiklīdz atbrīvojas kāds no max_paraleli pavedieniem.

Kāpēc try/except katrā video

Ja viens URL ir nederīgs vai video izdzēsts, kļūda tiek noķerta un izdrukāta, bet pārējo saraksta video lejupielāde turpinās netraucēti.

Divi praktiski ierobežojumi: (1) max_paraleli nevajadzētu likt daudz augstāku par 3-5 - pārāk daudz paralēlu pieprasījumu var YouTube pusē izraisīt pagaidu bloķēšanu. (2) Lejupielādē tikai saturu, kam tev ir tiesības to saglabāt (paša augšupielādēts video/straume, saturs ar skaidru atļauju) - YouTube lietošanas noteikumi masveida lejupielādi svešam saturam neatļauj.

Attēlu masveida izmēra maiņa

Samazina visu norādītās mapes attēlu platumu un failu izmēru - noderīgi pirms attēlu augšupielādes WordPress vietnē, kad kameras/telefona attēli ir nevajadzīgi lieli (piem., 4000px platumā, kur reāli vajag 1600px).

Uzinstalē: pip install Pillow

pythonimport sys
sys.stdout.reconfigure(encoding="utf-8")  # bez šī print() ar ā/ē/ī/š var avarēt Windows terminālī

from PIL import Image
import os

def samazinat_attelus(mape, max_platums=1600, kvalitate=85):
    """Samazina visu mapes attēlu izmēru un pārraksta tos vietā."""
    for fails in os.listdir(mape):
        if not fails.lower().endswith(('.jpg', '.jpeg', '.png')):
            continue

        cels = os.path.join(mape, fails)
        with Image.open(cels) as img:
            if img.width > max_platums:
                attieciba = max_platums / img.width
                jauns_augstums = int(img.height * attieciba)
                img = img.resize((max_platums, jauns_augstums), Image.LANCZOS)
            img.save(cels, quality=kvalitate, optimize=True)
        print(f"✓ {fails}")

if __name__ == "__main__":
    samazinat_attelus("attēli")

Skripts pārraksta oriģinālos failus vietā (img.save(cels, ...)) - ja oriģinālie, pilna izmēra attēli vēl ir vajadzīgi, vispirms izveido to kopiju citā mapē, pirms palaid šo skriptu.

PDF failu apvienošana

Apvieno vairākus PDF failus vienā, tādā secībā, kādā tie norādīti sarakstā - noderīgi, piem., apvienojot skenētus dokumentus vai atsevišķas rēķina daļas, bez online rīkiem, kur faili iet caur svešu serveri.

Uzinstalē: pip install pypdf

pythonimport sys
sys.stdout.reconfigure(encoding="utf-8")  # bez šī print() ar ā/ē/ī/š var avarēt Windows terminālī

from pypdf import PdfWriter

def apvienot_pdf(faili, izvades_fails="apvienots.pdf"):
    apvienotajs = PdfWriter()
    for fails in faili:
        apvienotajs.append(fails)
    apvienotajs.write(izvades_fails)
    apvienotajs.close()
    print(f"✓ Izveidots: {izvades_fails}")

if __name__ == "__main__":
    apvienot_pdf(["dala1.pdf", "dala2.pdf", "dala3.pdf"])

apvienotajs.append(fails) pieņem gan faila ceļu (kā šeit), gan jau atvērtu faila objektu - der arī, ja PDF vispirms jāapstrādā citādi (piem., jāizfiltrē konkrētas lapas ar append(fails, pages=(0, 3))).

Lejupielāžu mapes automātiska sakārtošana

Pārvieto failus no vienas mapes (piem., Lejupielādes) apakšmapēs pēc faila tipa - attēli, dokumenti, arhīvi, video katrs savā mapē. Nelieto nekādas ārējas bibliotēkas, tikai Python standarta moduļus.

pythonimport sys
sys.stdout.reconfigure(encoding="utf-8")  # bez šī print() ar ā/ē/ī/š var avarēt Windows terminālī

import os
import shutil

MAPES_PA_TIPIEM = {
    "Attēli": [".jpg", ".jpeg", ".png", ".gif", ".webp"],
    "Dokumenti": [".pdf", ".docx", ".txt", ".xlsx"],
    "Arhivi": [".zip", ".rar", ".7z"],
    "Video": [".mp4", ".mkv", ".mov"],
}

def sakartot_mapi(mape):
    for fails in os.listdir(mape):
        cels = os.path.join(mape, fails)
        if os.path.isdir(cels):
            continue

        pletiens = os.path.splitext(fails)[1].lower()
        for mapes_nosaukums, pletieni in MAPES_PA_TIPIEM.items():
            if pletiens in pletieni:
                merkis = os.path.join(mape, mapes_nosaukums)
                os.makedirs(merkis, exist_ok=True)
                shutil.move(cels, os.path.join(merkis, fails))
                print(f"→ {fails} pārvietots uz {mapes_nosaukums}/")
                break

if __name__ == "__main__":
    sakartot_mapi(os.path.expanduser("~/Downloads"))

shutil.move() failus pārvieto (ne kopē) - pirmajā reizē izmēģini uz mapi ar dažiem testa failiem, ne uzreiz uz reālo Lejupielādes mapi, lai pārliecinātos, ka sadalījums pa tipiem atbilst tavām vēlmēm.

# daudzas vietnes (Cloudflare u.tml. aizsardzība) atgriež 403 pieprasījumiem
# bez "pārlūka izskata" - bez šī requests sevi piesakās kā "python-requests/x.x"
# un tiek nobloķēts, pat ja vietne pati par sevi strādā pilnīgi normāli
HEADERS = {

}

# ja kāda vietne ir aizsargāta ar paroli servera līmenī (piem. Plesk "Password
# protection" konkrētai mapei/domēnam - HTTP Basic Auth), pievieno tās
# lietotājvārdu/paroli šeit. Vietnēm, kas šajā vārdnīcā NAV, PAROLES.get(url)
# atgriež None, un requests to interpretē tieši tāpat kā auth vispār nesūtot
PAROLES = {

}

# atceras katras vietnes pēdējo zināmo statusu, lai paziņotu tikai tad, kad tas MAINĀS
iepriksejie_statusi = {}

# --- Paziņojumu logi: VIENS kopīgs Tk process visiem, ar rindu citiem pavedieniem ---
# (nevis atsevišķs tk.Tk() katram paziņojumam savā pavedienā - tas var izraisīt,
# ka pie diviem gandrīz vienlaicīgiem paziņojumiem redzams tikai viens no tiem)
_pazinojumu_rinda = queue.Queue()
_aktivie_logi = []
_bildes_cache = []  # jāpatur reference uz katru PhotoImage - citādi Python to izmet
                    # (garbage collection) un ikona pazūd, kaut Canvas to joprojām rāda

def _apalu_taisnstura(c, x1, y1, x2, y2, r, **kwargs):
    # tkinter Canvas nemāk zīmēt noapaļotus taisnstūrus pats - tā to uzbūvē
    # no punktiem ar smooth=True (izliektas līknes starp punktiem)
    punkti = [
        x1+r, y1, x2-r, y1, x2, y1, x2, y1+r,
        x2, y2-r, x2, y2, x2-r, y2, x1+r, y2,
        x1, y2, x1, y2-r, x1, y1+r, x1, y1,
    ]
    return c.create_polygon(punkti, smooth=True, **kwargs)

def _gluds_aplis(krasa, izmers=32):
    # canvas.create_oval() ZĪMĒ ROBAINU apli - Canvas nepretalaiso savas formas.
    # Risinājums: uzzīmē apli PIL 4x lielāku, tad samazina ar LANCZOS - samazinot
    # augstas izšķirtspējas attēlu, malas dabiski izlīdzinās (supersampling)
    merogs = 4
    img = Image.new("RGBA", (izmers*merogs, izmers*merogs), (0, 0, 0, 0))
    ImageDraw.Draw(img).ellipse((0, 0, izmers*merogs-1, izmers*merogs-1), fill=krasa)
    img = img.resize((izmers, izmers), Image.LANCZOS)
    foto = ImageTk.PhotoImage(img)
    _bildes_cache.append(foto)
    return foto

def _atskanot_skanu(ir_labi):

        winsound.Beep(880, 90)
        winsound.Beep(1175, 130)
    else:

def _izveidot_pazinojuma_logu(root, virsraksts, zina, ir_labi):
    logs = tk.Toplevel(root)
    logs.overrideredirect(True)
    logs.attributes("-topmost", True)
    logs.attributes("-alpha", 0.0)  # sākas neredzams, tad iebalsinās

    platums, augstums, atstarpe = 360, 100, 14
    # "burvju" krāsa - jebkur, kur tā parādās logā, kļūst pilnībā caurspīdīga.
    # Tas ir vienīgais veids, kā panākt TIEŠI noapaļotus stūrus bez rāmja logā,
    # kam ir overrideredirect(True) - tā vietā, lai logs būtu taisnstūris ar
    # noapaļotu saturu, pats logs kļūst neredzams tur, kur nav "stikla" formas
    magic = "#0a0a0c"
    logs.configure(bg=magic)
    logs.attributes("-transparentcolor", magic)

    x = logs.winfo_screenwidth() - platums - 24
    y = logs.winfo_screenheight() - augstums - 60 - len(_aktivie_logi) * (augstums + atstarpe)
    logs.geometry(f"{platums}x{augstums}+{x}+{y}")

    canvas = tk.Canvas(logs, width=platums, height=augstums, bg=magic, highlightthickness=0)
    canvas.pack(fill="both", expand=True)

    krasa_akcents = "#4ade80" if ir_labi else "#f87171"
    stikla_krasa = "#14141f"   # tumšs, puscaurspīdīgas stikla iespaida panelis
    apmales_krasa = "#3a3a55"  # smalka gaiša mala ap paneli

    _apalu_taisnstura(canvas, 1, 1, platums-1, augstums-1, 22,
                     fill=stikla_krasa, outline=apmales_krasa, width=1)

    # ikona apļa nozīmītē - ✓ veiksmei, ✕ kļūdai, baltā krāsā labam kontrastam
    ikonas_izmers = 32
    ikonas_cx, ikonas_cy = 40, augstums // 2
    ikonas_bilde = _gluds_aplis(krasa_akcents, ikonas_izmers)
    canvas.create_image(ikonas_cx, ikonas_cy, image=ikonas_bilde)
    canvas.create_text(ikonas_cx, ikonas_cy, text=("✓" if ir_labi else "✕"), fill="white",
                        font=("Segoe UI", 13, "bold"))

    canvas.create_text(70, 32, text=virsraksts, fill="white", anchor="w", font=("Segoe UI", 11, "bold"))
    canvas.create_text(70, 56, text=zina, fill="#a6a3c4", anchor="w", font=("Segoe UI", 9), width=250)

    canvas.create_text(platums - 24, 20, text="✕", fill="#8b87a3",
                        font=("Segoe UI", 10, "bold"), tags="aizvert")

    def aizvert(event=None):
        if logs in _aktivie_logi:
            _aktivie_logi.remove(logs)
        logs.destroy()

    canvas.tag_bind("aizvert", "<Button-1>", aizvert)
    _aktivie_logi.append(logs)

    def iebalsinat(soli=0):
        if not logs.winfo_exists():
            return
        logs.attributes("-alpha", min(soli / 10, 0.93))
        if soli < 10:

    # NAV automātiskas aizvēršanās ar taimeri - logs paliek, kamēr pats nenospiež ✕

def _apstradat_pazinojumu_rindu(root):
    try:
        while True:
            virsraksts, zina, ir_labi = _pazinojumu_rinda.get_nowait()
            _izveidot_pazinojuma_logu(root, virsraksts, zina, ir_labi)
    except queue.Empty:
        pass
    root.after(150, lambda: _apstradat_pazinojumu_rindu(root))

def _palaist_pazinojumu_fonu():
    root = tk.Tk()
    root.withdraw()  # paslēpj tukšo galveno logu - redzami tikai paši paziņojumi
    _apstradat_pazinojumu_rindu(root)
    root.mainloop()

# VIENS fona pavediens ar VIENU Tk logu, kas apstrādā visus paziņojumus
threading.Thread(target=_palaist_pazinojumu_fonu, daemon=True).start()

def rada_pazinojumu(virsraksts, zina, ir_labi):
    _pazinojumu_rinda.put((virsraksts, zina, ir_labi))

def parbaudit_vienu_vietni(url):
    # ja VIETNES sarakstā ierakstīts tikai domēns bez "http(s)://" (piem. "piemers.lv"),
    # requests to uztver kā nederīgu URL un ziņotu "nestrādā" pat tad, ja vietne
    # tiešām strādā - šeit pievieno https:// automātiski, ja tā trūkst
    if not url.startswith(("http://", "https://")):
        url = "https://" + url

    try:
        atbilde = requests.get(url, timeout=10, headers=HEADERS, auth=PAROLES.get(url))
        if atbilde.status_code < 400:
            return "strada"
        print(f"  [{url}] atbildēja ar statusu {atbilde.status_code}")
        return "kluda"
    except requests.exceptions.SSLError:
        # serveris pats automātiski pāradresē http -> https, bet https pusē nav derīga
        # sertifikāta - tas NENOZĪMĒ, ka vietne ir lejā, tāpēc pārbauda vēlreiz bez
        # sertifikāta validācijas, lai redzētu, vai serveris tiešām atbild
        try:
            atbilde = requests.get(url, timeout=10, headers=HEADERS, auth=PAROLES.get(url), verify=False)
            if atbilde.status_code < 400:
                return "strada"
            print(f"  [{url}] atbildēja ar statusu {atbilde.status_code}")
            return "kluda"
        except requests.exceptions.RequestException as e2:
            print(f"  [{url}] SSL fallback arī neizdevās: {e2}")
            return "nestrada"
    except requests.exceptions.RequestException as e:
        # PARĀDA īsto kļūdu - bez šī nav iespējams zināt, vai vietne tiešām lejā,
        # vai to bloķē antivīruss/ugunsmūris/proxy uz ŠĪ datora
        print(f"  [{url}] kļūdas iemesls: {e}")
        return "nestrada"

# "strada"/"kluda"/"nestrada" iekšēji ir īsi, bez garumzīmēm, ērtākai
# salīdzināšanai kodā - šis vārdnīca dod tiem pareizu latviešu tekstu, ko
# tiešām rāda lietotājam (konsolē un paziņojumos)
STATUSA_TEKSTI = {
    "strada": "strādā",
    "kluda": "kļūda",
    "nestrada": "nestrādā",
}

def parbaudit_vietnes():
    for url in VIETNES:
        iepriksejais = iepriksejie_statusi.get(url)
        jaunais = parbaudit_vienu_vietni(url)

        if jaunais != iepriksejais:
            if jaunais == "strada" and iepriksejais is not None:
                rada_pazinojumu("Vietne atkal strādā", url, ir_labi=True)
            elif jaunais != "strada":
                rada_pazinojumu("Vietne nestrādā", url, ir_labi=False)
            print(f"{url} -> {STATUSA_TEKSTI[jaunais]}")

        iepriksejie_statusi[url] = jaunais

if __name__ == "__main__":
    while True:
        parbaudit_vietnes()
        time.sleep(300)  # pārbauda ik pēc 5 minūtēm

HEADERS (User-Agent)

Bez šī daudzas vietnes ar Cloudflare vai līdzīgu aizsardzību atgriež 403 pieprasījumam, kas nāk no python-requests - skripts to pareizi ziņotu kā "kluda", lai gan vietne apmeklētājam pārlūkā strādā normāli. Ar pārlūka izskata galveni serveris pieprasījumu neatšķir no īsta apmeklētāja.

PAROLES (Basic Auth)

Ja vietne servera līmenī aizsargāta ar paroli (piem. Plesk "Password protection" konkrētai mapei/domēnam), bez pieteikšanās dati serveris atgriež 401. Pievieno vietnes URL, lietotājvārdu un paroli PAROLES vārdnīcā - vietnēm bez ieraksta tur nekas nemainās, jo PAROLES.get(url) tām atgriež None.

Kopīgs Tk process + rinda

Iepriekšējā versijā katrs paziņojums izveidoja savu tk.Tk() savā pavedienā - divi gandrīz vienlaicīgi paziņojumi dažkārt "sacentās" un redzams bija tikai viens. Tagad ir viens fona pavediens ar vienu logu, kas ik pēc 150ms pārbauda rindu un droši izveido jaunu paziņojumu katram ierakstam.

Iebalsināšanās animācija

attributes("-alpha", ...) pakāpeniski ceļ logu no caurspīdīga uz gandrīz pilnībā redzamu 150ms laikā - vienkāršs veids, kā panākt mīkstāku, modernāku parādīšanos bez ārējām bibliotēkām.

Sakrāvums (stacking)

Ja vairāki paziņojumi parādās gandrīz vienlaicīgi, katrs nākamais tiek novietots virs iepriekšējā (nevis pāri tam) - len(_aktivie_logi) nosaka nobīdi uz augšu.

Noapaļoti stūri (-transparentcolor)

tkinter nemāk noapaļot loga stūrus tieši, tāpēc logam iestata "burvju" krāsu, kas kļūst pilnībā caurspīdīga - un uz tā zīmē noapaļotu formu (Canvas.create_polygon(..., smooth=True)). Rezultātā redzams tikai pats noapaļotais panelis, ne taisnstūra logs ap to. Pārbaudīts ar ekrānuzņēmumu - stūri tiešām caurspīdīgi, ne tikai teorētiski.

Divtoņu skaņa (winsound.Beep)

Nevis viens plakans sistēmas pīkstiens, bet divi īsi toņi pēc kārtas - augšupejoši (880→1175 Hz) veiksmei, lejupejoši (392→330 Hz) kļūdai. Skaņu ģenerē pats Python, nevis atskaņo failu - nekas jāuzinstalē nav.

Gluds ikonas aplis (Pillow)

canvas.create_oval() zīmē robainu, nepretalaisinātu apli - īpaši pamanāms mazā izmērā. Risinājums: uzzīmē apli ar Pillow 4x lielākā izšķirtspējā, tad samazina ar Image.LANCZOS - samazinot augstas izšķirtspējas attēlu, malas dabiski izlīdzinās (supersampling). Pārbaudīts ar ekrānuzņēmumu - salīdzinājumā ar iepriekšējo versiju aplis tagad ir gluds.

Paliek, kamēr pats neaizver

Nav automātiska taimera - logs paliek ekrānā neierobežoti ilgi, kamēr nenospiež ✕. _bildes_cache saraksts ir nepieciešams, jo PhotoImage objekti pazūd (tos izmet garbage collector), ja uz tiem nepaliek neviena Python mainīgā - pat ja Canvas tos joprojām mēģina rādīt.

Kāpēc pirmajā palaišanas reizē varētu nebūt NEVIENA paziņojuma: tas ir ar nodomu, ne kļūda. Paziņojums nāk tikai divos gadījumos - vietne pārstāj strādāt, vai vietne atkal sāk strādāt pēc tam, kad bija zināms, ka tā nestrādāja. Ja pirmajā pārbaudē visas vietnes jau strādā, nav "no kā atgūties" - tāpēc paziņojuma nav, tikai teksts terminālī (url -> strādā). Paziņojumu redzēsi tad, kad kāda vietne tiešām pārstās/atsāks strādāt starp pārbaudēm.

Kompromiss salīdzinājumā ar Windows iebūvēto paziņojumu sistēmu (Action Center): šie logi neparādās paziņojumu vēsturē un pēc aizvēršanas nekur nepaliek. Un, tāpat kā iepriekš: paziņojums parādās tikai uz šī paša datora, kamēr skripts tur palaists.

PAROLES vārdnīcā parole ir tekstā, tieši skripta failā - tas ir pietiekami drošs risinājums, kamēr skripts paliek TIKAI Tavā datorā un netiek dalīts/commitots publiskā vietā (piem., GitHub). Ja skripts jebkad nonāk versiju kontrolē vai tiek dalīts, pārliecinies, ka parole tur nenonāk - vai nu izslēdz to failu no Git (.gitignore), vai nolasi paroli no vides mainīgā (os.environ) tā vietā, lai to rakstītu tieši kodā.

Godīgi par "glassmorphism": augstāk redzamais panelis ir puscaurspīdīgs, noapaļots, tumšs "stikla" izskata panelis - bet tas nav īsts fona izpludinājums (blur-behind), jo tīrs tkinter to nemāk. Ja gribi arī reālu Windows 11 "Acrylic"/"Mica" fona izpludinājumu (redzēt izplūdušu darbvirsmu caur logu, tāpat kā Windows sistēmas paziņojumos), der izmēģināt bibliotēku pywinstyles (pip install pywinstyles) un pievienot pywinstyles.apply_style(logs, "acrylic") pēc loga izveides - tas strādā droši tikai Windows 11 un nav šeit iekļauts/pārbaudīts pēc noklusējuma, jo tas ir papildu atkarība ar OS versijas ierobežojumu.
