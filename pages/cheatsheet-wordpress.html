WordPress Cheatsheet

Ātrās uzziņas lapa - katrai kartiņai īss skaidrojums, ko funkcija dara un kam tā domāta, plus sintakses fragments. Pilnus, soli-pa-solim piemērus skaties pilnajā WordPress dokumentācijā.

Template Tags

Izsauc The Loop iekšpusē, lai izvadītu ieraksta datus.

the_title()

Izvada ieraksta virsrakstu tieši lapā. Lieto The Loop iekšpusē, kad jāparāda nosaukums, piem., <h2> tagā.

<h2><?php the_title(); ?></h2>

the_content()

Izvada pilnu ieraksta saturu ar visu formatējumu (rindkopas, attēli, bloki) - parāda to, ko lietotājs uzrakstīja redaktorā.

<?php the_content(); ?>

the_excerpt()

Izvada īsu, automātiski nogrieztu (vai manuāli uzrakstītu) izvilkumu - noder sarakstu/arhīva skatos, kur pilns saturs būtu par garu.

<?php the_excerpt(); ?>

the_permalink()

Izvada pilnu, gatavu URL uz šo konkrēto ierakstu - parasti liek href atribūtā, lai izveidotu saiti.

<a href="<?php the_permalink(); ?>">

get_the_ID()

Atgriež (nevis izvada) pašreizējā ieraksta skaitlisko ID - noder, ja ID jānodod tālāk citai funkcijai, piem. get_post_meta().

$id = get_the_ID();

the_date()

Izvada ieraksta publicēšanas datumu - parametrā norāda formātu (piem. 'j.m.Y' = diena.mēnesis.gads).

<?php the_date('j.m.Y'); ?>

the_author()

Izvada tā lietotāja vārdu, kurš publicēja ierakstu - noder blogu/rakstu lapās, lai parādītu autoru.

<?php the_author(); ?>

the_post_thumbnail()

Izvada ieraksta izcēlattēlu gatavā <img> tagā - parametrā norāda izmēru (thumbnail/medium/large/full).

<?php the_post_thumbnail('medium'); ?>

get_the_title($id)

Tas pats, kas the_title(), bet atgriež virsrakstu kā tekstu, nevis izvada uzreiz - noder, ja virsraksts jāapstrādā pirms parādīšanas.

$t = get_the_title($id);

bloginfo()

Izvada vispārīgu vietnes informāciju - nosaukumu, aprakstu, valodu u.c. - atkarībā no parametra ('name', 'description', 'url').

<?php bloginfo('name'); ?>

wp_title()

Ģenerē teksta saturu lapas <title> tagam - mūsdienās to biežāk aizstāj SEO spraudņi (Yoast, Rank Math).

<?php wp_title('-'); ?>

get_the_term_list()

Atgriež HTML sarakstu (ar saitēm) no ierakstam piesaistītajiem taksonomijas terminiem - piem., visas kategorijas, kam ieraksts pieder.

echo get_the_term_list($id, 'category');

Conditional Tags

Atgriež true/false - kāds lapas veids pašlaik tiek rādīts. Noder koplietotos failos (header.php, footer.php), kur jāizvada dažāds saturs atkarībā no lapas.

is_front_page()Vai pašreizējā lapa ir vietnes sākumlapa
is_home()Vai šī ir jaunāko ierakstu plūsmas lapa
is_single()Vai šis ir viens ieraksts (post vai CPT)
is_page()Vai šī ir statiska lapa (nevis ieraksts)
is_page('kontakti')Vai šī ir tieši konkrētā lapa pēc tās slug
is_archive()Vai šī ir jebkāda veida arhīva lapa
is_category() / is_tag()Vai šī ir kategorijas vai birkas arhīva lapa
is_search()Vai šī ir meklēšanas rezultātu lapa
is_404()Vai šī ir "nav atrasts" kļūdas lapa
is_user_logged_in()Vai apmeklētājs pašlaik ir pieteicies
is_admin()Vai kods izpildās admin panelī, nevis publiskajā daļā
has_post_thumbnail()Vai konkrētajam ierakstam ir iestatīts izcēlattēls

Loop & WP_Query

The Loop

Standarta WordPress cikls, kas iziet cauri atrastajiem ierakstiem un ļauj template tagiem (the_title() u.c.) zināt, par kuru ierakstu runāt.

if (have_posts()) : while (have_posts()) : the_post();
  // saturs
endwhile; endif;

WP_Query

Izveido pielāgotu vaicājumu ārpus galvenā Loop - noder, kad jāparāda ieraksti pēc saviem kritērijiem (piem., "Populārākie raksti" sānjoslā).

$q = new WP_Query([
  'post_type' => 'post',
  'posts_per_page' => 5,
]);

wp_reset_postdata()

Obligāti jāizsauc pēc katra pielāgota WP_Query cikla - atjauno globālo $post mainīgo, lai pārējā lapa turpina rādīt pareizos datus.

wp_reset_postdata();

get_posts()

Īsāka alternatīva WP_Query, kad vajag vienkārši masīvu ar ierakstiem, bez pilnas cikla sintakses.

$posts = get_posts(['numberposts' => 5]);

meta_query

WP_Query parametrs, kas filtrē ierakstus pēc pielāgotu lauku (post meta) vērtībām, piem., cenas diapazona.

'meta_query' => [[
  'key' => 'cena', 'value' => 50,
  'compare' => '<=', 'type' => 'NUMERIC',
]]

tax_query

WP_Query parametrs, kas filtrē ierakstus pēc taksonomijas terminiem (kategorija, birka, pielāgota taksonomija).

'tax_query' => [[
  'taxonomy' => 'category',
  'field' => 'slug', 'terms' => 'jaunumi',
]]

pre_get_posts

Āķis, ar ko maina jau esošu (galveno) vaicājumu pirms tas izpildās - drošāk un efektīvāk nekā veidot jaunu WP_Query no nulles.

add_action('pre_get_posts', function($q) {
  if (!is_admin() && $q->is_main_query())
    $q->set('posts_per_page', 12);
});

Pagination

Iegūst pašreizējo lapas numuru no URL - izmanto WP_Query 'paged' parametrā, lai atbalstītu vairāku lapu pārlūkošanu.

'paged' => get_query_var('paged') ?: 1

Biežākie Hooks

init

Izsaucas, kad WordPress kodols ir ielādēts, bet pirms satura izvades - pareizā vieta CPT un taksonomiju reģistrēšanai.

add_action('init', 'fn');

after_setup_theme

Izsaucas ļoti agri tēmas ielādes laikā - izmanto tēmas atbalsta funkcijām (add_theme_support, register_nav_menus).

add_action('after_setup_theme', 'fn');

wp_enqueue_scripts

Vienīgā pareizā vieta, kur pievienot CSS/JS failus publiskajā daļā - nekad nepievieno tos tieši ar <link>/<script> veidnē.

add_action('wp_enqueue_scripts', 'fn');

wp_head / wp_footer

Izsaucas attiecīgi <head> tagā un tieši pirms </body> - noder, lai ievietotu analītikas kodu bez tēmas failu rediģēšanas.

add_action('wp_footer', 'fn');

save_post

Izsaucas ikreiz, kad ieraksts tiek saglabāts (jauns vai atjaunināts) - noder datu automātiskai apstrādei saglabāšanas brīdī.

add_action('save_post', 'fn');

admin_menu

Izsaucas admin paneļa izvēlnes veidošanas laikā - izmanto, lai pievienotu savu jaunu sadaļu admin sānizvēlnē.

add_action('admin_menu', 'fn');

the_title (filter)

Filtrs, kas ļauj mainīt virsraksta tekstu tieši pirms tas tiek izvadīts - piem., pievienot prefiksu visiem virsrakstiem.

add_filter('the_title', 'fn');

the_content (filter)

Filtrs, kas ļauj mainīt vai papildināt ieraksta saturu pirms izvades - piem., automātiski pievienot tekstu ieraksta beigās.

add_filter('the_content', 'fn');

do_action() / apply_filters()

Ļauj izveidot savu, pielāgotu āķi - do_action() izpilda kodu konkrētā vietā, apply_filters() ļauj citiem (vai sev) mainīt vērtību.

do_action('mans_akis');
$v = apply_filters('mans_filtrs', $v);

remove_action()

Noņem iepriekš pievienotu āķi - jānorāda tieši tāda pati prioritāte, ar kādu āķis tika pievienots, citādi noņemšana nestrādās.

remove_action('wp_head', 'wp_generator');

CPT & Taxonomy

register_post_type()

Reģistrē jaunu, strukturētu satura tipu (piem., "Produkti") ar savu administrācijas sadaļu, atsevišķi no ierakstiem un lapām.

register_post_type('produkts', [
  'public' => true, 'show_in_rest' => true,
  'supports' => ['title','editor'],
]);

register_taxonomy()

Reģistrē jaunu veidu, kā grupēt saturu (līdzīgi kategorijām/birkām), un piesaista to konkrētam ieraksta tipam.

register_taxonomy('zime', 'post', [
  'hierarchical' => true,
]);

Template failu nosaukumi

WordPress automātiski izmanto šos failus konkrētajam CPT, ja tie eksistē tēmas mapē - nekas papildus nav jāreģistrē koda pusē.

single-produkts.php
archive-produkts.php

Pēc reģistrēšanas

Jauna CPT publiskā lapa sākotnēji var rādīt 404 - šis saglabāšanas klikšķis piespiež WordPress pārbūvēt saišu noteikumus.

Iestatījumi → Pastāvīgās
saites → Saglabāt

Post Meta (pielāgoti lauki)

update_post_meta()

Saglabā jaunu vērtību vai pārraksta esošu pielāgotu lauku konkrētam ierakstam - visbiežāk lietotā no šīm četrām funkcijām.

update_post_meta($id, 'cena', 49.99);

get_post_meta()

Nolasa saglabātu pielāgotā lauka vērtību - trešais parametrs (true) nozīmē "atgriez vienu vērtību", nevis masīvu.

get_post_meta($id, 'cena', true);

add_post_meta()

Pievieno jaunu vērtību, bet tikai tad, ja tāda vēl neeksistē (ar pēdējo parametru true) - retāk lietota par update_post_meta().

add_post_meta($id, 'cena', 49.99, true);

delete_post_meta()

Pilnībā izdzēš pielāgoto lauku no ieraksta - noder tīrīšanai vai lauka atiestatīšanai.

delete_post_meta($id, 'cena');

Enqueue (skripti/stili)

wp_enqueue_style()

Pareizais veids, kā pievienot CSS failu - WordPress pats parūpējas par ielādes secību un izvairās no dubultas ielādes.

wp_enqueue_style('id', get_stylesheet_uri());

wp_enqueue_script()

Pareizais veids, kā pievienot JS failu - pēdējais parametrs (true) liek to ielādēt lapas beigās, kas paātrina lapas atvēršanos.

wp_enqueue_script('id', $url, [], '1.0', true);

wp_localize_script()

Nodod PHP mainīgos (piem., AJAX URL, nonce) uz JS pusi kā globālu objektu - vienīgais drošais veids piekļūt servera datiem no JS faila.

wp_localize_script('id', 'Data', ['x' => 1]);

get_template_directory_uri()

Atgriež tēmas mapes pilnu URL adresi - izmanto, lai izveidotu ceļu uz failiem tēmas iekšienē (attēliem, JS, CSS).

get_template_directory_uri() . '/js/app.js'

Drošība

esc_html()

Padara tekstu drošu HTML izvadei - pārvērš speciālos simbolus (<, >, &) par to HTML ekvivalentiem, novēršot XSS uzbrukumus.

echo esc_html($teksts);

esc_attr()

Tas pats, kas esc_html(), bet paredzēts izvadei HTML atribūta iekšienē (piem., value="...").

value="<?= esc_attr($v) ?>"

esc_url()

Attīra un pārbauda URL pirms izvades - novērš ļaunprātīga koda ievietošanu caur href/src atribūtiem.

href="<?= esc_url($url) ?>"

sanitize_text_field()

Attīra lietotāja ievadītu tekstu pirms saglabāšanas - noņem HTML tagus, liekās atstarpes un nederīgus rakstzīmju kodus.

$v = sanitize_text_field($_POST['x']);

wp_nonce_field()

Ievieto slēptu, unikālu drošības tokenu formā - nepieciešams, lai vēlāk pārbaudītu, ka pieprasījums patiešām nāk no šīs formas (CSRF aizsardzība).

wp_nonce_field('darbiba', 'nonce_lauks');

wp_verify_nonce()

Pārbauda, vai saņemtais nonce tokens ir derīgs un sakrīt ar sagaidāmo darbību - ja nē, pieprasījums jānoraida.

wp_verify_nonce($_POST['n'], 'darbiba');

wp_kses()

Atļauj tikai norādītos HTML tagus/atribūtus lietotāja ievadītā HTML, pārējo izfiltrē - noder, kad pilnīga esc_html() būtu par stingru (piem., komentāros ar ierobežotu formatējumu).

wp_kses($html, ['a' => ['href' => true], 'strong' => []]);

current_user_can()

Pārbauda, vai pašreizējam lietotājam ir konkrēta tiesība (capability) - pareizais veids kontrolēt piekļuvi, nevis pārbaudīt lomas nosaukumu tieši.

if (current_user_can('edit_posts')) { }

Lietotāji & lomas

wp_get_current_user()

Atgriež pilnu lietotāja objektu pašreizējam pieteiktajam lietotājam - satur vārdu, e-pastu, lomas un citus datus.

$u = wp_get_current_user();

is_user_logged_in()

Ātra pārbaude, vai apmeklētājs vispār ir pieteicies - bieži lieto, lai rādītu dažādu saturu pieteiktiem/nepieteiktiem.

if (is_user_logged_in()) { }

get_userdata($id)

Iegūst konkrēta lietotāja pilnus datus pēc zināma ID - noder, kad ID jau ir zināms (piem., no ieraksta autora lauka).

$u = get_userdata(5);

wp_insert_user()

Programmatiski izveido jaunu WordPress lietotāju - noder automatizētai reģistrācijai (piem., pēc veiksmīga maksājuma).

wp_insert_user(['user_login'=>'x','user_pass'=>'y']);

Lomas (zems→augsts)

WordPress iebūvētās lietotāju lomas augošā tiesību secībā - katra augstāka loma manto zemākas lomas tiesības.

Subscriber → Contributor →
Author → Editor → Administrator

URL & Ceļi

home_url()

Atgriež vietnes publiski redzamo pamata adresi - izmanto, lai izveidotu saites uz konkrētām lapām vietnē.

home_url('/kontakti')

site_url()

Atgriež adresi, kur atrodas pati WordPress instalācija - parasti sakrīt ar home_url(), bet var atšķirties, ja WordPress ir apakšmapē.

site_url()

admin_url()

Atgriež adresi uz admin paneļa daļu - visbiežāk izmanto, lai iegūtu admin-ajax.php pilnu URL AJAX pieprasījumiem.

admin_url('admin-ajax.php')

get_permalink($id)

Atgriež konkrēta ieraksta pastāvīgo saiti (URL) pēc tā ID - noder, ja saite jāizveido ārpus The Loop.

get_permalink($id)

get_template_directory()

Atgriež servera failu sistēmas ceļu (ne interneta adresi) uz tēmas mapi - izmanto PHP failu iekļaušanai (require/include).

get_template_directory() . '/inc/x.php'

plugin_dir_url(__FILE__)

Atgriež spraudņa mapes URL adresi no jebkura spraudņa faila - noder, lai pieslēgtu spraudņa paša CSS/JS failus.

plugin_dir_url(__FILE__)

Datubāze ($wpdb)

$wpdb->get_results()

Izpilda SQL vaicājumu un atgriež visas atbilstošās rindas kā masīvu - izmanto, kad WP_Query nespēj izteikt vajadzīgo vaicājumu.

global $wpdb;
$wpdb->get_results("SELECT * FROM {$wpdb->posts}");

$wpdb->get_row()

Tas pats, kas get_results(), bet atgriež tikai vienu (pirmo atbilstošo) rindu - noder, ja zini, ka rezultāts būs viens ieraksts.

$wpdb->get_row("... WHERE id=1");

$wpdb->prepare()

Sagatavo SQL vaicājumu ar drošu vietturu aizvietošanu - vienmēr jāizmanto, kad vaicājumā iekļauj mainīgu (lietotāja) datu, lai novērstu SQL injection.

$wpdb->prepare("... WHERE id=%d", $id)

$wpdb->prefix

Pašreizējās instalācijas tabulu prefikss (noklusējumā wp_, bet var būt cits) - vienmēr izmanto šo mainīgo, nevis cietkodētu "wp_".

{$wpdb->prefix}mana_tabula

Media

add_theme_support()

Ieslēdz WordPress iebūvētu funkcionalitāti tēmai - parametrs "post-thumbnails" aktivizē izcēlattēlu atbalstu, bez kura the_post_thumbnail() nestrādās.

add_theme_support('post-thumbnails');

the_post_thumbnail()

Izvada ieraksta izcēlattēlu gatavā <img> tagā ar norādīto izmēru - prasa iepriekš ieslēgtu add_theme_support('post-thumbnails').

the_post_thumbnail('large');

get_the_post_thumbnail_url()

Atgriež tikai izcēlattēla URL adresi (nevis gatavu <img> tagu) - noder, ja attēls jāizmanto, piem., CSS background-image īpašībā.

$url = get_the_post_thumbnail_url($id);

wp_get_attachment_image()

Izvada jebkuru mediatēkas attēlu kā <img> tagu pēc tā pielikuma (attachment) ID - noder attēliem, kas nav ieraksta izcēlattēls.

wp_get_attachment_image($att_id, 'medium');

AJAX & REST

wp_ajax_ / wp_ajax_nopriv_

Divi āķi ar vienādu darbības nosaukumu - pirmais apstrādā pieteiktus lietotājus, otrais nepieteiktus. Jāreģistrē abi, ja AJAX jāstrādā arī viesiem.

add_action('wp_ajax_x', 'fn');
add_action('wp_ajax_nopriv_x', 'fn');

wp_send_json_success/error()

Nosūta atbildi atpakaļ JS pusei gatavā JSON formātā ar "success" karodziņu - automātiski arī pārtrauc PHP skripta izpildi.

wp_send_json_success(['ok' => true]);

register_rest_route()

Reģistrē savu, pielāgotu REST API galapunktu - alternatīva admin-ajax.php pieejai, modernāka un vieglāk testējama.

register_rest_route('ns/v1', '/x', [
  'methods' => 'GET', 'callback' => 'fn',
]);

/wp-json/wp/v2/posts

WordPress kodola iebūvēts REST galapunkts, kas jau strādā uzreiz - atgriež publicētos ierakstus JSON formātā bez papildu koda.

GET /wp-json/wp/v2/posts

Options & HTTP API

get_option() / update_option()

Nolasa/saglabā vienkāršu iestatījumu vērtību pēc atslēgas - standarta veids, kā tēmas/spraudņi glabā savus iestatījumus wp_options tabulā.

update_option('krasa', '#f00');
get_option('krasa', '#000');

add_option() / delete_option()

add_option() pievieno tikai tad, ja opcija vēl neeksistē; delete_option() izdzēš to pilnībā.

add_option('versija', '1.0');
delete_option('versija');

wp_remote_get()

Nosūta GET pieprasījumu uz ārēju API - WordPress ieteiktais veids, nevis tiešs cURL, jo ievēro servera proxy iestatījumus.

$r = wp_remote_get('https://api.x.lv/dati');

wp_remote_post()

Tas pats, kas wp_remote_get(), bet POST pieprasījumam ar datiem un galvenēm.

wp_remote_post($url, ['body' => $dati]);

is_wp_error()

Vienmēr jāpārbauda pēc wp_remote_*() izsaukuma - pārbauda, vai pats pieprasījums tehniski izdevās (nevis servera atbildes statusu).

if (is_wp_error($r)) { /* kļūda */ }

wp_remote_retrieve_body()

Izvelk tikai atbildes saturu (tekstu/JSON) no pilnās wp_remote_*() atbildes struktūras.

$dati = json_decode(wp_remote_retrieve_body($r), true);

i18n & Gutenberg

__()

Atgriež tulkotu tekstu (nevis izvada) - otrais parametrs vienmēr ir text domain, kas piesaista tekstu konkrētajai tēmai/spraudnim.

$t = __('Sveiki', 'mana-tema');

_e()

Tas pats, kas __(), bet uzreiz izvada tekstu - saīsinājums echo __(...).

_e('Sveiki', 'mana-tema');

esc_html__()

Apvieno tulkošanu ar drošu HTML izvadi vienā solī - visbiežāk lietotā kombinācija veidnēs.

echo esc_html__('Sveiki', 'mana-tema');

load_theme_textdomain()

Reģistrē text domain un norāda mapi, kur meklēt .po/.mo tulkojumu failus.

load_theme_textdomain('mana-tema', get_template_directory().'/languages');

register_block_type()

Reģistrē Gutenberg bloku, nolasot tā block.json failu - bloks pēc tam parādās redaktora bloku sarakstā.

register_block_type(__DIR__ . '/blocks/x');

block.json

Bloka metadatu fails (nosaukums, kategorija, ikona, JS/CSS faili) - WordPress to nolasa automātiski, izsaucot register_block_type() ar mapes ceļu.

{ "name": "ns/x", "editorScript": "file:./index.js" }

Citas noderīgas

add_shortcode()

Reģistrē pielāgotu [tagu], ko redaktorā var ierakstīt kā tekstu, un WordPress to automātiski aizvieto ar funkcijas atgriezto saturu.

add_shortcode('gads', fn() => date('Y'));

set_transient() / get_transient()

Saglabā/nolasa pagaidu, uz laiku ierobežotu kešoto vērtību - noder, lai izvairītos no dārgu aprēķinu vai ārēju API pieprasījumu atkārtošanas katrā lapas ielādē.

set_transient('x', $v, HOUR_IN_SECONDS);

wp_schedule_event()

Ieplāno funkciju, kas automātiski izpildīsies ar norādītu intervālu (WordPress "cron"). Vienmēr pirms tam pārbauda ar wp_next_scheduled(), lai nedublētu ieplānojumu.

if (!wp_next_scheduled('h'))
  wp_schedule_event(time(), 'daily', 'h');

register_sidebar()

Reģistrē jaunu widžetu zonu (piem., sānjoslu), kuru pēc tam var aizpildīt admin panelī Izskats → Widžeti, neko papildus nekodējot.

register_sidebar(['id' => 'main']);

register_nav_menus()

Reģistrē vietu (ar iekšēju nosaukumu) tēmā, kur vēlāk var piesaistīt izvēlni, ko lietotājs izveido admin panelī.

register_nav_menus(['primary' => 'Galvenā']);

wp_mail()

WordPress iebūvētā funkcija e-pastu sūtīšanai - pēc noklusējuma izmanto servera PHP mail() funkciju, kas daudzos hostingos ir neuzticama.

wp_mail($to, $subject, $body);
