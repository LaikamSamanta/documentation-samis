Template Tags

Izsauc The Loop iekšpusē, lai izvadītu ieraksta datus.

the_title()

Izvada virsrakstu

<h2><?php the_title(); ?></h2>

the_content()

Pilns saturs

<?php the_content(); ?>

the_excerpt()

Īss izvilkums

<?php the_excerpt(); ?>

the_permalink()

Pilns URL uz ierakstu

<a href="<?php the_permalink(); ?>">

get_the_ID()

Pašreizējā ieraksta ID

$id = get_the_ID();

the_date()

Publicēšanas datums

<?php the_date('j.m.Y'); ?>

the_author()

Autora vārds

<?php the_author(); ?>

the_post_thumbnail()

Izcēlattēls kā <img>

<?php the_post_thumbnail('medium'); ?>

get_the_title($id)

Atgriež (neizvada)

$t = get_the_title($id);

bloginfo()

Vietnes info

<?php bloginfo('name'); ?>

wp_title()

Lapas <title> saturs

<?php wp_title('-'); ?>

get_the_term_list()

Kategorijas/birkas

echo get_the_term_list($id, 'category');

Loop & WP_Query

The Loop

Standarta cikls

if (have_posts()) : while (have_posts()) : the_post();
  // saturs
endwhile; endif;

WP_Query

Pielāgots vaicājums

$q = new WP_Query([
  'post_type' => 'post',
  'posts_per_page' => 5,
]);

wp_reset_postdata()

Pēc katra WP_Query

wp_reset_postdata();

get_posts()

Īsāka alternatīva

$posts = get_posts(['numberposts' => 5]);

meta_query

Filtrē pēc post meta

'meta_query' => [[
  'key' => 'cena', 'value' => 50,
  'compare' => '<=', 'type' => 'NUMERIC',
]]

tax_query

Filtrē pēc taksonomijas

'tax_query' => [[
  'taxonomy' => 'category',
  'field' => 'slug', 'terms' => 'jaunumi',
]]

pre_get_posts

Maina galveno vaicājumu

add_action('pre_get_posts', function($q) {
  if (!is_admin() && $q->is_main_query())
    $q->set('posts_per_page', 12);
});

Pagination

Lapu numerācija

'paged' => get_query_var('paged') ?: 1

Post Meta (pielāgoti lauki)

update_post_meta()

Saglabā/pārraksta

update_post_meta($id, 'cena', 49.99);

get_post_meta()

3. param. true = viena vērtība

get_post_meta($id, 'cena', true);

add_post_meta()

Pievieno, ja unikāls

add_post_meta($id, 'cena', 49.99, true);

delete_post_meta()

Izdzēš lauku

delete_post_meta($id, 'cena');

Enqueue (skripti/stili)

wp_enqueue_style()

CSS fails

wp_enqueue_style('id', get_stylesheet_uri());

wp_enqueue_script()

JS fails (args: handle,src,deps,ver,footer)

wp_enqueue_script('id', $url, [], '1.0', true);

wp_localize_script()

PHP dati → JS mainīgais

wp_localize_script('id', 'Data', ['x' => 1]);

get_template_directory_uri()

Tēmas mapes URL

get_template_directory_uri() . '/js/app.js'
