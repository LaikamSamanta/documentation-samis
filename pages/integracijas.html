Sākums Integrācijas

Integrācijas

Pilnas, gatavas integrācijas jebkuram WordPress projektam — iekopē un uzreiz strādā. Katra integrācija ir sava, sakļaujama sadaļa sānjoslā — spied uz nosaukuma, lai atvērtu tās soļus.

Kur likt PHP kodu: ja vien nav norādīts citādi, visi šīs lapas PHP piemēri jāievieto aktīvās tēmas functions.php failā (Izskats → Tēmas redaktors, vai tieši failā serverī) un jāsaglabā — izmaiņas parasti redzamas uzreiz pēc lapas atsvaidzināšanas. WordPress pamatiem (tēmas, hooks, CPT) skaties WordPress sadaļu.

Valodu sistēma (multi-language) — pārskats

Šī ir pilna, patstāvīga daudzvalodu sistēma — tavs paša "mini WPML", bet vienkāršāks, bez maksas un pilnībā tavā kontrolē. To var iekopēt gandrīz jebkurā WordPress projektā un tā uzreiz strādā. Sistēma sastāv no astoņām daļām, kuras zemāk izskaidrotas pa vienai:

1️⃣ Valodu saraksts

JSON fails ar aktīvajām valodām (kods + nosaukums).

2️⃣ Valodas noteikšana

No URL, sīkdatnes vai noklusējuma — automātiski.

3️⃣ Pretty URL

/en/lapa/ vietā neglīta ?lang=en.

4️⃣ Statiskā teksta tulkojumi

Pogas, izvēlnes, virsraksti — visās valodās.

5️⃣ Daudzvalodu lauki

Ieraksta lauki (piem., apakšvirsraksts) katrā valodā atsevišķi.

6️⃣ Admin lapa

Valodu pievienošana/dzēšana bez koda rediģēšanas.

7️⃣ Google Translate

Viena poga aizpilda tulkojumu automātiski.

8️⃣ Pārslēdzējs & SEO

Frontend valodu izvēlne + hreflang tagi.

Visas 8 daļas kopā veido vienu failu — inc/multilingual.php. Katra sadaļa zemāk paskaidro savu gabalu un rāda tā kodu; pēdējā sadaļā ("Kā ielikt citā projektā") ir precīzi soļi, kā tās salikt kopā jaunā WordPress projektā.

1. Pamata fails & valodu saraksts

Valodu saraksts netiek glabāts datubāzē, bet vienkāršā JSON failā wp-content/uploads/ml-lang/languages.json — tas ir ātrāk nekā datubāzes vaicājums un failu var apskatīt/rediģēt tieši, ja kādreiz vajag. Fails ar .htaccess tiek pasargāts, lai neviens to nevarētu atvērt tieši pārlūkā.

php/**
 * inc/multilingual.php
 * Daudzvalodu sistēma — daļa 1: pamata valodu saraksts
 */
defined('ABSPATH') || exit;

// Atgriež mapes ceļu, kur glabājam valodu datus (izveido, ja neeksistē)
function ml_lang_dir(): string {
    $dir = wp_upload_dir()['basedir'] . '/ml-lang';
    if (!file_exists($dir)) {
        wp_mkdir_p($dir);
        file_put_contents($dir . '/.htaccess', 'deny from all');
    }
    return $dir;
}

// Nolasa aktīvo valodu sarakstu — piem. [['code'=>'lv','label'=>'Latviešu'], ...]
function ml_get_languages(): array {
    $file = ml_lang_dir() . '/languages.json';

    if (!file_exists($file)) {
        return [['code' => 'lv', 'label' => 'Latviešu']];
    }

    $data = json_decode(file_get_contents($file), true);
    return (is_array($data) && !empty($data))
        ? $data
        : [['code' => 'lv', 'label' => 'Latviešu']];
}

// Saglabā valodu sarakstu atpakaļ JSON failā
function ml_save_languages(array $langs): bool {
    $file = ml_lang_dir() . '/languages.json';
    $json = wp_json_encode($langs, JSON_PRETTY_PRINT | JSON_UNESCAPED_UNICODE);
    return (bool) file_put_contents($file, $json);
}

// Pirmā valoda sarakstā vienmēr ir noklusējuma (galvenā) valoda
function ml_default_lang(): string {
    $langs = ml_get_languages();
    return $langs[0]['code'] ?? 'lv';
}

Ja fails vēl neeksistē, sistēma automātiski strādā ar vienu noklusējuma valodu (lv) — tā nekad "nesalūzt" pat pirms pirmās konfigurēšanas.

2. Aktīvās valodas noteikšana

Katrā lapas ielādē sistēmai jāzina, kurā valodā rādīt saturu. Prioritāšu secība: vispirms skatās URL (/en/...), tad sīkdatni (atceras iepriekšējo izvēli), visbeidzot — noklusējumu.

php// Nosaka un atceras aktīvo valodu vienas lapas ielādes ietvaros (static — skaitļo tikai vienreiz)
function ml_detect_lang(): string {
    static $detected = null;
    if ($detected !== null) return $detected;

    $allowed = array_column(ml_get_languages(), 'code');
    $default = ml_default_lang();

    // 1) URL segments, piem. "/en/kontakti/" -> "en"
    $path  = parse_url($_SERVER['REQUEST_URI'] ?? '/', PHP_URL_PATH) ?? '/';
    $parts = explode('/', trim($path, '/'));

    if (!empty($parts[0]) && in_array($parts[0], $allowed, true)) {
        return $detected = $parts[0];
    }

    // 2) Sīkdatne no iepriekšējā apmeklējuma
    $cookie = sanitize_key($_COOKIE['ml_lang'] ?? '');
    if ($cookie && in_array($cookie, $allowed, true)) {
        return $detected = $cookie;
    }

    // 3) Noklusējums
    return $detected = $default;
}

// Īsāks, ērtāks alias — šo sauc visur pārējā kodā un veidnēs
function ml_current_lang(): string {
    return ml_detect_lang();
}

// Katru reizi, kad valoda mainās, atjaunojam sīkdatni uz gadu
add_action('init', function () {
    $lang = ml_detect_lang();
    if (($_COOKIE['ml_lang'] ?? '') !== $lang) {
        setcookie('ml_lang', $lang, time() + YEAR_IN_SECONDS, COOKIEPATH, COOKIE_DOMAIN, is_ssl(), true);
    }
});

3. Pretty URL maršrutēšana

Bez šī soļa vienīgais veids, kā norādīt valodu, būtu neglīts ?lang=en parametrs. add_rewrite_rule() māca WordPress saprast, ka /en/kontakti/ ir tas pats, kas parastā "kontakti" lapa, tikai citā valodā.

php// Reģistrē URL noteikumus katrai valodai: /en/, /en/jebkas/, u.t.t.
add_action('init', function () {
    foreach (ml_get_languages() as $l) {
        $code = preg_quote($l['code'], '#');

        add_rewrite_rule('^' . $code . '/?$', 'index.php?ml_lang=' . $l['code'], 'top');
        add_rewrite_rule('^' . $code . '/(.+?)/?$', 'index.php?ml_lang=' . $l['code'] . '&ml_path=$matches[1]', 'top');
    }
});

// Māca WordPress atpazīt jaunos URL parametrus
add_filter('query_vars', function (array $vars): array {
    $vars[] = 'ml_lang';
    $vars[] = 'ml_path';
    return $vars;
});

// Pārvērš "ml_path" (piem. "kontakti") par īstu WordPress lapu
add_action('parse_request', function (WP $wp): void {
    if (empty($wp->query_vars['ml_lang'] ?? '')) return;

    $path = trim($wp->query_vars['ml_path'] ?? '', '/');
    unset($wp->query_vars['ml_path']);

    // Tukšs ceļš ("/en/") -> sākumlapa
    if ($path === '') {
        $front_id = (int) get_option('page_on_front');
        if ($front_id) $wp->query_vars['page_id'] = $front_id;
        return;
    }

    // Meklē lapu pēc slug, piem. "kontakti"
    $page = get_page_by_path($path);
    if ($page) {
        $wp->query_vars['page_id'] = $page->ID;
        return;
    }

    // Ja nekas neatrodas, ļauj WordPress mēģināt pašam (arī raksti/CPT)
    $wp->query_vars['pagename'] = $path;
});

// Ģenerē saiti uz pašreizējo lapu, bet citā valodā (izmanto pārslēdzējā)
function ml_url(string $target_lang): string {
    $home    = untrailingslashit(home_url());
    $default = ml_default_lang();
    $allowed = array_column(ml_get_languages(), 'code');

    if (!in_array($target_lang, $allowed, true)) return $home . '/';

    $path     = parse_url($_SERVER['REQUEST_URI'] ?? '/', PHP_URL_PATH) ?? '/';
    $relative = '/' . ltrim($path, '/');

    // Noņem esošo valodas prefiksu, ja tāds jau ir ceļā
    foreach ($allowed as $code) {
        $prefix = '/' . $code;
        if ($relative === $prefix || str_starts_with($relative, $prefix . '/')) {
            $relative = substr($relative, strlen($prefix));
            break;
        }
    }
    $relative = '/' . ltrim($relative ?: '/', '/');

    return $target_lang === $default
        ? $home . $relative
        : $home . '/' . $target_lang . $relative;
}

// Katru reizi, kad maini valodas vai atjauno tēmu, jāatsvaidzina URL noteikumi
add_action('after_switch_theme', 'flush_rewrite_rules');

Pēc šī koda pievienošanas dodies uz Iestatījumi → Pastāvīgās saites → Saglabāt — tas piespiedu kārtā atsvaidzina URL noteikumus. Bez šī soļa /en/... adreses rādīs 404.

4. Statiskā teksta tulkojumi

Šis nodrošina tulkojumus fiksētiem tekstiem, kas nav piesaistīti konkrētam ierakstam — pogas, izvēlnes vārdi, virsraksti. Tie tiek glabāti JSON failos, sagrupēti pa "grupām" (piem., menu.json, kontakti.json), lai katra lapa/sadaļa turētu savu nelielo tulkojumu failu.

php// Nolasa/raksta konkrētas grupas tulkojumu failu, piem. "menu" -> ml-lang/menu.json
function ml_dict_file(string $group): string {
    return ml_lang_dir() . '/' . sanitize_file_name($group) . '.json';
}

function ml_dict_read(string $group): array {
    $file = ml_dict_file($group);
    if (!file_exists($file)) return [];
    $data = json_decode(file_get_contents($file), true);
    return is_array($data) ? $data : [];
}

function ml_dict_write(string $group, array $data): bool {
    return (bool) file_put_contents(ml_dict_file($group), wp_json_encode($data, JSON_PRETTY_PRINT | JSON_UNESCAPED_UNICODE));
}

// ŠO IZSAUC VEIDNĒS: ml_t('menu', 'home') -> "Sākums" / "Home" / "Главная"
function ml_t(string $group, string $key, string $lang = ''): string {
    $lang = $lang ?: ml_current_lang();
    $data = ml_dict_read($group);

    return $data[$lang][$key]
        ?? $data[ml_default_lang()][$key]
        ?? '';
}

Lietošana veidnē (piem. header.php):

php<a href="/"><?= esc_html(ml_t('menu', 'home')) ?></a>

Atbilstošais menu.json fails izskatītos šādi (šo faila saturu vēlāk rediģēs caur admin lapu, skat. 6. soli, nevis ar roku):

json{
    "lv": { "home": "Sākums", "contact": "Kontakti" },
    "en": { "home": "Home",   "contact": "Contact" }
}

5. Daudzvalodu pielāgotie lauki

Šī daļa atšķiras no 4. soļa — tā ir domāta laukiem, kas pieder konkrētam ierakstam (piem., raksta apakšvirsraksts), nevis fiksētiem UI tekstiem. Vērtība katrai valodai tiek saglabāta vienā post meta laukā kā JSON masīvs — piem. {"lv": "...", "en": "..."}.

php// ŠO IZSAUC VEIDNĒS: ml_field(get_the_ID(), 'ml_subtitle')
function ml_field(int $post_id, string $field, string $lang = ''): string {
    $raw = get_post_meta($post_id, $field, true);
    if (empty($raw)) return '';

    $data = is_array($raw) ? $raw : json_decode($raw, true);
    if (!is_array($data)) return '';

    $lang = $lang ?: ml_current_lang();

    return $data[$lang]
        ?? $data[ml_default_lang()]
        ?? reset($data)
        ?: '';
}

Un pilns meta box piemērs — pievieno vienu ievades lauku katrai valodai jebkura ieraksta rediģēšanas ekrānā, ar drošu saglabāšanu (nonce pārbaude):

phpadd_action('add_meta_boxes', function () {
    add_meta_box('ml_subtitle_box', 'Apakšvirsraksts (visās valodās)', 'ml_render_subtitle_box', 'post');
});

function ml_render_subtitle_box(WP_Post $post): void {
    wp_nonce_field('ml_save_subtitle', 'ml_subtitle_nonce');

    $raw     = get_post_meta($post->ID, 'ml_subtitle', true);
    $data    = $raw ? json_decode($raw, true) : [];
    $langs   = ml_get_languages();
    $default = ml_default_lang();

    foreach ($langs as $l):
        $code = $l['code'];
        $val  = $data[$code] ?? '';
    ?>
    <p>
        <label><strong><?= esc_html(strtoupper($code)) ?> — <?= esc_html($l['label']) ?></strong></label><br>
        <input type="text" style="width:100%"
               id="ml_subtitle_<?= esc_attr($code) ?>"
               name="ml_subtitle[<?= esc_attr($code) ?>]"
               value="<?= esc_attr($val) ?>">
        <?php if ($code !== $default): ?>
            <button type="button" class="button ml-translate-btn"
                data-from="<?= esc_attr($default) ?>" data-to="<?= esc_attr($code) ?>"
                data-source="#ml_subtitle_<?= esc_attr($default) ?>"
                data-target="#ml_subtitle_<?= esc_attr($code) ?>">
                🌍 Tulkot no <?= esc_html(strtoupper($default)) ?>
            </button>
        <?php endif; ?>
    </p>
    <?php
    endforeach;
}

add_action('save_post', function (int $post_id) {
    if (!isset($_POST['ml_subtitle_nonce']) || !wp_verify_nonce($_POST['ml_subtitle_nonce'], 'ml_save_subtitle')) return;
    if (!current_user_can('edit_post', $post_id)) return;

    $values = array_map('sanitize_text_field', $_POST['ml_subtitle'] ?? []);
    update_post_meta($post_id, 'ml_subtitle', wp_json_encode($values, JSON_UNESCAPED_UNICODE));
});

Un rādīšana veidnē (piem. single.php):

php<?php $apaksvirsraksts = ml_field(get_the_ID(), 'ml_subtitle'); ?>
<?php if ($apaksvirsraksts): ?>
    <p class="subtitle"><?= esc_html($apaksvirsraksts) ?></p>
<?php endif; ?>

Vēlies daudzvalodu lauku citam CPT vai citam laukam? Nokopē šo pašu meta box piemēru, nomaini 'post' uz savu satura tipu un 'ml_subtitle' uz savu lauka nosaukumu — pārējais paliek identisks.

6. Admin lapa valodām

Lai valodas varētu pievienot/dzēst bez koda rediģēšanas, pievieno vienkāršu admin lapu. Tā parādās WordPress sānizvēlnē un ļauj rediģēt valodu tabulu (kods + nosaukums), kas tieši atbilst 1. solī izveidotajam languages.json.

phpadd_action('admin_menu', function () {
    add_menu_page('Valodas', 'Valodas', 'manage_options', 'ml-languages', 'ml_languages_page', 'dashicons-translation', 80);
});

function ml_languages_page(): void {
    if (!current_user_can('manage_options')) return;

    if (isset($_POST['ml_save']) && check_admin_referer('ml_save_langs')) {
        $codes  = array_map('sanitize_key',        $_POST['code']  ?? []);
        $labels = array_map('sanitize_text_field', $_POST['label'] ?? []);

        $langs = [];
        foreach ($codes as $i => $code) {
            if ($code && !empty($labels[$i])) {
                $langs[] = ['code' => $code, 'label' => $labels[$i]];
            }
        }

        if ($langs) {
            ml_save_languages($langs);
            flush_rewrite_rules(); // jauna valoda = jauni URL noteikumi
            echo '<div class="notice notice-success"><p>Saglabāts!</p></div>';
        }
    }

    $langs = ml_get_languages();
    ?>
    <div class="wrap">
        <h1>🌍 Valodas</h1>
        <form method="post">
            <?php wp_nonce_field('ml_save_langs'); ?>
            <table class="widefat">
                <thead><tr><th>Kods</th><th>Nosaukums</th></tr></thead>
                <tbody>
                <?php foreach ($langs as $l): ?>
                    <tr>
                        <td><input type="text" name="code[]" value="<?= esc_attr($l['code']) ?>" maxlength="5"></td>
                        <td><input type="text" name="label[]" value="<?= esc_attr($l['label']) ?>"></td>
                    </tr>
                <?php endforeach; ?>
                <tr>
                    <td><input type="text" name="code[]" placeholder="en" maxlength="5"></td>
                    <td><input type="text" name="label[]" placeholder="English"></td>
                </tr>
                </tbody>
            </table>
            <p><button type="submit" name="ml_save" class="button button-primary">Saglabāt</button></p>
        </form>
    </div>
    <?php
}

Pēdējā tukšā rinda tabulā vienmēr ļauj pievienot vēl vienu jaunu valodu — vienkārši ieraksti kodu un nosaukumu un spied "Saglabāt".

7. Google Translate automātiskā tulkošana

Šī daļa pievieno pogu "🌍 Tulkot", kas automātiski aizpilda tulkojuma lauku, izmantojot Google Translate bezmaksas, neoficiālo galapunktu (to pašu, ko izmanto translate.google.com pārlūkā). Nav vajadzīga API atslēga vai maksas konts.

phpadd_action('admin_footer', function () {
    ?>
    <script>
    (function () {
        // Tulko tekstu no vienas valodas uz otru caur Google Translate
        async function mlTranslate(text, from, to) {
            if (!text.trim()) return text;
            const url = 'https://translate.googleapis.com/translate_a/single'
                + '?client=gtx&sl=' + from + '&tl=' + to + '&dt=t&q=' + encodeURIComponent(text);
            const res  = await fetch(url);
            const json = await res.json();
            // Google atgriež ligzdotu masīvu — saliekam gabalus vienā tekstā
            return json[0].map(part => part[0]).join('');
        }

        document.addEventListener('click', async function (e) {
            const btn = e.target.closest('.ml-translate-btn');
            if (!btn) return;

            const from = btn.dataset.from || 'lv';
            const to   = btn.dataset.to;
            const src  = document.querySelector(btn.dataset.source);
            const dest = document.querySelector(btn.dataset.target);
            if (!src || !dest) return;

            btn.disabled = true;
            const original = btn.textContent;
            btn.textContent = '⏳ Tulko...';

            dest.value = await mlTranslate(src.value, from, to);

            btn.textContent = '✅ Gatavs';
            setTimeout(() => { btn.textContent = original; btn.disabled = false; }, 1500);
        });
    })();
    </script>
    <?php
});

Šī poga jau strādā ar 5. solī izveidoto meta box piemēru (tur tai jau ir pareizie data-* atribūti) — ne pati funkcija, ne pogas HTML nekas papildus nav jāraksta.

Šis ir neoficiāls Google galapunkts (nav Google Cloud Translation API) — tas ir bez maksas un ideāls admin ērtībai, bet nav garantijas, ka Google to nemainīs nākotnē. Lieliem apjomiem vai kritiskiem projektiem ilgtermiņā apsver oficiālo, maksas Google Cloud Translation API.

8. Valodu pārslēdzējs & SEO

Pēdējā daļa — apmeklētājam redzamā valodu izvēlne un hreflang SEO tagi, kas palīdz Google saprast, ka lapas dažādās valodās ir viena un tā pati satura versija, nevis dublēts saturs.

php// ŠO IZSAUC VEIDNĒ (piem. header.php): <?php ml_language_switcher(); ?>
function ml_language_switcher(): void {
    $langs = ml_get_languages();
    if (count($langs) < 2) return; // nav jēgas rādīt pārslēdzēju vienai valodai

    $current = ml_current_lang();
    ?>
    <div class="ml-switcher">
        <?php foreach ($langs as $l): ?>
            <a href="<?= esc_url(ml_url($l['code'])) ?>"
               class="ml-switcher-item <?= $l['code'] === $current ? 'active' : '' ?>">
                <?= esc_html(strtoupper($l['code'])) ?>
            </a>
        <?php endforeach; ?>
    </div>
    <?php
}

// hreflang tagi <head> sadaļā — palīdz SEO, novērš "dublēta satura" problēmu
add_action('wp_head', function () {
    $langs = ml_get_languages();
    if (count($langs) < 2) return;

    foreach ($langs as $l) {
        printf(
            '<link rel="alternate" hreflang="%s" href="%s">' . "\n",
            esc_attr($l['code']),
            esc_url(ml_url($l['code']))
        );
    }
}, 1);

Minimāls CSS pārslēdzējam (pielāgo pēc savas vietnes stila):

css.ml-switcher { display: flex; gap: 8px; }
.ml-switcher-item { opacity: .5; text-decoration: none; font-weight: 600; }
.ml-switcher-item.active { opacity: 1; }

Kā ielikt citā projektā

Precīza soļu secība, lai šo sistēmu pievienotu jaunam vai esošam WordPress projektam:

text1. Izveido failu:  wp-content/themes/tava-tema/inc/multilingual.php
2. Iekopē tajā VISU kodu no 1.-8. sadaļas augstāk (šajā secībā)
3. functions.php failā pievieno vienu rindu:
   require_once get_template_directory() . '/inc/multilingual.php';
4. WordPress admin: Iestatījumi → Pastāvīgās saites → Saglabāt
   (tas aktivizē /en/, /ru/ u.c. URL noteikumus)
5. Ej uz jauno "🌍 Valodas" izvēlni admin sānjoslā un pievieno valodas
6. header.php failā ielikt: 
7. Veidnēs izmanto ml_t('grupa', 'atslēga') statiskajam tekstam
   un ml_field($post_id, 'lauka_vards') ieraksta laukiem

Sistēma darbojas ar jebkuru valodu skaitu un jebkuriem kodiem (lv, en, ru, de, ...) — nekas kodā nav "hardkodēts" uz konkrētām valodām. Pievienojot jaunu valodu admin lapā, viss (URL, pārslēdzējs, hreflang) sāk strādāt automātiski.

Ja projektā jau ir cita daudzvalodu sistēma vai spraudnis (WPML, Polylang), neinstalē abas vienlaikus — tās konfliktēs (piem., abas mēģinās reģistrēt savus add_rewrite_rule() noteikumus un URL sajuks).

Kontaktforma + Cloudflare Turnstile — pārskats

Šī ir pilna, darbojoša kontaktforma ar mūsdienīgu spam aizsardzību — bez kaitinošajām "izvēlies visus attēlus ar autobusiem" reCAPTCHA mīklām. Cloudflare Turnstile lielākajai daļai apmeklētāju ir pilnīgi neredzama (strādā fonā, analizējot pārlūka uzvedību) un ir bez maksas jebkuram apmeklējumu apjomam.

Sistēmai ir trīs slāņi aizsardzības pret spamu un trīs galvenās daļas:

🛡️ Turnstile

Cloudflare pārbauda, vai aiz formas stāv reāls cilvēks, nevis bots.

🍯 Honeypot

Slēpts lauks, ko cilvēks neredz un neaizpilda — boti gan bieži aizpilda visu.

🔐 WordPress nonce

Apliecina, ka pieprasījums nāk no tavas lapas, nevis no ārpuses.

📝 Forma (HTML)

Vārds, e-pasts, ziņojums + neredzams Turnstile logrīks.

⚡ Iesūtīšana (JS)

Nosūta datus bez lapas pārlādēšanas (AJAX/fetch).

📧 Apstrāde (PHP)

Pārbauda visu, tad nosūta divas e-pasta vēstules.

1. Cloudflare Turnstile uzstādīšana

Pirms koda raksti, jāiegūst divas atslēgas no Cloudflare — tas ir bez maksas un neprasa, lai tava vietne vispār būtu pieslēgta Cloudflare (Turnstile strādā neatkarīgi no tā, kur mitināta vietne).

text1. Ej uz https://dash.cloudflare.com un izveido bezmaksas kontu (ja vēl nav)
2. Kreisajā izvēlnē atrodi sadaļu "Turnstile"
3. Spied "Add site" (Pievienot vietni)
4. Ievadi:
   - Site name:  jebkurš nosaukums sev pašam (piem. "Mana Vietne")
   - Domain:     tavas vietnes domēns, piem. piemers.lv
                 (lokālai izstrādei vari pievienot arī "localhost")
5. Widget Mode — izvēlies "Managed" (ieteicams sākumā, Cloudflare
   pati izlemj, cik pamanāms logrīks jārāda konkrētam apmeklētājam)
6. Spied "Create"
7. Cloudflare parādīs DIVAS atslēgas — nokopē abas:
   - Site Key   (publiska, redzama HTML kodā)
   - Secret Key (SLEPENA, nekad nerāda publiski!)

Site Key drīkst redzēt HTML kodā (to redz ikviens, kas atver "View Source") — tas ir normāli un ar nodomu. Secret Key nekad nedrīkst nonākt HTML, JavaScript vai publiski redzamā vietā — tas paliek tikai servera (PHP) kodā.

Tālāk jāreģistrē pats Turnstile skripts, kas WordPress pusē renderē logrīku:

php// functions.php — pieslēdz Cloudflare Turnstile skriptu visai vietnei
add_action('wp_enqueue_scripts', function () {
    wp_enqueue_script(
        'cf-turnstile',
        'https://challenges.cloudflare.com/turnstile/v0/api.js',
        [], null, true
    );
});

2. Kur glabāt atslēgas: wp-config.php vai functions.php

Secret Key nekad nedrīkst tikt saglabāta datubāzē (piem., kā parasta iestatījuma vērtība) vai iekļauta tēmas failos, kas var nonākt publiskā Git repozitorijā. Ir divas saprātīgas vietas, kur to definēt kā PHP konstanti:

✅ wp-config.php Ieteicams

Atrodas ārpus tēmas — paliek nemainīgs, ja nomaini vai atjaunini tēmu. Šis fails nekad netiek iekļauts Git repozitorijā (standarta WordPress prakse), tāpēc atslēga automātiski paliek ārpus versiju kontroles.

⚠️ functions.php Der, bet ne ideāli

Vienkāršāk rediģēt (pat caur WP admin tēmas redaktoru), taču atslēga "pieder" tēmai — nomainot tēmu, to vajadzēs pārnest manuāli. Ja tēmas kods glabājas Git, atslēga var netīšām tur nonākt.

Ieteicamais variants — pievieno faila wp-config.php beigās, pirms rindas /* That's all, stop editing! */:

phpdefine('TURNSTILE_SITE_KEY',   'ievieto_savu_site_key_šeit');
define('TURNSTILE_SECRET_KEY', 'ievieto_savu_secret_key_šeit');
define('CONTACT_OWNER_EMAIL',  'tavs@epasts.lv'); // kur sūtīt jaunos ziņojumus

Ja tomēr izvēlies functions.php ceļu (piem., ja nav ērtas piekļuves wp-config.php failam), tieši tas pats kods darbojas arī tur — vienīgā atšķirība ir kurā failā šīs trīs rindas ieliec. Lai kods nesagāztos, ja atslēgas kādreiz aizmirst pievienot, visur kodā tās izmanto ar drošu pārbaudi:

php$site_key   = defined('TURNSTILE_SITE_KEY')   ? TURNSTILE_SITE_KEY   : '';
$secret_key = defined('TURNSTILE_SECRET_KEY') ? TURNSTILE_SECRET_KEY : '';

3. Formas HTML

Ievieto šo veidnē (piem., page-kontakti.php vai tieši lapas saturā). Pievērs uzmanību honeypot laukam — tas ir tīši paslēpts ar CSS un normālam apmeklētājam nekad nav redzams, tāpēc, ja tas tomēr ir aizpildīts, zinām, ka to darīja bots.

html<form id="contact-form" novalidate>
    <!-- Honeypot — cilvēkam neredzams, boti to bieži aizpilda -->
    <input type="text" name="website" style="display:none !important" tabindex="-1" autocomplete="off">

    <div class="form-group">
        <label for="cf_name">Vārds</label>
        <input type="text" id="cf_name" name="name" required>
    </div>

    <div class="form-group">
        <label for="cf_email">E-pasts</label>
        <input type="email" id="cf_email" name="email" required>
    </div>

    <div class="form-group">
        <label for="cf_message">Ziņojums</label>
        <textarea id="cf_message" name="message" required></textarea>
    </div>

    <!-- Cloudflare Turnstile logrīks -->
    <div class="cf-turnstile" data-sitekey="<?= defined('TURNSTILE_SITE_KEY') ? esc_attr(TURNSTILE_SITE_KEY) : '' ?>"></div>

    <div id="contact-form-msg" role="alert"></div>

    <button type="submit">Nosūtīt ziņu</button>
</form>

4. Iesūtīšana (JS)

Šis skripts pārtver formas nosūtīšanu, savāc visus laukus (ieskaitot Turnstile "biļeti", kuru logrīks pats automātiski ievieto slēptā laukā cf-turnstile-response) un nosūta tos WordPress admin-ajax.php galapunktam bez lapas pārlādēšanas.

jsdocument.getElementById('contact-form').addEventListener('submit', async function (e) {
  e.preventDefault();

  const btn = this.querySelector('button[type="submit"]');
  const msg = document.getElementById('contact-form-msg');
  btn.disabled = true;

  try {
    const data = new FormData(this);
    data.append('action', 'handle_contact_form'); // jāsakrīt ar PHP wp_ajax_ āķa nosaukumu
    data.append('nonce', CF_DATA.nonce);          // skat. 5. soli — nonce nāk no PHP

    const res    = await fetch(CF_DATA.ajax_url, { method: 'POST', body: data });
    const result = await res.json();

    msg.className   = result.success ? 'form-success' : 'form-error';
    msg.textContent = result.data.message;

    if (result.success) this.reset();
  } catch (err) {
    msg.className   = 'form-error';
    msg.textContent = 'Kļūda nosūtot. Mēģiniet vēlreiz.';
  } finally {
    btn.disabled = false;
  }
});

Mainīgais CF_DATA (ar ajax_url un nonce) jānodod no PHP puses — tas parādīts nākamajā solī (wp_localize_script).

5. Servera apstrāde (PHP)

Šeit notiek viss būtiskais: nonce pārbaude, Turnstile pārbaude servera pusē (klienta puses pārbaude vien nav droša — to var apiet), honeypot pārbaude, datu attīrīšana un divu e-pasta vēstuļu nosūtīšana — īpašniekam par jauno ziņu un apmeklētājam kā apstiprinājums.

php// 1) Nododam JS pusei nepieciešamos datus (ajax_url un nonce)
add_action('wp_enqueue_scripts', function () {
    wp_enqueue_script('contact-form-js', get_template_directory_uri() . '/js/contact-form.js', [], '1.0', true);
    wp_localize_script('contact-form-js', 'CF_DATA', [
        'ajax_url' => admin_url('admin-ajax.php'),
        'nonce'    => wp_create_nonce('contact_form_nonce'),
    ]);
});

// 2) Reģistrējam AJAX āķi — nopriv versija ļauj strādāt arī neielogotiem apmeklētājiem
add_action('wp_ajax_handle_contact_form',        'handle_contact_form_submit');
add_action('wp_ajax_nopriv_handle_contact_form', 'handle_contact_form_submit');

function handle_contact_form_submit(): void {

    // ── 1. Nonce — vai pieprasījums nāk no mūsu pašu lapas ──
    if (!wp_verify_nonce($_POST['nonce'] ?? '', 'contact_form_nonce')) {
        wp_send_json_error(['message' => 'Drošības kļūda. Atsvaidzini lapu un mēģini vēlreiz.']);
    }

    // ── 2. Honeypot — ja "website" lauks aizpildīts, tas ir bots ──
    if (!empty($_POST['website'])) {
        wp_send_json_error(['message' => 'Konstatēts spams.']);
    }

    // ── 3. Cloudflare Turnstile — pārbauda ar Cloudflare serveri ──
    $turnstile_token = $_POST['cf-turnstile-response'] ?? '';
    if (empty($turnstile_token)) {
        wp_send_json_error(['message' => 'Lūdzu, pabeidziet drošības pārbaudi.']);
    }

    $secret_key = defined('TURNSTILE_SECRET_KEY') ? TURNSTILE_SECRET_KEY : '';

    $verify = wp_remote_post('https://challenges.cloudflare.com/turnstile/v0/siteverify', [
        'body' => [
            'secret'   => $secret_key,
            'response' => $turnstile_token,
            'remoteip' => $_SERVER['HTTP_CF_CONNECTING_IP'] ?? $_SERVER['REMOTE_ADDR'],
        ],
    ]);

    $outcome = json_decode(wp_remote_retrieve_body($verify), true);

    if (empty($outcome['success'])) {
        wp_send_json_error(['message' => 'Drošības pārbaude neizdevās. Vai tu neesi bots?']);
    }

    // ── 4. Lauku validācija un attīrīšana ──
    if (empty($_POST['name']) || empty($_POST['email']) || empty($_POST['message'])) {
        wp_send_json_error(['message' => 'Lūdzu, aizpildi visus laukus.']);
    }

    $name    = sanitize_text_field(wp_unslash($_POST['name']));
    $email   = sanitize_email($_POST['email']);
    $message = sanitize_textarea_field($_POST['message']);

    if (!is_email($email)) {
        wp_send_json_error(['message' => 'Nederīga e-pasta adrese.']);
    }

    // ── 5. E-pastu sagatavošana un nosūtīšana ──
    $owner_email = defined('CONTACT_OWNER_EMAIL') ? CONTACT_OWNER_EMAIL : get_option('admin_email');
    $site_name   = get_bloginfo('name');

    // Vēstule vietnes īpašniekam
    $owner_body = "<p><strong>Vārds:</strong> {$name}</p>"
        . "<p><strong>E-pasts:</strong> {$email}</p>"
        . "<p><strong>Ziņojums:</strong><br>" . nl2br(esc_html($message)) . "</p>";

    $owner_sent = wp_mail(
        $owner_email,
        'Jauns ziņojums no vietnes ' . $site_name,
        $owner_body,
        ['Content-Type: text/html; charset=UTF-8', 'Reply-To: ' . $name . ' <' . $email . '>']
    );

    // Apstiprinājuma vēstule apmeklētājam
    $client_body = "<p>Sveiki, {$name}!</p>"
        . "<p>Esam saņēmuši Jūsu ziņojumu un atbildēsim pēc iespējas ātrāk.</p>"
        . "<p><em>" . nl2br(esc_html($message)) . "</em></p>"
        . "<p>Ar cieņu,<br>{$site_name}</p>";

    wp_mail(
        $email,
        'Paldies par ziņojumu — ' . $site_name,
        $client_body,
        ['Content-Type: text/html; charset=UTF-8', 'From: ' . $site_name . ' <' . $owner_email . '>']
    );

    if ($owner_sent) {
        wp_send_json_success(['message' => 'Ziņojums veiksmīgi nosūtīts!']);
    }

    wp_send_json_error(['message' => 'Sūtīšanas kļūda. Lūdzu, mēģiniet vēlreiz.']);
}

Turnstile pārbaudi nekad nedrīkst darīt tikai JavaScript pusē — jebkurš var atvērt pārlūka rīkus un nosūtīt pieprasījumu tieši uz admin-ajax.php, apejot JS pilnībā. Tāpēc solis "wp_remote_post uz siteverify" servera pusē ir absolūti obligāts, ne tikai ieteicams.

Ja e-pasti nesasniedz iesūtni (bieži nokrīt spamā), tas parasti nav koda kļūda — WordPress wp_mail() pēc noklusējuma sūta no servera IP, kam bieži nav SPF/DKIM ieraksta. Risinājums: uzstādi spraudni kā WP Mail SMTP un nosūti vēstules caur īstu e-pasta servisu (Gmail, SendGrid, Brevo u.tml.).

Kā ielikt citā projektā

text1. Cloudflare Turnstile panelī izveido jaunu "site" savam domēnam
   un nokopē Site Key + Secret Key (1. sadaļa augstāk)

2. wp-config.php failā (pirms "stop editing" rindas) pievieno:
   define('TURNSTILE_SITE_KEY', '...');
   define('TURNSTILE_SECRET_KEY', '...');
   define('CONTACT_OWNER_EMAIL', 'tavs@epasts.lv');

3. functions.php pievieno skripta pieslēgšanu (1. sadaļa) un
   AJAX apstrādi (5. sadaļa) — vai izceļ 5. sadaļu atsevišķā
   failā, piem. inc/contact-form.php, un pievieno:
   require_once get_template_directory() . '/inc/contact-form.php';

4. Izveido failu js/contact-form.js ar 4. sadaļas JS kodu

5. Veidnē (piem. page-kontakti.php) ievieto 3. sadaļas HTML formu

6. Pārbaudi: aizpildi formu īstā vietnē (ne localhost — Turnstile
   sitekey ir piesaistīts konkrētam domēnam) un pārliecinies,
   ka abas e-pasta vēstules pienāk

Vēlies to pašu formu izmantot vairākās lapās (kontakti, footer, popup)? Nekas jāmaina nav — HTML/JS/PHP paliek identisks, jāpārliecinās tikai, ka katrā lapā ir unikāls elementa id, ja vienā lapā ir vairākas formas vienlaikus.
