DNS komandas

dig

DNS uzziņa (Linux/Mac)

dig example.com
dig example.com MX

nslookup

DNS uzziņa (Windows)

nslookup example.com

whois

Domēna reģistrācijas info

whois example.com

ping

Pārbauda sasniedzamību

ping example.com

ipconfig /flushdns

Notīra lokālo DNS kešu (Win)

ipconfig /flushdns

traceroute / tracert

Ceļš līdz serverim

tracert example.com

cURL komandas

GET pieprasījums

curl https://example.com

Skatīt tikai galvenes

curl -I https://example.com

POST ar JSON

curl -X POST https://example.com/api \
  -H "Content-Type: application/json" \
  -d '{"key":"value"}'

Sekot redirektiem

curl -L https://example.com

Ignorēt SSL kļūdas (tests!)

curl -k https://example.com

SSL / TLS komandas

Skatīt sertifikātu

openssl s_client -connect example.com:443

Derīguma termiņš

echo | openssl s_client -connect example.com:443 2>/dev/null \
  | openssl x509 -noout -dates

Certbot (Let's Encrypt)

certbot certonly --standalone -d example.com

Sertifikāta atjaunošana

certbot renew
