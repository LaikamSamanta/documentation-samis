PHP Cheatsheet

Blīva ātrās uzziņas lapa — sintakse bez garajiem skaidrojumiem. Pilnus piemērus un paskaidrojumus skaties pilnajā PHP dokumentācijā.

Sintakse & tipi

Atvēršanas tags

<?php
// kods
?>

echo / print

echo "Sveiks";
echo "A", "B";

gettype() / var_dump()

gettype($x);
var_dump($x);

Tipi

string, int, float, bool,
array, object, null

Tipa konvertācija

(int) "5"; (string) 5;
intval($x); strval($x);

Mainīgie & konstantes

Mainīgais

$vards = "Anna";

define() / const

define('VERSIJA', '1.0');
const MAX = 100;

Interpolācija

echo "Sveiks, $vards!";
echo "Sveiks, {$obj->vards}!";

isset() / empty() / is_null()

isset($x); empty($x); is_null($x);

null coalescing

$v = $x ?? "noklusējums";
$x ??= "noklusējums";

Operatori

===

Stingra salīdzināšana

"5" === 5 // false

<=>

Spaceship, kārtošanai

usort($a, fn($x,$y) => $x <=> $y);

Ternārais / short ternary

$x ? "jā" : "nē";
$x ?: "noklusējums";

. (konkatenācija)

$pilns = $vards . " " . $uzvards;

&& / || / !

if ($a && !$b) {}

Vadības struktūras

if / elseif / else

if ($a) {} elseif ($b) {} else {}

match (PHP 8+)

$r = match($x) {
  1, 2 => "mazs",
  default => "cits",
};

switch

switch ($x) {
  case 1: break;
  default: break;
}

for / foreach

for ($i=0; $i<5; $i++) {}
foreach ($arr as $k => $v) {}

while / do...while

while ($x < 5) { $x++; }

Funkcijas

function

function saskaitit($a, $b) {
  return $a + $b;
}

Noklusējuma parametrs

function f($x = 10) {}

Tipizēti parametri

function f(int $x): string {
  return (string) $x;
}

Anonīma / arrow function

$f = function($x) { return $x * 2; };
$f = fn($x) => $x * 2;

Variadiskie parametri

function f(...$args) {}

Masīvi

array_map()

array_map(fn($n) => $n * 2, $arr);

array_filter()

array_filter($arr, fn($n) => $n > 0);

array_reduce()

array_reduce($arr, fn($c,$n) => $c+$n, 0);

array_merge()

array_merge($a, $b);

in_array() / array_search()

in_array(3, $arr);
array_search(3, $arr);

count() / sort()

count($arr);
sort($arr); rsort($arr);

array_keys() / array_values()

array_keys($arr);
array_values($arr);

array_slice()

array_slice($arr, 1, 2);

Asociatīvais masīvs

$a = ['vards' => 'Anna', 'vecums' => 30];

Teksti

strlen() / str_replace()

strlen($s);
str_replace("a", "x", $s);

explode() / implode()

explode(",", "a,b,c");
implode(", ", $arr);

trim() / substr()

trim($s);
substr($s, 0, 3);

strtoupper() / strtolower()

strtoupper($s);
strtolower($s);

sprintf()

sprintf("Cena: %.2f EUR", 9.5);

str_contains/starts/ends

str_contains($s, "abc");
str_starts_with($s, "a");

OOP

class / constructor

class Lietotajs {
  public function __construct(
    private string $vards
  ) {}
}

extends / implements

class Admins extends Lietotajs implements Loggable {}

interface

interface Loggable {
  public function log(): void;
}

trait

trait Sveiciens {
  public function sveicini() { echo "Sveiks"; }
}
class X { use Sveiciens; }

static

class C { public static int $skaits = 0; }
C::$skaits++;

abstract

abstract class Forma {
  abstract public function laukums(): float;
}

Redzamība

public, protected, private

PDO datubāze

Savienojums

$pdo = new PDO(
  'mysql:host=localhost;dbname=db;charset=utf8mb4',
  'lietotajs', 'parole'
);

Sagatavots vaicājums (drošs!)

$stmt = $pdo->prepare('SELECT * FROM lietotaji WHERE id = ?');
$stmt->execute([$id]);
$rinda = $stmt->fetch();

Vairākas rindas

$rindas = $stmt->fetchAll();

INSERT + lastInsertId

$stmt = $pdo->prepare(
  'INSERT INTO log (teksts) VALUES (?)'
);
$stmt->execute([$teksts]);
$id = $pdo->lastInsertId();
