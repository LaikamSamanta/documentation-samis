PHP Cheatsheet

Ātrās uzziņas lapa - katrai kartiņai īss skaidrojums, ko tā dara un kam domāta, plus sintakses fragments. Pilnus piemērus un paskaidrojumus skaties pilnajā PHP dokumentācijā.

Sintakse & tipi

Atvēršanas tags

Viss PHP kods jāieskauj šajos tagos - bez tiem serveris rādītu kodu kā parastu tekstu, nevis izpildītu to.

<?php
// kods
?>

echo / print

Izvada tekstu tieši uz lapu - echo pieņem vairākus argumentus uzreiz, print vienmēr atgriež 1 un pieņem tikai vienu.

echo "Sveiks";
echo "A", "B";

gettype() / var_dump()

gettype() atgriež mainīgā tipu kā tekstu; var_dump() izvada gan tipu, gan vērtību - noder atkļūdošanai.

gettype($x);
var_dump($x);

Tipi

PHP pamata datu tipi - mainīgais pats par sevi nav "tipizēts", tips ir tai vērtībai, ko tas satur konkrētajā brīdī.

string, int, float, bool,
array, object, null

Tipa konvertācija

Piespiedu kārtā pārveido vērtību par citu tipu - (int)/(string) ir īsā sintakse, intval()/strval() to pašu dara ar funkciju.

(int) "5"; (string) 5;
intval($x); strval($x);

Mainīgie & konstantes

Mainīgais

PHP mainīgie vienmēr sākas ar $ zīmi - tips netiek norādīts, PHP to nosaka automātiski pēc piešķirtās vērtības.

$vards = "Anna";

define() / const

Izveido nemainīgu vērtību, ko nevar pārrakstīt vēlāk - define() strādā jebkurā vietā, const parasti izmanto klases iekšpusē vai globāli.

define('VERSIJA', '1.0');
const MAX = 100;

Interpolācija

Dubultpēdiņu teksta iekšienē mainīgie tiek automātiski aizvietoti ar savu vērtību - vienpēdiņu tekstā tas nenotiek.

echo "Sveiks, $vards!";
echo "Sveiks, {$obj->vards}!";

isset() / empty() / is_null()

isset() pārbauda, vai mainīgais eksistē un nav null; empty() vai tas ir "tukšs" (arī 0, "", false); is_null() - vai tieši null.

isset($x); empty($x); is_null($x);

null coalescing

?? atgriež labo pusi, ja kreisā ir null vai neeksistē (bez brīdinājuma); ??= piešķir vērtību tikai tad, ja mainīgais vēl nav iestatīts.

$v = $x ?? "noklusējums";
$x ??= "noklusējums";

Operatori

===

Salīdzina gan vērtību, gan tipu, bez automātiskas konvertācijas - droši lietojams, vienmēr izvēlies šo, nevis ==.

"5" === 5 // false

<=>

"Spaceship" operators - atgriež -1, 0 vai 1 atkarībā no salīdzinājuma, tieši tas, ko sagaida kārtošanas (usort) funkcijas.

usort($a, fn($x,$y) => $x <=> $y);

Ternārais / short ternary

Ternārais ir īss if/else, kas atgriež vērtību; short ternary (?:) atgriež kreiso pusi, ja tā ir patiesa, citādi labo.

$x ? "jā" : "nē";
$x ?: "noklusējums";

. (konkatenācija)

Savieno (saliek kopā) divus vai vairākus tekstus vienā - PHP tekstu savienošanai lieto punktu, nevis +.

$pilns = $vards . " " . $uzvards;

&& / || / !

Loģiskie operatori - UN (abi patiesi), VAI (vismaz viens patiess), NE (apgriež pretējā virzienā).

if ($a && !$b) {}

Vadības struktūras

if / elseif / else

Pamata sazarošanās - izpilda atšķirīgu koda bloku atkarībā no nosacījuma patiesumvērtības.

if ($a) {} elseif ($b) {} else {}

match (PHP 8+)

Modernāka switch alternatīva, kas atgriež vērtību un salīdzina stingri (===) - nav vajadzīgs break, nav "izkrišanas" riska.

$r = match($x) {
  1, 2 => "mazs",
  default => "cits",
};

switch

Salīdzina vienu vērtību ar vairākiem iespējamiem variantiem - break apstādina "izkrišanu" uz nākamo case.

switch ($x) {
  case 1: break;
  default: break;
}

for / foreach

for - cikls ar zināmu iterāciju skaitu un skaitītāju; foreach - iziet cauri masīva elementiem (un/vai atslēgām) tieši.

for ($i=0; $i<5; $i++) {}
foreach ($arr as $k => $v) {}

while / do...while

Cikls, kas turpinās, kamēr nosacījums patiess - do...while vienmēr izpilda ķermeni vismaz vienreiz.

while ($x < 5) { $x++; }

Funkcijas

function

Pamata funkcijas deklarācija - pieņem argumentus un (neobligāti) atgriež vērtību ar return.

function saskaitit($a, $b) {
  return $a + $b;
}

Noklusējuma parametrs

Piešķir vērtību parametram, ja izsaucot funkciju tas netiek nodots.

function f($x = 10) {}

Tipizēti parametri

Norāda sagaidāmo parametru un atgriežamās vērtības tipu - PHP izmet kļūdu, ja tips nesakrīt (strict_types režīmā).

function f(int $x): string {
  return (string) $x;
}

Anonīma / arrow function

Funkcija bez nosaukuma, ko var saglabāt mainīgajā vai nodot kā argumentu - fn() (arrow) automātiski "redz" ārējos mainīgos.

$f = function($x) { return $x * 2; };
$f = fn($x) => $x * 2;

Variadiskie parametri

... pirms parametra savāc jebkādu skaitu nodoto argumentu vienā masīvā funkcijas iekšpusē.

function f(...$args) {}

Masīvi

array_map()

Atgriež jaunu masīvu, katru elementu pārveidojot ar norādīto funkciju - oriģinālais masīvs netiek mainīts.

array_map(fn($n) => $n * 2, $arr);

array_filter()

Atgriež jaunu masīvu tikai ar elementiem, kas iztur nosacījumu (callback funkciju).

array_filter($arr, fn($n) => $n > 0);

array_reduce()

Sareducē visu masīvu vienā vērtībā, izpildot funkciju secīgi katram elementam ar uzkrāto rezultātu.

array_reduce($arr, fn($c,$n) => $c+$n, 0);

array_merge()

Apvieno divus vai vairākus masīvus vienā jaunā - teksta atslēgas dublējoties tiek pārrakstītas, skaitliskās pārnumurētas.

array_merge($a, $b);

in_array() / array_search()

in_array() pārbauda, vai vērtība eksistē masīvā (true/false); array_search() atgriež tās atslēgu (vai false).

in_array(3, $arr);
array_search(3, $arr);

count() / sort()

count() atgriež elementu skaitu; sort()/rsort() sakārto masīvu augošā/dilstošā secībā, PĀRRAKSTOT atslēgas ar jaunu numerāciju.

count($arr);
sort($arr); rsort($arr);

array_keys() / array_values()

Atgriež masīva atslēgas vai vērtības kā jaunu, atsevišķu (skaitliski indeksētu) masīvu.

array_keys($arr);
array_values($arr);

array_slice()

Izgriež masīva daļu pēc sākuma pozīcijas un garuma, neko nemainot oriģinālajā masīvā.

array_slice($arr, 1, 2);

Asociatīvais masīvs

Masīvs ar teksta atslēgām (nevis secīgiem skaitļiem) - pieejai pie vērtībām izmanto atslēgas nosaukumu, nevis indeksu.

$a = ['vards' => 'Anna', 'vecums' => 30];

Teksti

strlen() / str_replace()

strlen() atgriež teksta garumu (baitos); str_replace() aizvieto VISAS meklētā apakšteksta sakritības ar jaunu.

strlen($s);
str_replace("a", "x", $s);

explode() / implode()

explode() sadala tekstu masīvā pēc atdalītāja; implode() dara pretējo - savieno masīva elementus vienā tekstā.

explode(",", "a,b,c");
implode(", ", $arr);

trim() / substr()

trim() noņem liekās atstarpes teksta malās; substr() izgriež teksta daļu pēc sākuma pozīcijas un garuma.

trim($s);
substr($s, 0, 3);

strtoupper() / strtolower()

Pārvērš tekstu par lielajiem/mazajiem burtiem - noder salīdzināšanai bez reģistrjutības.

strtoupper($s);
strtolower($s);

sprintf()

Formatē tekstu, ievietojot mainīgos noteiktā formātā (piem., decimālskaitļus ar fiksētu ciparu skaitu aiz komata).

sprintf("Cena: %.2f EUR", 9.5);

str_contains/starts/ends

Pārbauda, vai teksts satur/sākas/beidzas ar norādīto apakštekstu - atgriež true/false (PHP 8+).

str_contains($s, "abc");
str_starts_with($s, "a");

OOP

class / constructor

Veidne objektu izveidei - __construct() izpildās automātiski, kad izveido jaunu instanci ar new. "private string $vards" ir saīsināta konstruktora rekvizīta sintakse (PHP 8+).

class Lietotajs {
  public function __construct(
    private string $vards
  ) {}
}

extends / implements

extends manto no citas klases (mantojums); implements apņemas ievērot interfeisa metodes (līgumu).

class Admins extends Lietotajs implements Loggable {}

interface

Definē metožu "līgumu" bez to realizācijas - jebkurai klasei, kas to implementē, obligāti jāraksta šīs metodes.

interface Loggable {
  public function log(): void;
}

trait

Koda bloks, ko var "iejaukt" (use) vairākās klasēs, kurām nav kopīga vecāka - apiet PHP ierobežojumu mantot tikai no vienas klases.

trait Sveiciens {
  public function sveicini() { echo "Sveiks"; }
}
class X { use Sveiciens; }

static

Īpašība/metode, kas pieder pašai klasei, nevis atsevišķai instancei - piekļūst caur klases nosaukumu ar ::.

class C { public static int $skaits = 0; }
C::$skaits++;

abstract

Klase/metode, ko nevar izveidot (instantizēt) tieši - kalpo tikai kā veidne, no kuras jāmanto un jārealizē trūkstošās metodes.

abstract class Forma {
  abstract public function laukums(): float;
}

Redzamība

Kontrolē, no kurienes drīkst piekļūt īpašībai/metodei - public (visur), protected (klase + mantotāji), private (tikai šī klase).

public, protected, private

Kļūdu apstrāde

try/catch/finally

try satur kodu, kas var izmest izņēmumu (Exception); catch to noķer; finally izpildās vienmēr, neatkarīgi no rezultāta.

try {
  riskants();
} catch (Exception $e) {
  echo $e->getMessage();
} finally {}

throw

Apzināti izmet izņēmumu - apstādina tālāko koda izpildi, ja vien to neaptver try/catch augstāk izsaukumu ķēdē.

throw new InvalidArgumentException("kļūda");

Custom exception

Sava izņēmumu klase, kas manto no Exception - ļauj catch blokā atšķirt savas kļūdas no citām, pēc to tipa.

class ManaKluda extends Exception {}

Superglobālie mainīgie

Iebūvēti masīvi, kas pieejami jebkurā koda vietā bez papildu deklarēšanas - satur ārējos datus, kas ienāk kopā ar pieprasījumu.

MainīgaisSatur
$_GETURL query parametri (piem. ?id=5 → $_GET['id'])
$_POSTFormas dati, nosūtīti ar POST metodi
$_SESSIONDati, kas saglabājas starp lapām vienam apmeklētājam (pēc session_start())
$_COOKIESīkdatnes, ko saglabājis pārlūks
$_SERVERServera un pieprasījuma info (URL, IP, galvenes)
$_FILESInformācija par augšupielādētajiem failiem

Faili & include

include / require

Abas ielādē citu PHP failu tieši šajā vietā - require pārtrauc visa skripta izpildi, ja fails nav atrasts, include tikai izmet brīdinājumu un turpina.

require_once 'config.php';
include 'header.php';

file_get_contents / put

get_contents() nolasa visa faila saturu vienā tekstā; put_contents() ieraksta tekstu failā (izveidojot to, ja neeksistē).

$s = file_get_contents('fails.txt');
file_put_contents('fails.txt', $s);

file_exists()

Pārbauda, vai fails vai mape eksistē pirms mēģini to lasīt/rakstīt - izvairās no kļūdas, ja ceļš nepareizs.

if (file_exists('fails.txt')) {}

__DIR__ / __FILE__

__DIR__ ir pašreizējā faila mapes ceļš, __FILE__ - paša faila pilnais ceļš - droši lietot include ceļos neatkarīgi no tā, no kurienes skripts izsaukts.

require __DIR__ . '/config.php';

Datums & laiks

date()

Formatē pašreizējo (vai norādītu) laika zīmogu kā salasāmu tekstu pēc dotā formāta.

date('Y-m-d H:i:s');

DateTime

Objektorientēts veids darbam ar datumiem - modify() ļauj ērti pieskaitīt/atņemt laika periodus.

$d = new DateTime('2026-07-25');
$d->modify('+1 day');

strtotime()

Pārvērš cilvēkam saprotamu teksta izteiksmi ("+1 week", "next monday") par Unix laika zīmogu (skaitli).

strtotime('+1 week');

Regex

preg_match()

Pārbauda, vai teksts atbilst regulārai izteiksmei, un ieraksta atrasto sakritību mainīgajā ($m) - atgriež 1 (atrasts) vai 0.

preg_match('/^[a-z]+$/', $s, $m);

preg_replace()

Aizvieto visas regulārajai izteiksmei atbilstošās vietas tekstā ar norādīto aizvietotāju.

preg_replace('/\d+/', '#', $s);

preg_match_all()

Tas pats, kas preg_match(), bet atrod VISAS sakritības tekstā, nevis tikai pirmo, un saglabā tās masīvā.

preg_match_all('/\d+/', $s, $m);

PDO datubāze

Savienojums

Izveido savienojumu ar MySQL/MariaDB datubāzi, izmantojot PDO - universālu PHP saskarni, kas strādā ar vairākiem datubāzu tipiem.

$pdo = new PDO(
  'mysql:host=localhost;dbname=db;charset=utf8mb4',
  'lietotajs', 'parole'
);

Sagatavots vaicājums (drošs!)

? ir vietturis, ko aizpilda execute() masīvs - pasargā no SQL injection, jo dati nekad netiek tieši ielikti vaicājuma tekstā.

$stmt = $pdo->prepare('SELECT * FROM lietotaji WHERE id = ?');
$stmt->execute([$id]);
$rinda = $stmt->fetch();

Vairākas rindas

fetchAll() atgriež VISAS vaicājuma atbilstošās rindas kā masīvu, atšķirībā no fetch(), kas atgriež tikai vienu.

$rindas = $stmt->fetchAll();

INSERT + lastInsertId

Pēc jaunas rindas ievietošanas lastInsertId() atgriež tikko izveidotās rindas automātiski ģenerēto ID.

$stmt = $pdo->prepare(
  'INSERT INTO log (teksts) VALUES (?)'
);
$stmt->execute([$teksts]);
$id = $pdo->lastInsertId();

Composer

composer require

Instalē bibliotēku un pievieno to composer.json.

composer require monolog/monolog

composer install

Instalē visas atkarības no composer.lock - jāpalaiž pēc katras klonēšanas.

composer install

Ielāde kodā

Viena rinda, kas ielādē visas Composer bibliotēkas.

require 'vendor/autoload.php';

Spraudnī/tēmā

Composer WordPress projektā parasti pārvalda tikai VIENA spraudņa/tēmas atkarības, ne kodolu.

require __DIR__ . '/vendor/autoload.php';

WordPress Packagist

Ļauj pārvaldīt arī pašus WP spraudņus/tēmas caur composer.json.

"wpackagist-plugin/contact-form-7": "^5.9"

Citas noderīgas

json_encode / decode

encode() pārvērš PHP masīvu/objektu par JSON tekstu (nosūtīšanai/saglabāšanai); decode() dara pretējo.

json_encode($arr);
json_decode($json, true);

htmlspecialchars()

Pārvērš speciālos HTML simbolus (<, >, &) par to drošajiem ekvivalentiem - obligāti pirms lietotāja ievadītu tekstu izvadīt lapā, lai novērstu XSS.

echo htmlspecialchars($lietotaja_teksts);

null safe operator

?-> droši piekļūst iegultai objekta īpašībai - ja jebkura daļa ceļā ir null, visa izteiksme atgriež null, nevis met kļūdu (PHP 8+).

$pilseta = $lietotajs?->adrese?->pilseta;
