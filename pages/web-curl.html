curl: exit codes un statusa kodi

curl - kas tas ir un biežākie karogi

curl ir komandrindas rīks, kas nosūta HTTP pieprasījumu un parāda atbildi. To lieto, lai pārbaudītu, kas serveris tiešām atbild - bez pārlūka, kešatmiņas un spraudņiem.

Katram curl izsaukumam ir divi neatkarīgi rezultāti: HTTP statusa kods (ko atsūta serveris) un curl exit code (vai pats curl nostrādāja). Sk. zemāk.

curl exit codes (ko nozīmē skaitlis pēc komandas)

Pēc katras komandas curl atgriež skaitli. Tu to redzi ar echo $? (Linux/macOS/Git Bash) vai echo $LASTEXITCODE (PowerShell). 0 = curl pats nostrādāja bez kļūdām, cits skaitlis = curl nevarēja izpildīt pieprasījumu.

Exit code NAV HTTP statusa kods. Ja serveris atbild 404 vai 500, curl tik un tā beidzas ar exit 0 (jo pieprasījums izdevās - atbilde saņemta). Lai 4xx/5xx kļūtu par kļūdu, pievieno -f → tad exit code ir 22.

HTTP statusa kodi

Trīs cipari, ko serveris atsūta katrā atbildē. Pirmais cipars pasaka grupu: 2 viss ok · 3 redirect · 4 tava kļūda · 5 servera kļūda. Parādi ar curl -I vai -w '%{http_code}'.
