Sagataves

Gatavas UI komponentes — tīrs HTML/CSS/JS, bez bibliotēkām. Katrai — dzīvs priekšskatījums un pilnībā patstāvīgs kods, ko var iekopēt un uzreiz lietot.

Attēlu karuselis / slaideris

Slaidi ar automātisku maiņu, pogām un punktiem apakšā.

Priekšskatījums

HTML

html<div class="dscar" id="dscar1">
    <div class="dscar-track">
        <div class="dscar-slide" style="background:#7c3aed">1</div>
        <div class="dscar-slide" style="background:#2563eb">2</div>
        <div class="dscar-slide" style="background:#059669">3</div>
    </div>
    <button class="dscar-btn dscar-prev" aria-label="Iepriekšējais">‹</button>
    <button class="dscar-btn dscar-next" aria-label="Nākamais">›</button>
    <div class="dscar-dots"></div>
</div>

CSS

css.dscar { position: relative; overflow: hidden; border-radius: 12px; aspect-ratio: 16/7; }
.dscar-track { display: flex; height: 100%; transition: transform .4s ease; }
.dscar-slide { flex: 0 0 100%; display: flex; align-items: center; justify-content: center; color: #fff; font-size: 2rem; font-weight: 700; }
.dscar-btn { position: absolute; top: 50%; transform: translateY(-50%); background: rgba(0,0,0,.4); color: #fff; border: none; width: 36px; height: 36px; border-radius: 50%; cursor: pointer; font-size: 1.2rem; }
.dscar-prev { left: 12px; }
.dscar-next { right: 12px; }
.dscar-dots { position: absolute; bottom: 12px; left: 50%; transform: translateX(-50%); display: flex; gap: 8px; }
.dscar-dots button { width: 8px; height: 8px; border-radius: 50%; border: none; background: rgba(255,255,255,.5); cursor: pointer; padding: 0; }
.dscar-dots button.active { background: #fff; }

JavaScript

js(function () {
    const car = document.getElementById('dscar1');
    const track = car.querySelector('.dscar-track');
    const slides = car.querySelectorAll('.dscar-slide');
    const dotsWrap = car.querySelector('.dscar-dots');
    let index = 0;

    slides.forEach((_, i) => {
        const dot = document.createElement('button');
        if (i === 0) dot.classList.add('active');
        dot.addEventListener('click', () => goTo(i));
        dotsWrap.appendChild(dot);
    });
    const dots = dotsWrap.querySelectorAll('button');

    function goTo(i) {
        index = (i + slides.length) % slides.length;
        track.style.transform = `translateX(-${index * 100}%)`;
        dots.forEach((d, di) => d.classList.toggle('active', di === index));
    }

    car.querySelector('.dscar-prev').addEventListener('click', () => goTo(index - 1));
    car.querySelector('.dscar-next').addEventListener('click', () => goTo(index + 1));

    let timer = setInterval(() => goTo(index + 1), 4000);
    car.addEventListener('mouseenter', () => clearInterval(timer));
    car.addEventListener('mouseleave', () => { timer = setInterval(() => goTo(index + 1), 4000); });
})();

Slaidus (.dscar-slide) šeit aizvieto krāsaini bloki demonstrācijai — reālā projektā katra div vietā liec attēlu (<img>) vai jebkuru citu saturu. Ja lapā ir vairāki karuseļi, katram vajag unikālu id un savu document.getElementById(...) izsaukumu.

Akordeons (FAQ)

Klikšķinot uz jautājuma, atveras atbilde; atverot jaunu, iepriekšējā aizveras.

Priekšskatījums

HTML

html<div class="dsacc">
    <div class="dsacc-item">
        <button class="dsacc-head">Kas ir WordPress? <span>+</span></button>
        <div class="dsacc-body"><p>WordPress ir satura pārvaldības sistēma (CMS), kas darbina vairāk nekā 40% no visām interneta vietnēm.</p></div>
    </div>
    <div class="dsacc-item">
        <button class="dsacc-head">Vai der iesācējiem? <span>+</span></button>
        <div class="dsacc-body"><p>Jā — pamata lietošanai nav vajadzīgas programmēšanas zināšanas, bet pielāgošanai der zināt HTML/CSS/PHP.</p></div>
    </div>
    <div class="dsacc-item">
        <button class="dsacc-head">Cik tas maksā? <span>+</span></button>
        <div class="dsacc-body"><p>Pats WordPress ir bezmaksas — maksā tikai domēns un hostings.</p></div>
    </div>
</div>

CSS

css.dsacc-item { border-bottom: 1px solid #e5e7eb; }
.dsacc-head { width: 100%; text-align: left; background: none; border: none; padding: 16px 4px; font-size: 1rem; font-weight: 600; cursor: pointer; display: flex; justify-content: space-between; align-items: center; color: #111827; }
.dsacc-head span { transition: transform .25s ease; }
.dsacc-item.open .dsacc-head span { transform: rotate(45deg); }
.dsacc-body { max-height: 0; overflow: hidden; transition: max-height .3s ease; }
.dsacc-body p { margin: 0 0 16px; color: #4b5563; line-height: 1.6; }

JavaScript

jsdocument.querySelectorAll('.dsacc-item').forEach((item) => {
    const head = item.querySelector('.dsacc-head');
    const body = item.querySelector('.dsacc-body');

    head.addEventListener('click', () => {
        const isOpen = item.classList.contains('open');

        item.parentElement.querySelectorAll('.dsacc-item').forEach((i) => {
            i.classList.remove('open');
            i.querySelector('.dsacc-body').style.maxHeight = null;
        });

        if (!isOpen) {
            item.classList.add('open');
            body.style.maxHeight = body.scrollHeight + 'px';
        }
    });
});

Tabi (Tabs)

Klasiska tabu pārslēgšana — viena aktīva poga, viens redzams panelis.

Priekšskatījums

HTML

html<div class="dstabs">
    <div class="dstabs-nav">
        <button class="dstabs-btn active" data-tab="t1">Apraksts</button>
        <button class="dstabs-btn" data-tab="t2">Specifikācija</button>
        <button class="dstabs-btn" data-tab="t3">Atsauksmes</button>
    </div>
    <div class="dstabs-panel active" id="t1"><p>Produkta apraksts šeit...</p></div>
    <div class="dstabs-panel" id="t2"><p>Tehniskā specifikācija šeit...</p></div>
    <div class="dstabs-panel" id="t3"><p>Klientu atsauksmes šeit...</p></div>
</div>

CSS

css.dstabs-nav { display: flex; gap: 4px; border-bottom: 2px solid #e5e7eb; }
.dstabs-btn { background: none; border: none; padding: 10px 16px; cursor: pointer; font-weight: 600; color: #6b7280; border-bottom: 2px solid transparent; margin-bottom: -2px; }
.dstabs-btn.active { color: #7c3aed; border-bottom-color: #7c3aed; }
.dstabs-panel { display: none; padding: 16px 4px; color: #4b5563; }
.dstabs-panel.active { display: block; }

JavaScript

jsdocument.querySelectorAll('.dstabs-btn').forEach((btn) => {
    btn.addEventListener('click', () => {
        const tabs = btn.closest('.dstabs');

        tabs.querySelectorAll('.dstabs-btn').forEach((b) => b.classList.remove('active'));
        tabs.querySelectorAll('.dstabs-panel').forEach((p) => p.classList.remove('active'));

        btn.classList.add('active');
        tabs.querySelector('#' + btn.dataset.tab).classList.add('active');
    });
});

data-tab="t1" pogā un id="t1" panelī jāsakrīt — tā JS zina, kuru paneli rādīt, kad tu klikšķini uz konkrētas pogas. Pievienojot jaunu tabu, pievieno vienlaicīgi gan jaunu pogu, gan jaunu paneli ar to pašu identifikatoru abās vietās.

Modālais logs (Modal)

Uznirstošs logs virs lapas satura — aizveras ar ✕, klikšķi ārpusē vai Esc taustiņu.

Priekšskatījums

HTML

html<button id="openModalBtn" class="dsmodal-open-btn">Atvērt modālo logu</button>

<div class="dsmodal-overlay" id="myModal">
    <div class="dsmodal-box">
        <button class="dsmodal-close" aria-label="Aizvērt">✕</button>
        <h3>Modālā loga virsraksts</h3>
        <p>Šeit ir modālā loga saturs. Klikšķini ārpusē vai uz ✕, lai aizvērtu.</p>
    </div>
</div>

CSS

css.dsmodal-open-btn { background: #7c3aed; color: #fff; border: none; padding: 10px 20px; border-radius: 8px; cursor: pointer; font-weight: 600; }
.dsmodal-overlay { display: none; position: fixed; inset: 0; background: rgba(0,0,0,.5); align-items: center; justify-content: center; z-index: 999; }
.dsmodal-overlay.open { display: flex; }
.dsmodal-box { background: #fff; border-radius: 12px; padding: 24px; max-width: 400px; width: 90%; position: relative; }
.dsmodal-close { position: absolute; top: 12px; right: 12px; background: none; border: none; font-size: 1.1rem; cursor: pointer; color: #6b7280; }

JavaScript

jsconst modal = document.getElementById('myModal');

document.getElementById('openModalBtn').addEventListener('click', () => {
    modal.classList.add('open');
});
document.querySelector('.dsmodal-close').addEventListener('click', () => {
    modal.classList.remove('open');
});
modal.addEventListener('click', (e) => {
    if (e.target === modal) modal.classList.remove('open'); // klikšķis TIEŠI uz fona, ne uz kastes
});
document.addEventListener('keydown', (e) => {
    if (e.key === 'Escape') modal.classList.remove('open');
});

Toast paziņojums

Neuzbāzīgs paziņojums ekrāna stūrī, kas pēc dažām sekundēm pats pazūd.

Priekšskatījums

HTML

html<button id="showToastBtn" class="dstoast-btn">Rādīt paziņojumu</button>
<div class="dstoast-wrap" id="toastWrap"></div>

CSS

css.dstoast-btn { background: #059669; color: #fff; border: none; padding: 10px 20px; border-radius: 8px; cursor: pointer; font-weight: 600; }
.dstoast-wrap { position: fixed; bottom: 20px; right: 20px; display: flex; flex-direction: column; gap: 10px; z-index: 999; }
.dstoast { background: #111827; color: #fff; padding: 12px 18px; border-radius: 8px; box-shadow: 0 10px 30px rgba(0,0,0,.2); opacity: 0; transform: translateY(10px); transition: all .3s ease; font-size: .9rem; }
.dstoast.show { opacity: 1; transform: translateY(0); }

JavaScript

jsdocument.getElementById('showToastBtn').addEventListener('click', () => {
    const wrap = document.getElementById('toastWrap');
    const toast = document.createElement('div');
    toast.className = 'dstoast';
    toast.textContent = 'Saglabāts veiksmīgi!';
    wrap.appendChild(toast);

    requestAnimationFrame(() => toast.classList.add('show'));

    setTimeout(() => {
        toast.classList.remove('show');
        setTimeout(() => toast.remove(), 300); // pagaida, kamēr izbalēšanas animācija pabeidzas
    }, 3000);
});

Katrs klikšķis izveido jaunu .dstoast elementu — vairāki paziņojumi var sakrāties viens virs otra (tieši tāpēc .dstoast-wrap ir flex-direction: column). Tie automātiski izņem paši sevi no DOM pēc pazušanas, tāpēc tie nekrājas mūžīgi.

Lightbox (attēlu skatītājs)

Klikšķini uz sīktēla, lai redzētu attēlu pilnā izmērā virs lapas satura.

Priekšskatījums

HTML

html<div class="dslb-grid">
    <img src="attels-1.jpg" class="dslb-thumb" alt="Apraksts 1">
    <img src="attels-2.jpg" class="dslb-thumb" alt="Apraksts 2">
    <img src="attels-3.jpg" class="dslb-thumb" alt="Apraksts 3">
</div>

<div class="dslb-overlay" id="lbOverlay">
    <img src="" alt="" id="lbImage">
</div>

CSS

css.dslb-grid { display: flex; gap: 12px; flex-wrap: wrap; }
.dslb-thumb { width: 120px; height: 80px; object-fit: cover; border-radius: 8px; cursor: zoom-in; transition: opacity .2s; }
.dslb-thumb:hover { opacity: .85; }
.dslb-overlay { display: none; position: fixed; inset: 0; background: rgba(0,0,0,.85); align-items: center; justify-content: center; z-index: 999; cursor: zoom-out; }
.dslb-overlay.open { display: flex; }
.dslb-overlay img { max-width: 90%; max-height: 90%; border-radius: 8px; }

JavaScript

jsconst overlay = document.getElementById('lbOverlay');
const lbImg = document.getElementById('lbImage');

document.querySelectorAll('.dslb-thumb').forEach((thumb) => {
    thumb.addEventListener('click', () => {
        lbImg.src = thumb.src; // sīktēla attēls ir vienkāršības labad tas pats, kas pilnā izmērā —
        lbImg.alt = thumb.alt; // reālā projektā src norāda uz atsevišķu, lielāku attēla versiju
        overlay.classList.add('open');
    });
});
overlay.addEventListener('click', () => overlay.classList.remove('open'));
document.addEventListener('keydown', (e) => {
    if (e.key === 'Escape') overlay.classList.remove('open');
});
